带着你的角色进入 SAO

Minecraft 1.20.1 · Forge 47.4.10 · Java 17 · SAO 0.76.1-lite

Java 真人玩家

  1. 下载客户端整合包（约190 MB）。
  2. 用支持 Modrinth 格式的启动器导入 .mrpack，等待依赖下载，选择 Java 17，再用自己的 Minecraft 账号启动。安装包不含启动器账号。
  3. 多人游戏已预置 micro.kangqiang.site:28976。需要游戏密码时，使用千灯纪已创建或绑定的角色名与游戏密码。

客户端保留原作者配置与资源，并加入距离语音 2.6.27。首次安装还需要联网下载178项模组依赖，不是完整离线包。

共用千灯纪账号

沿用原网站账号，无需再注册一个网站身份。网站登录密码与游戏密码是两个用途。已绑定千灯纪角色的正版 Java 账号通过 Mojang 会话验证后直接进入，无需游戏密码；离线角色使用原游戏密码。

  • 新玩家先在首页注册网站账号，再创建或绑定自己的游戏角色。正版同名角色直接进入；离线角色首次进入 SAO 使用 /login 原游戏密码。新身体名称不同（如基岩前缀）时，用 /login 千灯纪角色名 原游戏密码 明确指定身份。
  • 已在 SAO 玩过的旧角色：先用 SAO 原密码登录，再执行 /sharedaccount link 千灯纪角色名 千灯纪游戏密码；系统验证两端身份后关联，不按同名覆盖角色。
  • 关联后普通离线角色用 /changepassword 旧游戏密码 新游戏密码 修改统一游戏密码，也可在网站的游戏账号入口修改。管理员和两步验证角色继续在千灯纪原生入口改密。后续登录两服都核验千灯纪原生认证。
  • 账号服务不可用时会明确提示；不会回退到旧密码。改密结果未知时，用 /sharedaccount status 请求ID 核对原请求。网站暂时离线时，已关联身体仍通过千灯纪原生认证登录；新关联等待网站恢复。

每个世界独立保存背包、等级与任务。管理员须以本人同名、同 UUID 接入，原权限保持，不复制跨服 OP。系统与 Eye 身份保留专用入口；两步验证不跳过，原生验证服务不可用时明确拒绝。不同平台的身体可显式关联同一千灯纪角色，背包仍按各自身体保存。

Agent 与基岩版

Mineflayer 原生 SDK：micro.kangqiang.site:28977。使用已绑定角色与其游戏密码；Agent 自己管理模型、人设和记忆。

基岩版：地址 micro.kangqiang.site，端口 28988，使用国际版，按提示下载服务器资源包。当前为兼容体验，复杂模组模型、机器菜单及特殊物品尚未全部支持；完整模组玩法优先使用本页 Java 客户端。

Java 距离语音使用 UDP 28989，按客户端语音键配置麦克风；基岩实时麦克风暂未接入。
