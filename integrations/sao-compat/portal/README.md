# SAO 客户端的 OSS 与网站发布

网站入口：<https://mc.kangqiang.site/sao.html>；下载中心：<https://mc.kangqiang.site/downloads.html#game-clients>。

客户端为 SAO `0.76.1-lite-20261030.2`，Minecraft 1.20.1、Forge 47.4.10、Java 17。`sao-client.json` 是网站下载目录的元数据来源，包含不可变对象链接、字节数和 SHA256。网站原九个下载保留。`.mrpack` 是整合包导入文件，首次安装仍需下载 178 项依赖，不能作为完整离线包宣传。

`../public/build_client_pack.py` 只读取固定作者归档与经过校验的语音模组，不读取维护者启动器账号或游戏运行目录。构建会重建服务器列表、清除凭据字段，并移除每台机器生成的 Resourceful Config Web 验证器文件，让客户端本机生成受保护的默认配置。不能用空密码代替删除验证器。输出文件不覆盖，改动应使用新文件名、版本与 OSS 哈希路径。

当前发布文件：`MyAgentWorld-SAO-0.76.1-lite-1.20.1-r2.mrpack`，189,698,558 字节，SHA256 `e858aee6e22b249a32c33c3a379274683bdedf5b26bd7f682a379f69c6ddb612`。匿名完整下载及哈希、ZIP CRC、真实 NBT 服务器地址解析均已核验。

## 网站增量合并

生产网站先前运行 0.8.31，并非仓库中早期门户目录的完整对应版本。`patch_site.py` 要求该准确基线，保留现役功能，增量加入 `shared-realm-access.mjs`、客户端清单和 `sao.html`，更新首页卡片与下载页，再生成 0.8.32。不要把早期门户源码整体覆盖到生产，也不要将此一次性补丁原样应用到未来版本。

现役容器镜像为 `qiandengji-portal:0.8.32-sao-770114e29b1a`。既有数据、只读配置和 `/trusted-world-viewer` 挂载保持；不做数据库重建或旧备份恢复。`cloud_stage.py` 在现役镜像基础上执行隔离克隆验证；`cloud_deploy.py` 正常停止旧容器后冷备，再保留旧镜像、启动新镜像并检查原账号、归属和下载。旧容器与冷备均保留，不能在运行时用旧数据库覆盖新增记录。

`sharedRealmAccess` 配置仅保存服务令牌 SHA256。受限 `GET /api/v1/internal/realm-accounts/roles` 返回已核验归属的普通角色名与 UUID，不返回密码、哈希、邮箱或模型密钥。只读家庭主机发布器使用独立私有令牌经 HTTPS 拉取；浏览器 Origin/Cookie、错误令牌和过期来源被拒绝。实际游戏认证及改密见 [共用账号组件](../../shared-realm-accounts/README.md)。网站登录密码与游戏密码保持各自用途。

临时来源提取与备份传输授权在完成后已撤销，桌面用户导出副本已删除；根用户备份及 E/F 校验副本保留。令牌、SSH 私钥、真实配置、数据库、安装包和测试账号均不提交 Git。
