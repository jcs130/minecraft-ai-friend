# R2 客户端兼容与主世界出生修复

官网 R2 是 SAO 0.76.1-lite / Minecraft 1.20.1 / Forge 47.4.10。保留原 R2 安装；这次修复属于服务端组件，不要求真人安装 Numen。

## 两个独立原因

服务器列表的红色 FML 提示来自额外安装的 Numen：实际连接允许缺少其客户端，但 Forge 压缩状态包仍将 `numen`、`numen_api` 及 `numen_api:main`、`numen_tlm:outfit` 声明为必需。不能把这个列表提示等同于所有内容模组不兼容。

CNxhy 保存的位置是主世界 `(0,100,0)` 附近的旧测试石平台；`level.dat` 也把它作为默认出生点。它不是世界地图全部内容，也不是私人家园维度。已保存的地形中存在村庄、遗迹等结构；没有重置世界或伪称安装包自带完整主城。

R2 静态核对：170 个共有 JAR 哈希一致；FTB Teams 与 vzling 两项保留既有服务端兼容修订。额外的 DirectAuth、共享账号组件、原生桥与 Numen 属于服务端安装。R2 SHA256 为 `e858aee6e22b249a32c33c3a379274683bdedf5b26bd7f682a379f69c6ddb612`。

## 组件行为

自有桥接组件升级到 0.1.1，SDK 升级到 0.1.2。服务器列表补丁仅在专用服务端、常驻组件已安装、Numen/API 均为已审核的 0.1.4.1、对应频道协议为 1 时生效。只修改新建的 `ServerStatusPing` 数据，不修改任何网络校验谓词、账号验证或其他模组声明。未知版本保持原声明。已有 Numen 客户端仍可使用；Mineflayer 同时声明缺少 Numen 的女仆外观频道，避免假装已安装它。

原生出生组件读取可选 `config/maw-arrival.json`。没有文件或 `enabled=false` 时不迁移。正式落地点为已生成的村庄道路附近 `minecraft:overworld (1259.5,84,-952.5)`，朝北、出生随机半径 0。启动时校验配置、边界、地面碰撞和脚部／头部空间，再设置世界出生点。

迁移只针对配置明确列出的原 UUID，并且必须已经完成原生认证、存活、尚未处理、仍处在旧平台边界内。当前仅列 CNxhy 与 LittleFish0510。其他探索位置、维度和账号不移动；每 tick 最多处理两人。保留背包、床、职业、任务、经验及原身体身份。欢迎文字私发一次，迁移意图与实际结果记录在 `world/data/maw-arrivals.jsonl`。

配置限制：schemaVersion 1；32 KiB；迁移名单最多 256 UUID；旧范围各轴端点差最多 64；出生随机半径 0–4；有限绝对坐标；落点必须在主世界内。`maw-arrival.json` 纳入部署冻结清单，修改应走正常维护发布。

## 验证与操作

50 项 Node、13 项 Python、21 项纯 Java 策略断言通过。完整模组隔离服验证了实际 FML 状态、缺少 Numen 及自有客户端组件时的登录、认证前不迁移、认证后的实际落点、重连不重复迁移、远处位置保留、库存与 UUID 保存，以及默认出生点和唯一迁移记录持久化。原有 45 个组件类逐字节保持一致。

测试准备失败记录也保留：首次新世界启动超时，随后发现隔离配置缺少保护配置、超平坦地面的真实高度为 -60。另一次等待注册表的预算不足。反向探针最初用了过长账号名，不能计为模组拒绝证据；修正后观察到原包允许缺少 Placebo 子频道，未为了满足测试而改变原门禁。没有将这些失败计为通过；未声称实机验证了所有不兼容版本的拒绝。

发布须先正常停止常驻控制器和 SAO 服务、核实 Java 退出 0、完成 E/F 全量冷备及成员哈希验证；替换自有 JAR 和 SDK 文件后重新冻结，等待新 JVM 注册表就绪，再恢复原身份的桐人。不要重新运行已消费的维护请求或覆盖当前世界、账号数据库及 Agent 记忆。回退只回退组件和配置，保留发布后新增的玩家数据。

客户端在服务器列表点刷新后重连。受影响的旧平台账号将在本人认证成功后迁到村庄。真实 R2 客户端最终像素画面与真人微软会话仍应由玩家复核；协议实连与保存数据验证不冒充真机 UI 验收。正式发布事实见 `client-spawn-release-20261031.json`。

Forge 的专用服务端显示规则参考：[官方 Sides 文档](https://docs.minecraftforge.net/en/1.20.x/concepts/sides/)。现有服务端专用组件继续使用 `IGNORE_SERVER_VERSION`。
