# 文本来源与发布说明

本目录保存为 My Agent World 编写的简体中文补全，语言键与任务格式来自 `pack.lock.json` 固定的模组版本。原模组的作者、名称、下载地址和许可证声明均保留在锁中；这里不重新授予第三方模型、贴图或模组二进制的分发许可。

Village Quest 的原项目为 <https://modrinth.com/mod/village-quest>；JustQuests 为 <https://github.com/ErikEdits/JustQuests>，作者 ErikEdits。其他来源逐项见锁文件。本目录不保存调用凭据、玩家消息或原模型接口回包。

自有 Java 兼容组件 0.1.1 按 GPL-3.0-only 发布，协议全文在 `../compat-src/COPYING`，全部 Java 源码、生成器中文资源和构建脚本随项目提供；客户端包也附组件源码与协议。JustQuests 的 Modrinth 声明与该发行 JAR 内的许可证字段存在差异，两者没有被修改；构建和索引保留各自原始事实。
