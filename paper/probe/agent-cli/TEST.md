# 精简 CLI 验收计划

只连接标记的隔离服；正式服本轮只读。新候选不等于上线。

- 规则：无参数查询、别名、格式旗标、必填 ID、未知动作、重复/非法页码、动作禁止分页；错误在任何动作之前产生。
- 帮助：同一目录生成根页与具体动作，最多七项；RPG 使用新职业/技能语义，其他功能仍可逐页发现；隐藏停用的学习/升级入口。
- 真实非 OP 客户端：从 status 和 --help 找到规则、六职业、技能、任务、共享补给与个人箱；错误和 --help 不选职、不接任务、不扣物。
- 操作闭环：显式选择职业，查询技能后施放；显式接原生任务、聚焦查进度；任务两页可遍历且 JSON 与文本动作一致。
- 兼容与隐私：progress 的旧分区仍走真实查询，spells/class/quests 可用；结果只发本人；archive 正文中的 --help 不改变写书解析。
- 冷启动：重启同一隔离服，核对职业、任务和原 UUID；不把命令发出当完成。
