# 大肥鱼 · 千灯纪原创 YSM 模型

原创奶白圆鱼、青蓝背鳍、珊瑚尾巴和鼓眼睛，带独立第一人称鱼鳍。
模型 ID：`qd_dafeiyu`；版本：`1.0.0`。

三套贴图是珍珠白 `pearl`、落日金 `sunset`、月海蓝 `moon`。
13 骨骼、139 方块、834 个面，三张 128×128 原创 PNG；显式保持 1 倍比例。
外观约 1.9×2×2 格，不改变正常玩家碰撞箱、视角、移动能力或权限。

## 安装与使用

将 `qd_dafeiyu` 文件夹放到运行 YSM 的 `config/yes_steve_model/custom/`。
也可直接放构建出的 ZIP；不要同时装文件夹和 ZIP，避免重复模型 ID。
这是 YSM 原生支持的开放模型包，不是原版 Minecraft 的资源包。
匹配客户端使用 Minecraft 1.21.1 / YSM 2.4.1，在 YSM 模型菜单中选择“大肥鱼”。

千灯纪已开启稳定扫描，模型文件变化自动重载；其他部署可在控制台执行
`ysm model reload`。`/appearance list` 可查询千灯纪的已验证目录。
服主若明确要给某个在线账号换装，可在受认证的代理控制台执行：

```text
appearance admin set <在线玩家名> qd_dafeiyu pearl
```

`sunset` 和 `moon` 可替换上面的 `pearl`。此管理命令沿用现有
`mandatory=true` 行为；切换前记录原模型、贴图和该标志，不用覆盖在线 NBT 回退。
本次只给独立的 `ag_AuthQA` 测试账号试穿并保留测试外观，未改变真人或 Agent 的现有选择。

## 动作与可编辑来源

`animations/main.animation.json` 包含待机、步行、奔跑、游泳、跳跃、潜行、
受击、睡眠、乘坐、攀爬和普通主副手挥动等状态。
`animations/arm.animation.json` 包含持物、挥鳍、进食、饮用、弓、盾与投掷姿势。
三个轮盘动作 `extra1`、`extra2`、`extra3` 分别为招手、开心摆尾、鞠躬。

`models/*.json` 可按 Bedrock 几何格式在建模工具中编辑；贴图与动画均为开放源文件。
整个模型从头制作，没有读取、解密、复制用户先前上传的加密“大肥鱼_1.1.ysm”的
几何、贴图、骨架或动画。该第三方原包继续单独保留，不纳入本目录或公开包。
本目录原创几何、贴图、动画按 CC0 1.0 发布。

重建需要 Python 3.11+ 和 Pillow，输出目录必须尚不存在：

```text
python build.py <新的输出目录>
```

构建器生成源目录、可重复构建的 YSM ZIP 和逐文件 SHA-256 清单。
