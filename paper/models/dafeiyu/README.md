# 大肥鱼 · 蓝发鲸鱼娘 YSM 模型

当前版本 **1.1.0**，模型 ID `qd_dafeiyu`。按蓝发鲸鱼娘人物形象重新建模：
蓝色渐变长发、蓝瞳、鲸鳍耳、卷翘呆毛、白色女仆发箍、深蓝白女仆裙、
白围裙与水平鲸尾。包含抱饭碗、招手和鞠躬动作。

1.0.0 将名字误解为圆鱼，造型方向错误，已经被本版本替换。
旧包及 `build.py` 只留作历史和公共建模函数，不代表该人物形象。

## 使用

千灯纪 YSM 2.4.1 Worker 已热加载，不必升级游戏或 YSM。
匹配的 Java 客户端在 YSM 菜单选择“大肥鱼 · 蓝发鲸鱼娘”。
`pearl` 为经典蓝白；旧 ID `moon`、`sunset` 保留，分别为深海蓝、浅海蓝，均保持蓝发造型。

其他部署把 `qd_dafeiyu` 文件夹或构建 ZIP 放入
`config/yes_steve_model/custom/`，执行 `ysm model reload`。
文件夹和 ZIP 二选一，不要重复安装同一 ID。这是 YSM 模型包，不是原版资源包。

千灯纪 `/appearance list` 可查目录；服主可在受认证代理控制台为指定在线玩家分配：

```text
appearance admin set <在线玩家名> qd_dafeiyu pearl
```

只用独立测试账号验证，真人和 Agent 的选择保持；外观不改变碰撞、生命、背包、移动或权限。

## 编辑与构建

32 骨骼、180 方块、三张 128×128 贴图；宽度比例 0.92、高度比例 0.88。
几何在 `qd_dafeiyu/models`，贴图在 `textures`，状态与轮盘动作在 `animations`。
`extra1` 招手，`extra2` 抱饭碗，`extra3` 鞠躬；饭碗是外观道具，不向背包发物品。

Python 3.11+ 与 Pillow，使用新构建入口，输出目录必须不存在：

```text
python build_whale_maid.py <新输出目录>
```

生成源目录、确定性 ZIP 和逐文件 SHA-256。模型是立方体风格，不宣称与插画曲面或像素等价。
