# 千灯纪 · FCL 原生手柄预览

适用于安卓 8 及以上的 arm64 手机。推荐 FCL 1.3.4.6，游戏为 Minecraft 1.21.1，运行时选 Java 21。

1. 从 https://github.com/FCL-Team/FoldCraftLauncher/releases/tag/1.3.4.6 安装 FCL。
2. 在 FCL 导入本 .mrpack，建立独立实例，运行时选择 Java 21。首次需联网下载游戏、NeoForge 和模组。Control Flex 从作者的 GitHub 下载，其余游戏模组从作者的 Modrinth 下载。
3. 启动游戏 → 多人游戏 → 千灯纪 · 主世界。沿用本人原角色名和游戏密码；不新建替代角色，也不用为真人客户端提供模型 Key。
4. 首次允许 FCL 使用麦克风，在触屏键盘按 V，完成语音向导及麦克风/扬声器自测。麦克风应为 Android AudioRecord。默认按键说话且静音；按本人意愿选择语音激活，或给触屏增加“按键说话”绑定。

进服地址已预置：micro.kangqiang.site:25702。服务器资源包已允许。女仆与玩家模型从原生模组/服务器同步，不需要下载其他人的私人模型或账号文件。

## 手柄

先在安卓系统通过蓝牙或 USB 连接手柄。启动整合包，在 FCL 游戏侧栏的「手柄」里启用「手柄控制」，将「手柄输入模式」设为「SDL 直通」。

Control Flex 在游戏内读取摇杆和按钮。预置的千灯纪服务器地址启用连续模拟移动，轻推和全推摇杆的速度不同。先试左摇杆移动、右摇杆转头、左扳机打开手上的技能罗盘。按键可在游戏内的 Control Flex 设置调整，背包和聊天也可用触屏。

这版含 Control Flex 0.8.9-beta.3。手机上的手柄识别、摇杆手感和重连还需实测。

## 第一次游玩

右键罗盘使用技能、查看状态和补给；右键自己的女仆进行原生交互。
聊天输入 /appearance status 查看形象，/mycli help 查看玩法，/voice status 查看语音接收状态。
屏幕按键至少保留移动、跳跃、右键、潜行、背包和聊天。先使用包内的 6 区块视距与 60 FPS 上限，再按手机性能调整。

## 语音兼容预览

此包已配置 SVC Java 编解码回退与安卓音频桥。Android Audio Shim 的独立 MIT 原生库保持原字节；千灯纪补充 NeoForge 元数据和 FCL 私有目录加载。
上游 SVC 官方不提供安卓售后支持，社区已有安卓实机适配证据。本包尚未在你的手机完成麦克风、耳听、附近距离和公网语音全链路验收；不能把安装完成当成语音已经畅通。
Java 回退不启用原生降噪、自动增益和 SVC 录音；普通语音收发与位置音频需按下述步骤确认。

有画面但听不到：完成 V 菜单向导、检查静音/输出设备；用 /voice status 看当前状态。
能听不能说：在安卓设置允许 FCL 麦克风权限，检查输入设备、按键说话/语音激活设置与静音。
语音显示断开：游戏 TCP 登录和语音 UDP 是两条链路，管理员需检查公网 UDP24454；重复登录游戏不能证明语音端口可用。
耳机不稳定：先用手机扬声器/有线耳机区分蓝牙双向音频问题。

遇到异常请提供 FCL 版本、手机型号、Android 版本、语音设置页状态及不含密码的错误行。不要发送账号密码、模型 Key 或私人录音。

## 更新与回退

以后从千灯纪官网下载新版，仍导入独立实例；角色、背包和成长在服务器中，不需要重建身份。
保留自己原来的电脑或手机实例。退出本实例再使用原客户端即可；不要让两个客户端同时登录同一角色。
