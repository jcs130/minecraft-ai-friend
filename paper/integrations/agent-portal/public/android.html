把千灯纪装进口袋

在 FCL 游玩千灯纪主世界，使用女仆、YSM 角色形象和附近语音。适用于安卓 8 及以上的 arm64 手机，原生手柄包推荐 FCL 1.3.4.6。

下载原生手柄预览包

四步进入主世界

  1. 安装 FCL。从 FCL 官方发布页下载 APK。
  2. 导入整合包。在 FCL 选择“导入整合包”，打开下载的 .mrpack，建立独立实例，运行时选择 Java 21。首次联网下载游戏与模组。
  3. 进入千灯纪。启动游戏，在多人游戏里选择预置的“千灯纪 · 主世界”。已有角色沿用原角色名与游戏密码。
  4. 设置语音。允许 FCL 使用麦克风，在触屏键盘按 V，完成语音向导与麦克风、扬声器自测。默认静音；按本人意愿选择语音激活，或给触屏增加按键说话按钮。

主世界地址：micro.kangqiang.site:25702。这个包使用 Minecraft 1.21.1；下载页另列的 SAO 1.20.1 属于另一个服务器。

已经配好什么

原生女仆模型与界面、YSM 角色形象、Simple Voice Chat 及安卓音频适配，连同中文界面、服务器地址和手机画质设置一起提供。先用 6 区块视距和 60 FPS 上限，再按手机性能调整。

右键罗盘查看技能、状态和补给；右键自己的女仆进行交互。聊天输入 /mycli help 查看玩法，/appearance status 查看角色形象。

真人游玩不需要填写模型 Key。保留原客户端和角色，换手机也不必重建身份。

原生手柄

  1. 在安卓系统通过蓝牙或 USB 连接手柄，启动「原生手柄预览」实例。
  2. 打开 FCL 游戏侧栏，在「手柄」里启用「手柄控制」，将「手柄输入模式」设为「SDL 直通」。
  3. 用左摇杆移动、右摇杆转头。拿起技能罗盘后用左扳机打开。预置的千灯纪地址启用了连续模拟移动，可以试试缓慢推杆。

在游戏的 Control Flex 设置里校准摇杆和调整按键。背包、聊天和语音向导也可以用触屏。

预览版使用 Control Flex 0.8.9-beta.3，手机上的手柄识别、摇杆和重连仍待实机验证。

附近语音兼容预览

安卓语音已有社区适配方案，本包已准备对应配置。千灯纪这套手机版仍需在真实手机上确认听说效果，当前标为兼容预览。

听不到声音时，先完成 V 菜单向导并检查输出和静音；不能说话时，检查安卓麦克风权限，输入设备应显示 Android AudioRecord。输入 /voice status 可查看收听状态。

如果游戏正常而语音显示断开，请把状态告诉管理员。手机语音使用独立网络通道，反复登录游戏通常不能解决。

更新时导入新的独立实例，沿用原角色。角色、背包和成长保存在服务器中；回退时退出当前实例，再使用原客户端。
