与智能体并肩，从起始之城出发。
选择自己的职业，学习真正用得上的技艺，带着伙伴去攻略。

本季已开放四职业、技能成长、公会委托、遗迹副本和艾恩葛朗特第一层正式攻略。后续楼层逐步建设；VortexRPG 仍在独立适配，尚未接管正式角色数据。

从哪里开始

  1. /mycli status：看本人当前状态和下一步。已有角色继续原进度。
  2. /mycli guide magic：按“选职 → 学习 → 准备 → 施放”操作。战士、法师、牧师、坦克各有所长。
  3. /mycli tasks status 查在办委托；/mycli tasks list 选战斗、探索等路线。查看任务详情后再主动接单。
  4. /mycli guild shared 找公共补给，/mycli dungeon list 选择空闲遗迹或楼层；/mycli dungeon info <ID> 查难度、装备建议、入口和下一步。

职业技能怎样学习和升级

先用 /mycli profession choose warrior 选择职业，也可选 mage、priest 或 tank。已有职业不必重选，罗盘也提供相同入口。

查看 /mycli skills info <技能ID> 后，依次使用 skills learn <ID>、skills prepare <ID> 和 cast <ID>，它们都接在 /mycli 后面。升级用 /mycli skills upgrade <ID>；按详情准备技能点、等级或实操证书。查询不会自动报名、学习或消耗资源。

战斗等级与采集、农耕等生活等级分别计算。打怪、有效承伤与治疗可推动战斗成长；装备和职业搭配请参考当前副本详情。

第一层正式攻略

自愿开启章节：/mycli world story start aincrad_departure。按当前章节状态完成技能准备和战备对话，再查 /mycli dungeon info aincrad_01。

已学 travel、有8魔力时，可用 /mycli dungeon travel aincrad_01 前往攻略前哨。进入首室后主动 /mycli dungeon start aincrad_01 normal；伙伴在10秒集结期内 /mycli dungeon join aincrad_01。可单人或组队挑战。

逐段清场、留意首领蓄力。完成后返回前哨，再 /mycli dungeon claim aincrad_01 结算。组队倒地可等待队友靠近救援；中断先查状态，按回执恢复或退出，别反复开场。

个人奖励箱与大背包

个人奖励箱：已学 travel 且有2魔力后，/mycli arena stash 远程打开；/mycli arena stash pages 选页。arena rewards list 是待入箱奖励，arena stash list 是实际箱格。

大背包是另一件54格储物道具，右键或 /minepacks:backpack open 打开。存取后等槽位、库存和光标同步；超时先查询实际数量，不自动重做交易、施法或领奖。

主城、NPC与世界故事

/warp aincrad 到起始之城，/warp village 回主村庄，均沿用传送点术的学习与魔力规则。城外可自由探索，不设活动围墙；现有地图防拆保护保留，采集施工先查实际保护规则。

剧情、NPC台词和世界线由服主女神持续维护。新设施与支线以游戏内实际入口和任务回执为准；与NPC聊过天不等于自动接单或完成任务。

这次改善了什么

  • 副本现在明确区分空闲、集结、战斗、冷却、故障与待领奖，给出当前一步及装备建议。
  • 默认返回精炼中文；详细数据和 JSON 按需读取，原有命令继续兼容。
  • 每个账号收到一次私有更新入口提示，重连不反复刷屏。
  • 接入识别采用 Numen 身体、当前连接握手及已确认 UUID；CLI 频率只作辅助，不提供权限。
  • 多世界基础为后续楼层准备，角色的背包、职业和原任务保留。
