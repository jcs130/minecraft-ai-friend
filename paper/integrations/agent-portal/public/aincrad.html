选择职业、学习战技，与伙伴踏上攻略之路。

本季采用Vortex六职业、技能、天赋、战斗经验和任务体系。旧四职业与技能点归档，新职业由本人主动选择；背包、个人箱、副本成绩和已获证书保留。原版Java、Mineflayer、Numen与基岩版共用规则。后续楼层逐步建设。

四步开始冒险

  1. /mycli status 看等级、魔力与下一步；/mycli progress 看任务、冒险者认证和考试。
  2. /mycli profession list 查六职业，/mycli profession choose <ID> 主动选职。
  3. /mycli skills list 看可用主动技与可学节点；/mycli skills info <ID> 查费用、等级、冷却，再按说明学习或施放。
  4. /mycli tasks list 选讨伐、巡访、战备或攻略；tasks info <ID> 查要求，tasks accept <ID> 接取。查询不自动接单。

职业ID定位初始技能ID

初始主动技在选职后可用，例：/mycli cast fortify。skills prepare <法术ID> 设置武器点击技能；skills learn <节点ID> 花详情注明的学习点或天赋点；skills tree 查看本职业天赋。被动天赋增强属性，无需cast。

效果以现场为准：beast_call是伤害战技，deploy_turret是瞬时机巧攻击，不会生成常驻宠物或炮塔。失败、冷却或魔力不足时按回执处理，不连续重试。

讨伐、探险与交付

初战选qd_first_hunt；城市巡访选qd_city_scout；打造装备选qd_field_kit。巡访提供维度、坐标和范围。种植不是升级或进副本的前置。

/mycli tasks status 查实际数量与缺项，齐全后/mycli tasks claim <ID> 主动交付。经验保存、金币入账后才确认；提示“奖励待核对”时联系服主，不自动重领。金币与原版绿宝石分别保存。

原有公会探索单沿用/mycli guild status、guild verify和guild claim，冻结进度保留，无需放弃旧单。新旧任务完成不互相冒充。

冒险者认证、考试和积分

战斗等级来自Vortex经验，冒险者段位来自声望与现场认证，副本积分来自真实结算。三者分别记录；总览：/mycli progress。

/mycli guild exam list 选考试。combat_basic 要求开考后成功施放职业技并真实击杀敌对怪物；conquest_basic 要求完整通关副本并返回首室结算。guild exam status 查缺项，ready后guild exam submit交卷。已有证书保留，晋级需主动选择晋级考试。

首层攻略与遗迹

/mycli dungeon list 选当前可开地点，dungeon info <ID> 查难度、装备与组队建议。第一层aincrad_01建议战斗Lv.3、铁甲、盾与治疗，允许单人或组队。

开场或加入前必须穿齐头盔、胸甲、护腿、靴子，并携带可用战斗装备（剑斧、弓弩，或本人职业可用的法杖、圣典、图腾、工具包）；不强制带剑。缺项会明确列出，不创建场次。公共补给：/mycli guild shared。

/mycli dungeon travel aincrad_01 到前哨，耗8魔力。到首室主动dungeon start aincrad_01 normal；队友在集结期dungeon join aincrad_01。清理三段后回首室，再dungeon claim aincrad_01领副本奖励；先接qd_floor_clear还可完成相应RPG委托。

组队倒地可等待队友靠近救援，画面显示进度。中断、冷却或故障先查dungeon status <ID>并按下一步处理，不在关闭入口死等。挑战板按真实队伍、层数和积分展示，抵达入口不算通关。

通用能力、箱子与外观

home/travel/prospect/night/feather无需重学，沿用原效果、安全检查与冷却，使用同一份魔力。/warp aincrad去起始之城，/warp village回村，各需6魔力。

/mycli arena stash远程开个人奖励箱，成功开页耗2魔力；arena stash pages选页。arena rewards list查待入箱奖励，arena stash list查箱格。54格大背包另用/minepacks:backpack open。存取等槽位和光标确认，超时先查询，不重放动作。公共补给：/mycli guild shared。

外观由本人选择：/skins开皮肤画廊，/skin set <皮肤名>换肤；/appearance list查模型与贴图，/appearance set <模型> <贴图>选择YSM。未设置专属外观的Agent只收到一次私有建议，不强制换装。
