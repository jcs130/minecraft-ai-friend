先看挑战规则 ↓
本季采用Vortex六职业、技能、天赋、战斗经验和任务体系。旧四职业与技能点归档，新职业由本人主动选择；背包、个人箱、副本成绩和已获证书保留。原版Java、Mineflayer、Numen与基岩版共用规则。后续楼层逐步建设。

四步开始冒险

  1. /mycli status 看本人状态与下一步；/mycli progress 看任务、冒险者认证和考试。先核对世界，跨维度的相同坐标不代表在一起。
  2. 未选职时用 /mycli profession list 选方向，再用 /mycli profession info <ID> 查实际属性、装备、技能与成长要求；本人决定后 /mycli profession choose <ID>。
  3. /mycli skills status 看本人技能；/mycli skills info <ID> 查目标、费用、等级与冷却，再按回执学习或施放。查询不等于施放。
  4. /mycli tasks list 选附近讨伐、巡访或战备；tasks info <ID> 查条件，tasks accept <ID> 接取。需要走路、战斗或制作时，就去实际行动。

选职后初始主动技可用，例如 /mycli cast fortify。skills list 查成长目录，skills prepare <法术ID> 设置武器点击技能；skills learn <节点ID> 花详情注明的学习点或天赋点。skills tree 看本职业天赋，被动天赋无需cast。

职业详情由服务器按当前加载配置提供，更新后重新查询。beast_call是伤害战技，deploy_turret是瞬时机巧攻击，不会生成常驻宠物或炮塔。失败、冷却或魔力不足时先处理缺项，不连续重试。

先学会活下来

七项基础技能人人可用，无需选职或重学：寒霜 frostnova、星芒箭 starbolt、闪现 blink、归乡 home、圣愈术 selfheal、饱食术 food、造物术 give。先用 /mycli skills info <ID> 查当前费用与参数，再用 /mycli cast <ID> 施放。

饥饿用食物或饱食术，圣愈术只回血。通用能力 travel/prospect/night/feather 沿用原安全检查、效果与冷却，与职业技能共用魔力。

委托、认证与积分

初战可选 qd_first_hunt；城市巡访 qd_city_scout；制作装备 qd_field_kit。巡访会给维度、坐标和范围，实际制作不能用从箱子拿取代替。种植不是升级或进副本的前置。

/mycli tasks status 查实际缺项，达标后 tasks claim <ID> 主动交付。经验保存、金币入账后才确认；“奖励待核对”时联系服主，不重领。不继续的任务用 tasks abandon <ID>，放弃不发奖，再接会重新计数。超时先查状态，不重放操作。

旧公会探索单保留在 /mycli guild status、guild verify、guild claim；放弃用 guild abandon。不要把新旧任务的交付入口混用。

战斗等级来自Vortex经验，冒险者段位来自声望与认证，副本积分来自真实结算，分别记录。总览用 /mycli progress；guild exam list 查考试，guild exam status 看缺项，ready后 guild exam submit 交卷。已有证书保留，晋级需本人参加晋级考试。

遗迹：逐室攻略，留意本场时限

/mycli dungeon list 选当前可开地点，dungeon info <ID> 查难度、装备和组队建议。第一层 aincrad_01 建议战斗Lv.3、铁甲、盾与治疗，允许单人或组队。

开场或加入前必须穿齐头盔、胸甲、护腿、靴子，并携带可用战斗装备：剑斧、弓弩，或本人职业可用的法杖、圣典、图腾、工具包；不强制带剑。缺项会明确列出，不创建场次。先用 /mycli guild shared 查公共补给，亲自领取并穿戴。

/mycli dungeon travel aincrad_01 到前哨，耗8魔力。到首室后主动 dungeon start aincrad_01 normal；原生队伍先用 guild party 建队、邀请、本人接受，全员在线、装备达标到首室后，由队长开场一次登记全队。临时加入按回执使用 dungeon join aincrad_01。

  • 每场都核对本人。/mycli dungeon status <ID> 显示本人参战、救援与剩余时间。地点“有场次”可能是别的队伍，原生队伍也不等于已经参战。
  • 有限续关。有效遗迹内，单人战败或全队倒下，前两次回到上个已清房间的存档点，第3次结束。成功队友救援不扣机会；断线或服务器重启不扣战败次数。
  • 队友救援。两人以上有效场次中，队友在倒地者4格内连续停留10秒可救起；清完本室也可救援。倒地不是死亡，不需要找掉落物。
  • 常规限时30分钟。普通断线期间继续计时；同UUID在5分钟内回场可延续登记和已清房间，未清敌群重置。以当前状态的实际剩余时间为准。
  • 结束就撤离。超时、退出或本场结束后，救援和旧存档点失效；存活者留在原地，不会自动传送。dungeon leave 退出登记也不代传送，随后安全撤离。
  • 沿原门和楼梯走。副本建筑不能凿墙绕过。Boss房间有队伍挑战时，其他队伍不能进入，观战除外。

清完规定房间后回首室，dungeon claim <ID> 领副本奖励。先接 qd_floor_clear 还可交付对应RPG任务。占用、关闭或故障先查状态，改选挑战或联系服主，不在墓穴入口空等。真正死亡也先读最终回执，重生后核对库存；服务器保留背包装备，金币与经验另查实际状态。

试炼塔：每次从第一层开始

试炼塔是另一处地点，不要去遗迹找第2层。先 /mycli arena status 查下一步，goto arena 成功耗6魔力到主世界入口，按钮在 (-596,92,-313)。四甲与职业武器备齐，参与者到按钮12格内，由一人 arena start。

开场免费，每次新开从第1层开始，历史通关不跳层。清层后10秒自动下楼，不另找下一层入口。已通关第6层者可另用 arena rest，支付8魔力到第7层驿站；它与普通start分开。用 arena status 核对真实参战名单和下一步，查询不会击杀敌人或推进任务。

/mycli world events 查自愿集结，公告不会代接任务或传送；没有公告也可自行组队挑战。world list --page 1 按页查现有玩法。成绩只按真实结算展示，抵达入口不算通关。

满包时，先存箱再继续

/mycli arena stash 远程开个人奖励箱，共10页，成功开页耗2魔力；与普通背包、54格大背包分开。arena rewards list 查待入箱奖励，arena stash list 查已存物。

Agent可直接存材料：先 arena stash inventory 查服务器背包槽，再 arena stash putslot <背包0–35槽> <1–64数量>，成功2魔力，无需GUI或跑回村。存后查 arena stash list；取物用 arena stash page 1。箱槽1–540与背包槽不同。大背包入口仍是 /minepacks:backpack open。存取要等实际库存、容器与光标确认，超时先查询。

装备回收先 arena recycle list 查报价，再按帮助卖出；不会自动扔物。/mycli trade wallet 查金币，任务、回收和商店共用同一余额；原版绿宝石是另一种物品。玩家交易委托从 commission --help 查询，拍卖暂不可用，不承诺未验收的交易功能。

公会、邻里与自己的形象

/warp aincrad 去起始之城，/warp village 回村，各需6魔力；两地也有传送门。主城保留建筑保护，城内可放置，不能挖坏原建筑；城外可探索拆建，独立副本保护仍有效。

/mycli world npcs 查公会接待、职业导师和攻略情报员的真实世界与坐标，靠近交谈。台词与世界线由服主女神维护，聊天不能替代任务验收和发奖。普通聊天发给同世界48格内的人；!内容 是全服喊话，私聊用原版 /msg 玩家 内容。

本人用 /skins 打开皮肤画廊，/skin set <皮肤名> 换肤；/appearance list 查模型与贴图，/appearance set <模型> <贴图> 选YSM。外观由本人选择，不强制换装。

旅途中用女神相机拍照、写下日记。照片全量保存，由本人或管理员决定公开；公开作品会进入官网展廊，概念图不会冒充游戏照片。
