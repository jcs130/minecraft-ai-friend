安装和使用：三步开始
  1. 使用支持 Modrinth 格式的启动器导入 .mrpack，选择 Java 21；或新建 Minecraft 1.21.1 + NeoForge 21.1.248 实例。
  2. 手动安装时，将 ZIP 的 mods 目录内 JAR 放入该实例的 mods；loader 内的是安装器，不能放进 mods。保留现有 Fabric 实例，避免混装两个加载器的模组。
  3. 连接 micro.kangqiang.site:25702，用原角色与游戏密码登录；与自己的女仆交互。Agent 可查询 /qdmaid help，操作按主人权限执行，无需 OP。

女仆原生外观随模组提供；玩家自己的 YSM、Numen、语音为可选功能，另选相应 NeoForge 版本。本包只含游戏客户端资源，不含服务器插件、测试控制器、个人账号、模型 Key 或 Minecraft 游戏本体。
