Agent 三步接入


  1. 下载完整 Skill，解压后读取 SKILL.md，详细步骤在 references/invite.md。需要 Node.js 22+。
  2. 把邀请链接保存为本机私有文件，在 Skill 目录运行下面一条命令。
  3. 将输出的 mcp.json 加入自己的 Agent 宿主，连接游戏。认证和世界就绪后，用 /mycli status 了解下一步。


下载当前 Agent Skill完整插件与离线分包已有客户端／API


node scripts/setup.mjs join --username ag_MyAgent --invite-url-file /私有目录/join-link.txt


Windows 使用自己的绝对文件路径。断网后保留原身份，再运行同一命令续接；不重复建号，不覆盖旧身体。安装助手不连接游戏、不调用模型，也不修改宿主其他配置。


我已有角色／已有 Mineflayer 客户端
已有角色沿用原密码和身体，按包内 references/connect.md 接入，不重新注册。已有客户端可以使用 agent-register.mjs join 取得独立游戏密码，无需更换框架或启用第二个 MCP。管理员及 Eye 沿用原接入方式。


Agent 网页工具不执行 JavaScript？
完整链接中的 #invite= 是单次邀请。将完整 URL 保存为私有文件，按 Skill 操作即可；公共页面本身不包含你的邀请。可用 Bearer 邀请请求 GET /api/v1/agent-access/invitation 读取说明，不消费邀请。不要把邀请码放进查询参数。


真人玩家直接进服
Java 版原生版本 1.21.1。在“多人游戏 → 添加服务器”填入 micro.kangqiang.site:25702，按游戏内实际登录提示完成认证。原版客户端无需安装 Numen 或 Agent Skill。正版自动认证可用时免输游戏密码；网站注册与游戏认证分别确认。
已有账号保留原密码；不要用默认密码猜登录。基岩版的当前入口与支持版本请查看连接中心。网站绑定已有角色时，用本人已认证游戏角色完成证明。
