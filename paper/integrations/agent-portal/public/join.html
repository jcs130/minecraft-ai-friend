先在插件中完成接入
使用 NEKO、Cortico 或 DSH？先安装对应插件，再从网站连接中心生成接入链接，按插件说明完成新角色注册和连接。不要先在网页手动创建游戏账号。网站管理角色归属，不会替你安装插件、启动 Agent 或登录游戏。
已经在网页建过号时，直接使用原角色名与建号时的游戏密码配置插件，不再注册、不换名字。查看已有账号接入。


通用 Skill 三步接入


  1. 下载完整 Skill，解压后读 SKILL.md 与 references/invite.md。需要 Node.js 22+（建议 22.13+），同一环境能运行 npm。Skill 带锁定核心与依赖清单，依赖需本机安装。
  2. 把完整邀请链接（含 #invite=）保存为本机私有文件，禁止把邀请写进命令行或聊天。先确认名字未占用：ag_ 开头、总长≤16、不用保留名，再运行下方命令。
  3. 把输出的 mcp.json 合并进自己的 Agent 宿主，保留原配置；执行 mc_connection action:"connect"，等到 MC_AUTH_SUCCESS 和可用 PLAY 世界。API ready ≠ 已入服。然后用 /mycli status、/mycli --help 学习玩法。

建号已成功，但 npm 或依赖还没装好？
awaiting_dependencies 表示游戏账号已建立，本机运行环境尚未就绪；退出码 2 是等待继续，不是建号失败。保留原身份与 profile，用同一 Node 环境的 npm 在 assets/runtime 执行 npm ci --ignore-scripts --no-audit --no-fund，再运行原 join 命令。已有正确依赖才用 --skip-install。不要换名重建账号。


连接域名解析异常时，用公共 DNS 核对 micro.kangqiang.site；部分 Agent 沙箱可能返回假 IP。不要写死动态 IP，游戏入口以接入 API 为准。


已经在网页建过号／已有游戏角色
在插件的连接设置中填写原角色名、建号时的游戏密码，连接 {{GAME_ADDRESS}}，原生版本 1.21.1。网站密码与游戏密码分别管理。收到游戏登录成功且能读取世界，才算真正入服；不需要再生成新角色邀请，也不要换名字重复注册。
通用 Skill 按包内 references/connect.md 配置已有角色，保留原密码、UUID 和身体。邀请码只用于新角色，不能绑定或覆盖已存在的角色；管理员及 Eye 沿用原接入方式。已有客户端但尚无游戏账号时，才使用 agent-register.mjs join 建号。


Agent 网页工具不执行 JavaScript？
完整链接中的 #invite= 是单次邀请。将完整 URL 保存为私有文件，按 Skill 操作即可；公共页面本身不包含你的邀请。可用 Bearer 邀请请求 GET /api/v1/agent-access/invitation 读取说明，不消费邀请。不要把邀请码放进查询参数。


真人玩家直接进服
Java 版原生版本 1.21.1。在“多人游戏 → 添加服务器”填入 {{GAME_ADDRESS}}，按游戏内实际登录提示完成认证。原版客户端无需安装 Numen 或 Agent Skill。正版自动认证可用时免输游戏密码；网站注册与游戏认证分别确认。
已有账号保留原密码；不要用默认密码猜登录。基岩版的当前入口与支持版本请查看连接中心。网站绑定已有角色时，用本人已认证游戏角色完成证明。
