# 千灯纪遗迹秘宝与入场指引

在罗盘的「冒险与任务 → 遗迹地下城」选地点。地点卡上能看传送入口、遇敌提示、房间路线、专属秘宝以及个人奖励。传送后沿实体路标到石钮，使用键打开同一张卡，选择难度。原版格子菜单也可用手柄操作。站到首室，穿齐四件护甲，带近战武器和可用远程武器；场地按原有资格机制登记参战。

主题装备采用区域专属掉落思路，通关目标与下一步集中在同一张卡。试炼塔单独展示登顶保底，遗迹每个角色首次核实终室参战且通关时保证获得专属秘宝。难度决定首次装备的原版附魔级别，刻印效果在结算时确定。 [Monumenta 区域专属稀有装备](https://monumenta.wiki.gg/wiki/Items) · [Wynncraft 内容手册更新公告](https://forums.wynncraft.com/threads/2-0-3-full-changelog-lootrun-reworks-more.308462/) · [Hypixel 可查询保底进度](https://hypixel.net/threads/hypixel-skyblock-patch-notes-0-20-1-chocolate-factory-hoppity%E2%80%99s-hunt-and-more.5645591/)

剑和斧有命中被动、使用技能和潜行使用技能，实际组合查看装备说明。普通攻击照常，主动用剑斧时副手留空。持弓弩潜行并按使用键施放刻印，普通射击照常。盾装主手或副手，站立持续按使用键格挡，实际挡住敌怪攻击才触发被动；潜行并按使用键施放盾牌主动技能。主动技能共用现有消耗、作用范围与冷却。手持普通盾靠近附魔台，潜行使用附魔台可选择坚壁、回潮、流风或熔卫，费用为 9 级原版经验和 3 个青金石。

从地点卡点「领取奖励」，再点「打开个人箱」取装备。秘宝收藏按不同遗迹计数，收录 1、5、10、15 件时分别显示「遗迹先行者」「遗迹巡行者」「十境寻迹者」「群境开拓者」。普通参战奖励仍按地点每日结算。已有实例、战利品和旧待领凭据继续可用，旧记录保持原装备内容。

## 运营与兼容

秘宝以角色 UUID 和地点 ID 去重。服务端把具体物品放进原场次的奖励凭据。领取时物品、收藏和凭据消费在同一次持久提交，队列不足时凭据保留。历史凭据没有秘宝字段时按老路径读取。新版本生成待领取秘宝后，回退前须保留能识别秘宝字段的领取路径。

Agent 用现有 `dungeon info --json` 查看 `relic`、`collection`、终室与入口坐标，装备被动和主动 ID 通过原状态频道的 `equipmentEffects` 回传。十五处入口及现有墙体保护沿用已部署的方块和事件配置。两处地下直达使用独立入口数据，不更改战斗定义、旧检查点签名或地图。

候选已在 Youer 隔离服核对十五个地点、三档装备和 180 次物品保存回读。黑旗林营的开场、两段出怪、领盾、重启去重及主手／副手格挡和施法通过实测。候选仍需随正常维护发布，基岩真机和实际 Eye 客户端的画面待联测。本批沿用入口附近的实地路标，遗迹之间的长距离道路另需核验地形和通行。
