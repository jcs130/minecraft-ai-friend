## 玩家怎么连接

| 身份 | 连接方式 |
| --- | --- |
| 新正版账号 | 本人的正版启动器在线验证，免服务器密码。不能只把离线启动器名字改成正版名 |
| 小鱼 `LittleFish0510` | 已关联官方正版身份，直接正版重连；原离线存档 UUID、OP、背包和领地保留，无需 `/login` |
| 其他已有离线身份的正版玩家 | 首次绑定仍需先用原密码登录，再 `/premium 当前密码`，按提示正版重连；服主也可核验后关联原账号。不要重新注册或迁移存档 |
| 普通离线 Agent | 已登记者仍用自己的密码，本轮临时值为 `/login 123456`；任务只在 `[MC_AUTH_SUCCESS]` 后开始 |
| 对应本体的 Eye | 本体先登录进入世界，再连接 `名字_eye` 或 `名字eye`；Eye 无需密码，自动进入旁观者模式。本体退出、配对变更后关闭观战连接 |
| 离线管理员、Goddess、独立 `live` | 仍用原独立密码或既有接入规则；没有因名字含管理员称号而自动放行 |
| 基岩玩家 | 原 Geyser/Floodgate Xbox 验证入口保持 |

本体刚登录后，等认证状态发布再启动 Eye，通常数秒内；本体尚未成功在线时会说明下一步。现有显式别名优先（例如 `CortiLan → CortiEye`），来源专用限制仍由原网关处理；默认后缀配对不比较 IP。自动 Eye 不能借用 Goddess/保留管理员名，也不把 Eye 当成本体继续套娃。

离线账号改密码：`/changepassword 当前密码 新密码`。离线管理员新密码至少十六位；正版免密依赖官方登录会话，微软账号密码在微软账号页面管理。既有本机交付凭据文件不是实时密码库，玩家在游戏内改密后可能已与该文件不同，不能据此覆盖玩家新密码。

## 如何保证身份正确

LibreLogin 要求已绑定正版名字完成官方加密和会话验证。LoginGuard 在 LibreLogin 重写存档 UUID **之前**保存已验证的官方 profile，并在 PREMIUM 认证回调核对：真实在线模式、原始官方 UUID、数据库绑定 UUID 均一致。名字查询只用于关联，不能当作登录证明；IP 会话自动登录仍关闭。

旧密码错误锁定不能拦截已绑定的正版会话；此分支强制官方验证，离线冒名仍拒绝。离线管理员继续保留独立密码证明，缺失认证服务/错误等候区监听仍关闭新登录。

Eye 使用原配对表，要求对应本体实际已认证并在 `paper` 后端。服务器通过 LibreLogin 授权接口结束等候，原 CortiEyeMirror 给予旁观者与只读镜像；每秒重查本体及当前配对。本体失效即撤销连接。客户端不能只收到 `spawn` 或 `[MC_AUTH_EYE]` 就启动任务。

`mineflayer-login-gate.mjs` 对短暂登录提示保留十秒自动登录等待；新 Eye 的 REGISTER 提示也等待服务器结果，不自动注册、不发送空密码。仍只认完整私有 `[MC_AUTH_SUCCESS]`，普通新玩家 REGISTER、错误密码与拒绝立即失败。远端若接入旧门禁模块，需要更新这份模块；本次没有修改另一台电脑的启动代码。
