# Java 与基岩局域网发现

用户目标是在同一家庭网络的客户端列表看到「千灯纪」，不必输入地址。

## 现有入口和本次候选

- 基岩沿用现役 Geyser 的 NetherNet LAN：UDP7551发现、19134会话传输，以及原RakNet19132。2026-11-10正式回读发现v7、协议2225/26.62及HTTP元数据均正常，不修改Xbox验证、身份密钥或现有LAN规则。详见原基岩发布记录。
- Java 补独立广播服务，公布现有家庭Java入口，不安装或在线替换游戏插件。复用已有 `paper/probe/mcstatus.mjs` 的运行副本核对家庭认证入口与游戏后端；目标不可用、维护中或健康结果过期时停止广播。
- 协议参考 [BetterLANBroadcaster](https://github.com/myxxr/BetterLANBroadcaster)，每1.5秒发往224.0.2.60:4445，TTL=1，固定使用明确家庭网卡。客户端使用原生发现功能，无需为发现功能加模组。

Java服务通过新独立SYSTEM计划任务启动，开机及分钟守护，单实例；关闭聊天窗口不会结束它。仅增加当前Node、家庭本机地址、UDP4445至固定多播地址的出站规则。已有入站、游戏与登录规则保持，不新增公网映射，也不替换登录路径。

## 验证与发布边界

五项回归覆盖原生发现字段、端口/标题/网卡校验、目标失效与过期抑制、并发健康合并和真实回环UDP接收；不会在隔离测试中往正式LAN广播虚构服务器。`--check` 仅做实际状态探测，不启动广播。注册程序先检查家庭地址、Minecraft状态和未占用的任务名，再创建独立任务。

本说明初始为候选。正式安装后必须另存计划任务、实际多播接收、正确入口状态及基岩发现回执；同机协议探针不能替代手机/Xbox或另一台Java客户端的实际列表/登录验收。路由器AP隔离、客户端本地网络权限及VPN仍需按真实设备结果区分。

回退仅停止并删除本次独立任务及精确命名的出站规则；保留游戏、账号、世界及原有Geyser LAN能力。
