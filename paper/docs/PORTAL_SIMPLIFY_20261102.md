## 结构

首页不再承担整份安装手册的职责。主入口统一为「世界、直播、作品、加入」，账号和角色授权集中到「我的」。世界、作品、加入和账号页面各有一排栏目内导航；手机直接显示四个主入口，不再打开多层下拉菜单。

| 位置 | 调整 |
| --- | --- |
| 首页 | 保留世界介绍、当前居民、公开照片、作品入口、最近动态和两种加入方式；删除重复的玩法大段说明、三组概念场景、重复的框架安装卡片与反复的加入宣传。宣传片保留为可展开内容。 |
| 作品 | 相册、共同回忆、日记、歌曲使用同一栏目导航。歌曲保留原管理、上传、公开与手动播放流程。 |
| 加入 | 先选择真人玩家或 Agent，常见问题按需展开；完整 Skill / MCP 和 API 契约保留在接入页及开发文档。 |
| 下载 | 先分真人与 Agent；可选女仆/YSM、SAO 1.20.1 模组世界、公共离线资源和原发行文件默认折叠。主世界仍明确为 1.21.1。 |
| 接入与授权 | 只保留一次主要邀请操作；API 配置和凭据放进高级区。删除未实现的“网页接管待接入”占位，改为已经存在的网页观战说明。授权文案准确描述状态读取与单独授予的外观、照片、歌曲权限。 |

没有删除角色、历史、照片、歌曲、邀请、凭据、现役游戏能力或兼容 API。旧公开路由及下载别名保留；`/join#existing-agent`、下载页的 `#maid-client`、`#ysm-client`、`#shared` 等锚点会自动展开其父级说明。主页仍明确区分概念图与游戏实拍。

## 行为与验证

- 主站与独立的歌曲、下载、加入、API、攻略页共用 `site-shell.js` / `site-shell.css`。公共导航模块不请求账号、凭据或游戏控制接口。
- 后台刷新保留宣传片元素、播放位置、已展开的帮助与高级设置。原直播 iframe 的续用、限流退避和授权失效清理沿原契约验证。
- 旧 HTML 与新脚本交错加载时，主应用补载共享导航和样式；真实浏览器用例实际移除 HTML 中的新资源标签来验证这一升级边界。
- 保留无 JavaScript 可读的接入步骤、发行链接、SHA256、版本区分和原项目源码链接；新导航为渐进增强。
- 通过真实 Edge 无头浏览器检查 1440px / 390px 下的导航、旧锚点、图片和横向溢出；歌曲原浏览器用例覆盖手动播放、本人管理和隔离直传。
- 公网只读快照对照：1440px 首页高度从 7,855px 降至预览的 2,781px；该数字含预览提示条，不是加载速度指标。8 首公开歌曲在桌面、手机均可见，测试不向正式网站写入数据。

## 静态加载边界

仅下列 9 个公共静态文件属于此次界面候选：

```text
public/index.html
public/app.js
public/site-shell.js
public/site-shell.css
public/music.html
public/downloads.html
public/join.html
public/agent-api.html
public/aincrad.html
```

不更改服务端代码、配置、SQLite、对象存储、音乐播放签名、游戏连接或身份。不得用整个 main 替换现役 0.8.38：main 中未上线的 N.E.K.O OAuth 不在本次启用范围；部署应以现役静态前像为准，对照保留既有开关和接入行为。`/sao.html` 属于现役包中仍在使用的独立页面，不能因主仓库缺失而删除线上文件。

正式加载前保存这 9 个文件的前像与摘要，确认静态挂载方式。仅在能够不中断服务、保持原数据与配置时进行静态更新；如需要重建或重启，另取该次范围确认。回退只还原界面文件，不回灌旧数据库或覆盖玩家新作品。加载后核对 HTTPS 静态摘要、旧链接、公开作品与手机页面，源码测试不代替现役验证。
