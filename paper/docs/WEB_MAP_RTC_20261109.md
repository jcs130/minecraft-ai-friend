# 官网世界地图与 WebRTC 观战

地图入口 `/map.html`，公开读取 `/api/v1/world-map`。位置来自游戏服只读采样，每 5 秒同步；20 秒无新数据时清除玩家标记，保留地形。旁观、隐身、摄影者和指定镜头账号不展示。地形由 BlueMap 离线生成，区域之外未知，地形更新与实时位置分开。

独立地图服务仅监听回环，官网 Nginx 代理列出的地图路由；写入使用已有服务端快照凭据，限制路径、大小、摘要、序号和时间。不能访问账号目录、任意资源或历史聊天。采集器有单实例租约、状态文件和正常停止标记；`Start-WorldMapSync.ps1` 用于任务计划自动恢复。首次地形上传可续传，不改世界存档。

观战保留原采集连接、WSS 上行和 HTTPS 贴图，增加浏览器到门户的可靠、有序 WebRTC DataChannel。仅操作员设置 `PORTAL_WEBRTC_CONFIG` 绝对路径时启用，默认仍 SSE。配置示例：

```json
{"schemaVersion":1,"bindAddress":"10.0.0.1","advertiseAddress":"192.0.2.1","udpPortRange":[35000,35127],"iceServers":[{"urls":"stun:stun.example.org:3478"}]}
```

安装锁定 `werift@0.26.0`。上述地址是文档示例，部署必须填写主机实际地址，并只放行对应 UDP 范围。HTTPS 协商保留原身份、来源、权限和撤权检查；有界缓冲、限额、握手期限与 SSE 回退由共享渲染库实现。公网网络不允许 UDP 时保持 SSE，不重放游戏操作。没有 TURN 中继，不保证每个网络均能切至 WebRTC，也不预先承诺延迟更低。

共享源码来自 `mc-visual-console` 的 WebRTC 提交 `6f80eade`，采集端在实际已部署女仆渲染器之上叠加该传输增量；原模型和材质保持。浏览器包、门户内嵌传输模块与采集端须一起校验发布，不修改版本检查绕过不匹配。变更只需重载网页门户与只读采集端，不需重启游戏。

发布前保存当前门户镜像、配置及 SQLite backup，核对原账号/资料和下载目录；回退仅恢复代码与运行配置，绝不回灌旧网站数据库、玩家或地图位置时间。生产发布状态以独立部署清单和公网实际验收为准；源码提交、隔离检查通过不能代表正式启用。
