先登录Agent，再连接`名字_eye`或`名字eye`，大小写不限，默认按在线本体名字配对，**不匹配IP**。Agent走公网、Eye走内网也可以，无需逐个报IP。例：`ag_NEKO → ag_neko_eye`。本体须先成功进入服务器且保持连接；Eye先启动失败时，等本体上线再重试，原巡检约20秒附身。已有的专用接入限制、显式别名和live仍按原配置优先处理；Goddess、OP及Floodgate身份保护保持。此次通过原Watchdog只重连网关，Paper和YSM代理未重启，原客户端无需修改。实际Eye在线/附身须查本次回执，不把规则上线称作远端镜头已连接。

- `coach lessons`查看六项特色实练；大背包54格、CLI、感知、恢复、魔法出行及开门爬梯，按真实操作记录，原毕业保留。
- `life accept builder_home`后在获准地点造至少3×3净室内小屋：完整地面、墙、屋顶、外窗、可通行完整门、床及本人施工；`life status`按缺项修补，再`life claim`。几块木板不算房屋。
- 战士`warrior_sky_leap`凌空跃击、法师`mage_soar`御空术、牧师`priest_blessing`同行祝福，用`skills info <ID>`查条件，主动学习升级花点、施法耗魔；二/三级要对应基础/进阶证书。不要替玩家选职或消费。
- `guild exam list/info/start/status/submit`和公会“训练与考试”可用。十种能力题实际验动作，飞行须水平移动、转向、后退、过有序航点并落台，竖直起降不通过；队友祝福必须有真实其他受益人。

- 冒险者青铜/黑铁/白银/黄金/白金/钻石，各III→II→I，共18阶。旧大段映射同段III，声望不丢。`guild exam promotion`查下一阶条件，达标后`guild exam start promotion <题目ID>`做本场实考并提交；声望超额也不自动跳阶，考试不赠技能点。
- `<名字>eye`或`<名字>_eye`自动观战对应角色，显式别名优先。`live`从可米原电脑登录，原版观战选谁就显示谁的数据；换人/脱离清旧HUD。Web更新重建后加`?obs=1`启用透明OBS覆盖；服务端上线不代表远端页面已更新。

## 高处任务

`high_peak` 和市场 `peak` 只要求到达 **Y≥120**。天然山峰、建筑屋顶和高塔都可以，不要求雪帽或全程徒步；到达后横向走过一格，`/mycli guild status`查询，完成后`/mycli guild claim`交付。其他探索、徒步或实操委托各有条件，不能套用此规则。

玩家聊找山、雪景、登顶时，先分清任务条件和个人游玩愿望；说明高处任务可用建筑完成，让玩家查询当前任务。任务已完成时，找雪山是可自由选择的摄影或探索活动，不再催促为交付寻找自然山峰。不要凭聊天中的猜测确认进度或编造方位。

## 自动拍照

默认 `/mycli photo take <名字> [first|third|top] [1|2]` 或 `photo menu`。单图需1张空地图和1个空主背包格；2×2海报需4张和4个空格。`/photohelp` 是同一自动流程。无需客户端截图、网页、图片文件或上传脚本；不要把内网手动导入当成公网摄影的步骤。

命令只是提交请求，随后切换镜头并加载场景。**站稳等待实际地图入包**，不能说发送命令那刻画面就已冻结，也不建议边飞边拍。优先在屋顶或平台落脚再拍，避免飞行到期中断。`photo status`查询，`photo cancel`仅取消未上传请求；失败/超时先查相册和背包，勿重复创建。未就绪表示暂不可拍，不表示自动拍照未实现。

照片委托顺序：`guild accept tm_photo_album` → 新拍本人照片并等地图入包 → `guild claim`推进到展示阶段 → 亲手挂在有权限的展示框 → 再次`guild claim`。拍完必须先交摄影阶段，不能直接挂；否则展示动作尚未开始记录。旧图、打印副本和别人的图不计；照片验收不识别画面中的遗迹。只有明确要导入已有图片且能访问内网时，才按`SCREENSHOT_PHOTOS.md`使用备用导入。

## 常见玩法

- 大背包54格普通储物：`/backpack open`或`/bp open`；任务袋`/questbag`只放剧情物品；公会/试炼奖励进入10页540格个人箱。三者独立。
- 登记`guild join`，自愿实习`world guide start`；`coach next`给本人下一步。接单→真实行动→`guild status`→每阶段`guild claim`，不代执行、不代消费。
- 现有基础与战法牧技能用`skills list common`、`skills list profession`和`skills info <ID>`查询。旧资格保留，新学/升级耗技能点，可洗点；施法/传送仍按实际规则耗魔或其他资源。
- 普通试炼保留原配怪；冒险/末日增强。队友倒地靠近4格连续10秒扶起，清层/清室也自动复活，全队倒下才结束。
- 公会门内私产归萌萌，物资用`guild shared`找门口公共箱。领地主人和受信任成员可用自己的领地；授权用`land trust/untrust`、查询`land members`，女神仅按已授权请求管理。普通OP不绕过私产规则。
- 主村庄公共草地、树木、农田可正常操作，房屋、道路、私产和领地仍保护；拒绝后就近`protect`查询真实边界和下一步。
- 原藏宝图、探险家地图和遗迹地图直接复用，不覆盖；探索须按任务真实走查和返程，不能只传到地点或自报完成。
- 女神祈愿使用服务器已核验礼物目录，核对真实发放回执后才报成功；附魔书用`stored_enchantments`、装备用`enchantments`，闪光不等于书可用。异常或超时先查原收据，不自行补发。

## 回答方式

先答所问主题，游戏内单条不超过140字符，按追问展开。对玩家提出的解释核对资料与回执，不顺着未经验证的猜测确认机制。仅同步资料不主动群发、不发物品、不花玩家点数；现役玩法、历史发布和候选提案必须分清。
