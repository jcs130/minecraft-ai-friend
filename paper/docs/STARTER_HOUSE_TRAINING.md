## 搭一间真正能住的小屋

保留生活委托 ID `builder_home`、每日限制和原奖励：建筑声望4、绿宝石3、花盆2。原版事件确认本人合法放置，验收读取现存房屋；被保护插件取消的操作不算。

1. `/mycli life accept builder_home`，在有拆建许可的地点施工。
2. 留出至少 **3×3 的室内地面**、两格通行净空，建地板、墙、屋顶、外墙窗、门和床。
3. 站到床附近，`/mycli life status` 验房；按 `house.nextAction` 修补，再查询。
4. 七项全通过后 `/mycli life claim`。交付时再次验房，拆掉屋顶或堵住门后不能沿用旧的达标进度领奖。

| 检查 | 具体要求 |
| --- | --- |
| 地面 | 同一高度的连通室内至少9格，X/Z跨度均至少3格；每格下方有完整实心方块或玻璃地板 |
| 墙 | 房间四周封闭，墙两格高；至少4列实心墙，完整门可作通路；不接受敞口或只有一排围栏 |
| 屋顶 | 每个室内位置上方2至8格内均有覆盖；实心方块、玻璃、台阶、楼梯可用，玻璃板不算屋顶 |
| 窗 | 至少一格外墙玻璃/玻璃板，朝向房外；室内玻璃柱、地上的玻璃不算窗 |
| 门 | 本人新放的完整两格门，室内可从床边走到，室外有两格净空和实心落脚地面；门可以关闭 |
| 床 | 本人新放的完整双格床，床头/床尾和朝向有效 |
| 亲手建设 | 至少12个仍存在且材质匹配的本人结构方块，并占被验收地板、墙、屋顶的至少一半；床、门、外墙窗也须本人新放 |

这是本服的“小屋委托”标准，数值不是原版 Minecraft 的住房判定。已有地面可利用；合规家具如箱子、工作台、熔炉允许摆放，但不能封死从床到门的通路。只检查一间可住的房间，不评建筑风格，也不要求整个复杂建筑只有一间房。

检查以本次接单后记录的床为起点：最多4张有效床；玩家与床的X/Z坐标差各不超过24格、Y差不超过12格。每间室内至多225格，离床各水平轴不超过15格。只读取已加载区块，不加载远处地形、不每tick扫建筑。放置证据最多2048条，保存请求合并到一秒一次。超出范围或区块未加载时会提示靠近/缩小单间后重查。

原已领取的任务和奖励不会撤回。原在途 `builder_home` 保留任务ID及历史记录；0.4.18加载后重新验房，旧“放12块”进度不保证通过。旧版未记录的建筑材料不会被猜测为本人新建；应按新要求完成真实施工，不能在旧村屋随便铺木板刷领奖。

`mcagent:life` 保持 schemaVersion=1、私有投递，状态/交付追加 `house`：`ready/reason/checks/interiorCells/newStructuralBlocks/structuralBlocks/nextAction`。`progress/target` 对本委托变为通过项数/7；结构破坏后进度会下降。其他任务仍沿用各自目标。

## 六项自愿特色实练（0.4.18已上线）

入口 `/mycli coach lessons`，或 `/mycli coach menu` 的“大背包与特色实练”按钮。每项会给实际步骤、命令和完成状态。新手原有三项实习证明、六项入门清单和毕业资格继续使用；这些扩展练习不强制重新毕业，不增加点数或免费资格。

| 实练 | 服务器实际记录的操作 |
| --- | --- |
| 大背包 | 打开本人 Minepacks，存入普通物品并关闭；再打开、取回并关闭。袋子与人物物品数量须相反变化，物品元数据一致；同一次开窗存入又拿出不算完成 |
| 查命令 | 成功执行 `mycli list`、`mycli explain skills`、`mycli status`；错误页码或不存在的条目不算 |
| 照亮/感知 | 成功施放已学夜视、探矿或心眼之一；先查 `skills info night`，粒子/打开详情本身不算 |
| 恢复/援助 | 需要时成功施放已学圣愈、范围治疗、牧师治疗或饱食之一；无须故意受伤，缺资格可稍后做 |
| 魔法出行 | 安全地成功使用已学闪现、归乡、传送点、支援、跃空或飞行之一；地点查询不算传送 |
| 开门/爬梯 | 原 `world practice` 验证：亲手开合法木门并走过，连续沿梯上爬3格；飞行/传送不算，已有实操证明保留 |

技能照常检查资格、魔力、冷却与安全位置。教程不会自动学习、花点、接单或操作物品。`MC_COACH` schemaVersion=1 新增 `type=lessons|feature_proof`；真实证明保存在本人PDC，正常重登/重启保留。观战账号不参加自己的实练，仍沿现有私有消息与实际附身Eye镜像规则投递。

### 三种储物一定分清

- **黄色大背包**：Minepacks，54格普通储物；`/minepacks:backpack open`，也可原 `/backpack open`、`/bp open` 或右键物品。关闭后重开核对数量。
- **任务物品袋**：`/questbag`，剧情专用物品和任务笔记；不能当普通储物箱，也不是领奖处。
- **个人奖励箱**：`/mycli arena stash pages`，10页540格；公会、试炼等奖励仍进入原库存/待入箱队列。

教学使用 Minepacks 的真实 Backpack API、持有人UUID与原版容器事件确认；不根据窗口标题猜测，不把任务袋/奖励箱算作大背包，不改任何一份库存。详见 [背包说明](BACKPACKS.md)。Minepacks禁止的游戏模式仍不开放。

## 参考与兼容边界

设计参考 Minecraft 官方的 [第一夜生存](https://www.minecraft.net/en-us/article/how-survive-your-first-night-minecraft)、[新手指南](https://www.minecraft.net/en-us/minecraft-tips-for-beginners) 与 [Minecraft Education 城市规划建房课程](https://education.minecraft.net/lessonsupportfiles/9223644809867444-Computing%20with%20Minecraft_Unit%202_City%20Planner.pdf)：通过真实搭建、使用工具和实际操作学习。原版第一夜临时避难所可以很简单；本服长期“小屋”委托另设上述有窗、有床的条件。

沿用原版方块、物品、箱子与系统聊天，不增加客户端模组或新物品ID。隔离原生协议验证及源码测试见本次运维回执；Mineflayer通过不等于手机/Xbox真机画面验收，也不代表Agent已自主学会六项技能。
