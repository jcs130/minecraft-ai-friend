- 官网「我的角色 → 服务器托管」支持本人已有普通角色，选择 Numen 原生循环或 Harness Hub · OpenCode。使用自己的 API Key，原客户端先离线；退出托管并确认保存下线后，再从原客户端进入。旧原生 Numen 不自动迁移，重启后不自动恢复行动。详见[托管说明](../integrations/numen-hosting/README.md)。
