# 照片全量保存与公开管理

0.8.29已于2026-10-29正式发布，先切换云端，再更新家庭采集器。云端已实收29张照片及归属UUID，游客仍只见原3张，26张保留私有；包括仅在持久档案里的5张旧照片。原游戏公开标记、账号及归属不变。[本轮发布](ALL_FEATURES_RELEASE_20261029.md)。

## 规则

所有完成的照片都上传保存，公开状态独立管理。默认沿用既有照片的公开选择；新未公开照片保持未公开。网站管理员可管理全部照片，普通用户可管理已绑定UUID对应角色的照片。不得按相同显示名认定归属。游客只能看公开展廊。

登录网站进入“相机展廊”，点“我的照片”（管理员为“管理全部照片”），可预览、设为公开或不公开。网站选择持久保存并优先于旧游戏标记，周期同步不会覆盖。源照片所属UUID改变时旧选择失效，原账号不能继续管理。退出或切换账号会清空私有列表和打开的预览。

撤展保留原片和元数据，关闭公开读图；网站重启不丢选择。私有图片禁止共享缓存，公开图片每次复核权限后再处理ETag，避免撤展后错误返回304。发布和撤展走已有浏览器登录与CSRF校验，不授予游戏OP或Agent平台Key。

## 同步与性能

家庭端合并当前相册与只读档案数据库的照片元数据，当前相册信息优先。每批最多50条、循环补传，完整目录上限10000。原片按内容摘要校验和去重；元数据变化无需重传未变图片；未知上传结果只补传同一ID/摘要。

旧多地图照片按[ImageFrame原生行序](https://github.com/LOOHP/ImageFrame/blob/main/common/src/main/java/com/loohp/imageframe/objectholders/URLStaticImageMap.java)无损重组，不能只取0.png。真实数据有3张需要重组，均还原1536×1536；29张约18.1MB。合成缓存最多32MiB、单图8MiB/4096像素边长，缺图、越界路径、非法尺寸拒绝，原数据保留等待恢复。没有下载任意图片URL、启动额外游戏账号或向Paper反复查询地图。

云端须先更新为支持全量目录和私有图片的版本，再切换家庭同步器。旧版云端只接受公开目录，不能反过来先换同步器。保留原账号、归属、相册、游戏标记与网站配置，新增公开选择表，不迁移或重建游戏角色。
