## 玩家用法

- 罗盘里的金币商城有弓、弩、箭、食物和每日精选。普通箭每 16 支 3 金币、每 64 支 12 金币。每日精选由远程武器、近战武器、两件护甲和两件工具或盾牌组成，共六件。附魔和价格随当天选出的装备生成，每款全服一件。北京时间每天 00:00 换货，售出后从已打开的货架和查询结果下架。
- `/mycli trade shop list daily` 查看当日装备和精确购买命令。`/mycli trade shop list supplies` 查看常驻补给。可加 `--json`，每日商品包含 `stock`、`refreshAt` 和 `buyCommand`。商品 ID 含日期。以私有成交回执为准，商品进入个人箱待入箱队列，`/mycli arena stash page 1` 取货。
- `/mycli cast frostnova` 打击 5.5 格内最多四只可见敌怪，施加缓慢 III 和短暂虚弱 I，同时扑灭自己、可见玩家和允许清理的地面火源。试炼塔岩浆层在场参战者可以清理本层明火。岩浆、营火和其他方块保留。无目标时不耗魔，有效施放消耗 7 魔力并进入 14 秒冷却。
- 牧师可以用 `/mycli skills info radiant_pulse` 查本职群疗学习节点，用 `/mycli skills info wardens_bloom` 查 4 级的守望绽放。守望绽放在 8 格内群疗、持续回血并清除最多两个符合标签的状态。法师 8 级的 `/mycli skills info astral_convergence` 提供 10 格内援护和对附近最多三只怪物的伤害。骑士的 `/mycli skills info fortify` 显示自己 8 秒抗性 I，以及 7 格内可见队友 5 秒抗性 I。
- 支援法术沿用 Vortex 职业和魔力。野外依据既有队伍；副本内依据实际参战名单。治疗和抗性作用于符合条件的可见队友。

## 构建及恢复

- AgentFriend 以 SHA256 固定的现役 .70 为基线。`build-daily-shop-frost.py` 仅换商城、法术、说明、技能回执相关类和版本。Youer 的技能事件用它实际接受的 Bukkit 封包，原版和未注册插件频道的 Mineflayer 可继续接收原 UTF-8 回执。
- `build-party-spells.py` 可从现役 qd29 或已核验的女仆施法候选构建团队技能版。联合候选以女仆施法版为基线，仍使用 RPG 桥所验证的 Vortex API 版本，制品摘要用于区分。
- 每日货架随日期落盘，商品和金币使用现有个人箱与 Vortex 结算。成交时，售出状态与准确的物品堆栈写入同一个配置版本。若扣款或交付结果待核对，货品保留隔离状态，按原交易 ID、原银行账本和个人箱队列核对。
- 上线前重新核对实际运行文件和当前维护条件，正常停启。回退用对应插件前像，并保留最新世界、金币、物品、货架及交易回执。
