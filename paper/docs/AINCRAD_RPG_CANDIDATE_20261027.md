## 本批可玩流程

选职业 → 实际学习并准备一项战斗技能 → 顾风战备说明 → 单人开场或10秒集结加入 → 三段清怪 → 首领蓄力/换剑 → 返回前哨 → 保存通关和个人领奖凭据 → claim → 打开个人箱。

复用现有命令，不新增攻略命令树：

## 数值、职业与性能边界

战斗Lv.1–100独立于Aura生活等级。一级升二级70XP、二级升三级120XP，按`40+20n+10n²`计算本级需求；每级增加0.5最大生命和0.08攻击。种地不产生战斗经验。自然敌人按表给XP，练习塔20%；攻击、承伤、真实有效治疗均可参与，纯旁观不分经验，不只奖励最后一击。

突刺等攻击保留原版受击间隔。测试曾把普通攻击和突刺同时发出，原回执误报`protected_target`。候选在扣费前区分`target_recovering`，要求约半秒后重新瞄准，既不强制清除受击保护，也不绕过真正的伤害取消。真实地图专项核验了掉血、成功回执、时序拒绝零消耗及其他插件拒绝后的退款。

四职业沿用原技能/魔力/点数/冷却账：战士剑技、法师远程与控制、牧师恢复和祝福、坦克持盾挑衅/坚壁/盾击/掩护。坦克挑衅6格可见敌人、基础3秒、12秒冷却；坚壁正面最终伤害减半但每击最多减3HP、持续4秒、18秒冷却。高阶数值由`skill-points.yml`管理。法术体系是本服Minecraft扩展，不把它冒称艾恩葛朗特原作数值。

单一战斗数值权威：默认不开启，配置明确启用；若Vortex同时运行则拒绝叠加。XP/通关账使用单个有界写队列，成功落盘后才宣布成长；副本通关证明有持久补记。TAB每秒读取主线程缓存的只读文本，显示职业、战斗等级、升级差额、生命、正式层和排名，不逐刻扫全世界。

## 远程个人箱的明确说明

先`/mycli skills info travel`，未学再`/mycli skills learn travel`；保持2魔力后`/mycli arena stash`打开，`stash pages`选10页。无需先施放传送术或返回试炼场。成功远程开页耗2魔力，实体箱旁免费。

`arena rewards list`查待入箱奖励，`stash list [页码]`查已经装入的箱格；领奖后开箱才物化，箱满继续保存。空箱查询同时提示待入箱数量。正常窗口存取要等库存/光标确认，超时先查不重放。54格大背包另用`/minepacks:backpack open`。
