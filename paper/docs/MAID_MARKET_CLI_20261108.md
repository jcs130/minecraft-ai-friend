## 最小修复

- 不同背包/个人箱槽位分别保存报价，每人最多32份、5分钟有效；同一槽重新报价只替换该槽旧 ID。超出容量淘汰最早报价，生成报价时清除过期记录。只生成报价不移动物品、不发金币。
- 出售仍按本人、原 ID、完整物品组件指纹和数量验证，精确消费该 ID；原持久化回收事务和未知结果锁保持。不得把“未读到回执”当作可重复出售。
- 回执带 `validForSeconds`、`expiresAt`、`confirmCommand`、`refreshCommand`。过期明确本次未出售，可重新查询原槽后核对；不会自动生成或执行新交易。
- `arena wallet --json` 和旧 `arena shop/recycle` 的既有结构化入口可达，与帮助目录一致。`arena` 是试炼塔，`pvp` 是玩家竞技场。未提供 JSON 的试炼动作继续拒绝执行，返回去掉 `--json` 的具体命令；不把不支持的格式当多余游戏参数，也不暗中执行动作。
- 配套 PR119 只修复女仆回执分类和已订阅客户端的附近 `chat-result` 投递，保留原实体、请求编号、权限、隐私和动作终态。`applied` 仍只证明模式设置，不能据此宣称工作目标完成。
