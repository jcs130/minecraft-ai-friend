服主已明确授权合并、部署 PR156、PR158。此记录的初始阶段是候选验证；正式版本、启动时间和实际验收必须以上线后回执为准，不能将合并等同加载。

PR158 修正三处 LoginGuard 消息订阅的异步默认行为。原认证、2FA、当前物理连接和其他插件的拒绝结果保持；音频仍按原序号、长度及 SHA256 严格检查，不缓冲重排、不放宽校验、不重播历史请求。

实际扫描代理插件，另发现 OptionalPayloadGuard 与 ViaVersion 各一处默认异步订阅。**是否还会乱序不能仅凭注解推断。** 用固定 Velocity 的真实分发器注册全部五个真实消息监听器，保留这两个现役 JAR：旧 LoginGuard 矩阵先失败 `[2,1,0]`，候选矩阵 C2S/S2C 均通过。实测据此将发布范围收敛到三份制品，另外两个插件没有修改或替换。将来变更事件组合仍须重新验收。

PR156 在真实附身、配对、维度、权限和当前连接均通过时补首帧 HUD；不授予 Eye OP、不开放任意附身，不重复广播或定时重附身。原角色、背包、经验、世界、任务、认证、模型/音色、原脑选择和动作账本均保留。

## 候选验收

- 两次独立构建的三份发布制品摘要一致。
- 15 组 LoginGuard 回归通过，包括原92条语音授权断言和消息顺序、认证恢复及持久发布边界。
- 真实三插件、五订阅矩阵：基线先失败，候选 C2S/S2C 通过；断言所有五项均实际注册。
- Paper/SVC 完整语音编译、原有90项边界及新有界拒绝诊断通过；14项 Node 客户端/被动采集检查通过。
- 回环真实 TCP/Velocity/原上传器/Java VoiceUploads：直接和代理各20次自然调度通过。该后端的完成回执是合成校验完成，不代表 SVC 或耳听。
- 新标记回环 Youer/NeoForge HUD 服：基线15项中13项按原缺口失败；正式发布制品26/26通过，含真实 UUID、四类初始包、E、空槽、权限、解绑及相同 UUID 重连。两次测试均正常停止，不涉及原角色。

隔离首轮启动脚本替换 Windows 路径时产生 `\v` 转义，发生在测试服启动前；失败文件保留，使用 POSIX 源路径和全新 r2 隔离目录后通过。早期三插件风险推断曾准备额外制品，但组合实测后撤除对应源码及发布目标，旧未采用构建不属于候选清单。

## 副本与原客户端边界

正式 `.70` 已包含墓穴入口/检查点与考试修复。直接针对正式 JAR 的90项指引回归通过；当前 `undead_crypt active=false` 表示没有新场次，不代表未开放。空闲场地需要一人到首室 `start`，已有场次中的合格访客才自动同队。服务端日志记录可米多次 info/status/travel 后归乡，未见新的 start；没有替她开场或修改委托。

服务端语音拒绝和原客户端停顿之间的因果尚未取得原队列证据。原客户端的模型等待、动作采用、本人按键/像素及真人耳听应由原宿主回读，不能用合成测试替代。沿用获授权的客户端联调通道，不新建同名身体或接管控制权。
