# 真人玩家的冒险大厅

状态：PR145 已合并（`bef66646`），六项CI通过；2026-11-09 16:57正常维护后，AF.68正式加载并通过15项只读启动检查。候选58项普通协议、113项Cumulus及正常重启57项检查保留；本人手机/Xbox/NeoForge像素验收仍独立待验。见[正式部署](ALL_PENDING_RELEASE_20261109.md)。

## 怎么打开

右键技能罗盘，或输入 `/mycli menu`。Java／NeoForge／原版用四行原版物品菜单；Floodgate 基岩玩家优先用原生按钮表单，API 不可用时回退到原版菜单。不增加必装客户端模组。

大厅只有六个分区：

| 分区 | 能做什么 |
| --- | --- |
| 角色与技能 | 本人等级与本级经验、职业选择、职业技能、天赋、13项通用技能 |
| 冒险与任务 | 村庄练习塔、艾恩葛朗特正式攻略、主题遗迹、RPG任务、公会委托与晋级 |
| 背包与仓库 | 54格大背包、十页个人箱、随身物品或全个人箱的无损堆叠合并 |
| 商城与交易 | 现有金币商城、装备回收、玩家交易行和个人箱收货 |
| 队伍与伙伴 | 当前队伍与邀请、确认创建或接受、原生队伍管理、查看伙伴与世界、支援传送、个人传送点 |
| 留影与生活 | 女神相机、公开日记与档案、外观画廊和旅行地点 |

新页面底部固定“返回／冒险大厅／关闭”。Java 鼠标悬停看条件；基岩按钮显示短说明，详情放在表单正文。旧原生子菜单保留原布局，关闭后再右键罗盘回大厅。熟练玩家可潜行右键罗盘，或 `/mycli menu quick` 使用旧快捷栏。

通用技能先打开效果、目标、消耗和失败说明，再主动点击使用；目标类技能会打开地点、伙伴、矿种或配方选择。浏览不会施法。天赋未选职时给中文说明并打开职业菜单，不替玩家选择。

未入队时不再把玩家送到原生菜单的英文死路：组队大厅先显示本人当前状态，无邀请时可确认创建一人队伍，有邀请时可核对邀请者后接受或拒绝；确认时重新读取状态，不会接到另一位邀请者的队伍。已入队后才打开原生管理菜单。现有队伍、权限及邀请期限不变，浏览不会自动组队。

“整理”只合并组件相同的堆叠，不销毁、不出售，不合并不同附魔或元数据。随身整理不包含 Minepacks 大背包；个人箱整理包含全部十页。两者都先显示范围、再确认。商城、回收与拍卖继续使用现有报价、确认、保护和交易账本。

## 研究与取舍

本轮在2026-11-09核对项目官方资料：

| 方案 | 适合的用途 | 本轮处理 |
| --- | --- | --- |
| [Geyser Forms / Cumulus](https://geysermc.org/wiki/geyser/forms/) | 原生基岩列表按钮、关闭与无效响应处理 | 复用已安装 Floodgate 的公开 API，实际构造并验证表单 |
| [InventoryFramework](https://github.com/stefvanschie/IF)／[Triumph GUI](https://triumphteam.dev/docs/triumph-gui/introduction) | Bukkit 菜单分区、分页及槽位行为 | 参考导航模式；本轮复用现有物品菜单，不引入另一套任务或交易引擎 |
| [FancyMenu](https://modrinth.com/mod/fancymenu) | 客户端定制和动态界面 | 可作为 NeoForge 客户端的后续视觉增强；本轮未安装，不能承担原版／基岩的基础入口 |
| [Inventory Profiles Next](https://modrinth.com/mod/inventory-profiles-next) | 客户端整理、锁槽与匹配搬运 | 参考整理范围和锁槽的表达；不把客户端“丢弃全部”设为服务端默认行为，本轮未安装 |
| [NeoForge 1.21.1 Menu 文档](https://docs.neoforged.net/docs/1.21.1/gui/menus/) | 自定义客户端屏幕与数据菜单分离 | 基础入口采用原版协议；后续自定义屏幕可复用相同服务端权限和玩法 |

这是对多端可用性和现有架构的取舍，不代表这些项目全部已安装或实测。当前只新增菜单展现和路由，不复制职业、金币、技能、组队或物品事务。

## 交互与恢复边界

- 库存图标为按钮，不是可取出的奖品。页面归属本人，Shift、数字键、拖拽、光标携物和底部背包操作不触发按钮。
- Java 点击延后到下一刻，并重新核对在线状态和当前页面；提前关闭或打开别的页面会取消。
- 表单响应绑定主人和一次性会话，120秒过期；关闭、非法索引、旧表单或重复响应不会重复执行。网络回调统一切到游戏主线程。
- 所有外部入口仍以本人执行，保留现有权限和玩法条件；不授予OP、不用控制台代执行。浏览不选职、学习、开团、购买或回收。
- 不定时刷新、不轮询模型、不增加每刻扫描。角色页是打开时快照，可主动刷新。
- 未确认的交易／学习／领取不自动重试；只报告入口和时间，按原回执核查。
- 原 CLI、原生子菜单及观战库存转发保持；基岩原生表单不是 Java 箱子，不能把表单 API 验证算成 Eye 已收到箱子窗口。

## 验收记录

构建与结果以 [候选清单](../manifests/player-ui-candidate-20261109.json) 为准。隔离测试使用固定25960/25961端口、专用标记和合成角色，不读取真实玩家背包或口令。

已先确认旧版默认入口仍为旧罗盘。联调过程中还发现未选职的天赋命令只给英文提示，已改为中文说明并打开职业选择。早期探针把1.21.1的NBT标题当字符串比较，是夹具错误，原失败记录保留；修正探针后重新验收，不当作正式服故障。

最终同摘要候选通过68项纯导航／响应／邀请绑定检查、58项普通Java协议实际操作、16页113项实际Cumulus编解码和关闭／无效响应检查。正常停服、原JVM退出、同制品冷启后再通过57项操作及113项表单检查，原合成角色职业与物品保留；另3481项原生掉落检查保持。浏览前等待原生魔力自然回满，避免把重连后的被动恢复误判为菜单写入。三次独立构建摘要一致，14个AF.67掉落条目字节一致。

实测安装的Cumulus合并Runnable回调在无效响应分支未被调用；适配器改用公开Consumer重载，并在有效回调入口再次检查按钮范围。原失败与通过记录保留。本轮不替换Floodgate，不改其底层实现。

测试夹具还曾让 Minepacks 自行更新成上游制品，且遗漏它实际读取的 `Database.UseDynamicTitle=false` 兼容项，导致开包编码断线。现已固定正式修正版摘要、禁用QA自动更新、补齐相同兼容项；正式JAR及配置未变。普通角色只获得正式默认组已核实的两项背包使用/六行容量权限，不授予OP或管理别人背包权限。试炼塔几何未导入此隔离存档，因此该入口验证明确的“未建成”与可用遗迹恢复提示，不冒称验证了隔离存档不存在的塔。

真人手机／Xbox触屏和手柄、本人原版／NeoForge画面，以及原客户端主动采用仍须分别回执。表单编解码通过不代表这些设备已实际操作；不以合成账号替代原可米主人格。

旧原生子界面沿用现有内容；外观和天赋插件仍有少量英文标题，本轮没有以改包或修改正在运行的界面来掩盖这一点。新大厅、分区、通用技能及组队引导使用中文。

## 发布与回退

候选 AF0.4.47.68 同时包含已合并 PR144 的 AF.67 练习塔掉落平衡；不包含新世界或角色数据。只从钉住摘要的正式 AF.66 窄包构建，保留638个无关归档条目；正式前需重复构建相同摘要、完整CI、E/F候选及原代码前像，并重新核验当次玩家／副本门禁。

未经这份候选的正式验收，不声称已上线。若发布，使用全新单次维护入口，180/60/10预告、正常停止原JVM、当次E/F冷备后替换；不复用未执行的AF.67入口来追加文件。

菜单故障时可回退 AF.66 代码恢复旧入口；最新世界、物品、职业、认证、金币、检查点、奖励和动作账本全部保留。浏览本身没有需要回灌的存档。若玩家已通过旧有交易／学习入口产生新状态，不回滚这些状态。
