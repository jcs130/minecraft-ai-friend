# 集结活动条与 Eye 去重

2026-11-09 候选：AgentFriend `0.4.47.65-activity-bars-rpg`、CortiEyeMirror `0.1.20`。本记录的候选测试不等于正式部署或真人画面验收。

## 问题与修复

live／Eye 同时拥有自己的全服活动条和目标角色转发的条。WorldEvents 的逻辑活动在不同接收者链路中可能使用不同 UUID，原镜像只按 UUID 避免重复，因此“冒险者集结·探索留影”会显示两条。

新增共享的保留活动识别：只处理当前六种 WorldEvents 活动，核对活动编号及倒计时，保留观战者原生活动条并撤下目标的重复副本。普通首领、救援和任务即使同名也不合并；不同倒计时代际保持独立。覆盖迟到 ADD、切换目标、原生条消失、退出附身、断线重连与 REMOVE。每个观战连接对每种实际去重活动只记录一次运营日志。

此前降噪只覆盖星灯夜巡、丰收时节和旅人顺风，没有覆盖三种冒险者集结，本次补齐。提示改为 `集结邀请·探索留影｜剩余约08:10`，每十秒至多改一次文字、进度以 5% 为步长；长度表示活动剩余时间，不表示拍照或副本任务进度。没有有效倒计时时标为“剩余时间待同步”，不伪造完成。

`/mycli world events --json` 保留实际 `remainingSeconds`，另返回 `progressMeaning=event_time_remaining`、`isTaskProgress=false`、`participationAutomatic=false`。集结只是自愿邀请，不自动报名、开副本、拍照或发奖。
