# 操作失败后的正确做法

AgentFriend 0.4.3 的玩家提示遵循“哪里出错 → 为什么 → 下一步”。适用于原版聊天、Agent 命令回执，以及实际附身的配对 Eye；Agent 客户端不用更新。原原因码、成功判断、耗费和权限规则保持。

## 建筑与私产保护

实际拆放、开箱等被服务器拒绝时，私聊说明被拒绝的动作、目标维度和坐标、所属保护区及其真实边界。例如：

```text
【操作未执行】拆除方块被保护规则拒绝；目标 minecraft:overworld (-489,66,-500)。
【保护范围】冒险者公会：minecraft:overworld (-498,64,-509) 至 (-480,76,-495)，含边界。
【正确做法】停止拆除；另选同世界 X≤-499 或 X≥-479 或 Z≤-510 或 Z≥-494 的区外目标。
那里可能还有其他保护，靠近后先查询目标，得到 allow_likely 再操作。
```

- 两端坐标都包含在保护范围内。换目标按水平 X/Z 离开范围，不通过地下挖洞或从屋顶绕过保护。
- 村屋、道路、生活馆等按原建筑方块和净空保护；提示的长方体是**外包范围**，不表示里面每个方块都禁用。多边形区域也明确标注外包范围。
- 重叠保护会列出相关范围，并按外包总范围给选址建议。区外仍可能有其他保护，必须重新查询。
- 全世界限制没有可跨出的局部边界，会提示联系服主确认允许的位置或授权。
- 保护服务或权限记录异常时，停止施工/取物，联系服主恢复服务，不能把异常当作允许。
- 私产即使搬出保护区，原归属仍有效。需要授权时联系主人；不是改个位置就能拿。
- 公会门内私产归萌萌。需要装备物资，执行 `/mycli guild shared`，前往门口公共箱；公共箱体不能拆，箱内物资可共享。
- 同一玩家、同一目标、同一动作的连续提示短时去重；取消操作仍每次生效。

动手前使用：

```text
/mycli protect break <x> <y> <z>
/mycli protect place <x> <y> <z>
/mycli protect container <x> <y> <z>
/mycli protect use <x> <y> <z>
```

查询只检查本人当前世界、眼睛周围16格内已加载的目标。`unknown` 表示没有确认，须按提示修正距离、区块、整数高度或操作类型；`allow_likely` 之后仍以实际事件为准。完整说明见 [保护查询](AGENT_PROTECTION.md)、[领地](LANDS.md)、[公共仓库](GUILD_SHARED_STORAGE.md)。

## 其他失败信息

| 场景 | 提示给出的下一步 |
| --- | --- |
| 技能ID、学习资格、点数、准备槽、装备 | 查技能目录/详情和本人点数；补齐条件或自行决定学习、升级、洗点 |
| 魔力不足、冷却、无治疗或攻击目标 | 查状态，等待恢复/剩余冷却，靠近有效目标；不循环施法 |
| 玩家委托、日常委托、工程验收 | 查本人任务、准确ID与条件；补物资、真实走查或按验收证据补齐结构 |
| 地下城、组队、倒地 | 查本场身份和首室，按集结期入队；队友4格内连续10秒扶起，或清层/室自动复活 |
| 传送点、公共地标 | 查有效地点、领地主人、魔力与安全落点；等待最终回执，原点受阻由主人更新 |
| 钱包、商店、回收 | 查余额、商品或真实槽位；重新获取报价并确认一次，队列满先整理个人箱 |
| NPC、村庄警报 | 到真实居民8格内对话；支援前重查活敌人与事件ID，过期警报停止追踪 |
| 技艺书、绑定装备 | 查背包槽位和技能熟练度；满级不消耗书，不能出售或转移绑定物 |
| 数据保存、发奖或施工异常 | 保留物品和记录，停止重复提交，将原因码、原命令和时间告知服主 |

查看说明不会替玩家学习、消费、接单、交付、传送或改权限。提示中的消费/退出/放弃/删除动作由玩家确认意图后自行执行。

## Agent 回执兼容

`mcagent:protection` 和私聊 `MC_PROTECTION` 保持 `schemaVersion:1` 及原 `status/allowed/reason/action/world/x/y/z`。拒绝时追加：

- `actionLabel`、`areas[]`；每个区域含 `id/name/world/min/max/shape/inclusive/envelopeOnly`。
- `boundaryInclusive:true`、`retrySameAction:false`、`nextAction`、`nextCommands[]`。
- `globalProtection:true` 表示全世界限制；`boundsIncomplete:true` 表示数据不足，停止操作并联系服主。

旧 `MC_LAND_ACCESS` 聊天保留紧凑字段，完整提示走原 plugin message 与私聊。公会拒绝保留 `MC_GUILD_ACCESS`。技能、委托、地下城、商店、PvP、生活、传送及目录等原回执追加 `errorMessage/nextAction/nextCommands`，原码和 schema 不变。纯文字技能报错也包含下一步。

Agent 应先检查原 `success/ok/status/allowed` 和原因码，再读取建议；`nextCommands` 是建议，不应盲目自动执行。实际失败后停止当前目标，按本人最新状态修正再试。

## 运维与边界

本次巡检覆盖本服自研玩家可见失败分支，补充 MagicSpells 通用施法错误和本服生成的 WorldGuard 领地拒绝文字。其他第三方插件自己的全部内部日志不属于玩家操作指引。新功能报错必须同时提供原因和正确下一步；涉及物品、钱包、施工的异常不可引导盲目重试。

MagicSpells 仅修改七项提示文字，原魔力、冷却、效果和物品保持。正式发布须走维护门禁、E/F 停服完整快照和正常重启；回退 JAR 与两份提示配置时保留玩家进度，不能用隔离世界覆盖正式服。基岩使用原版私聊，不依赖客户端模组；手机/Xbox真实显示须以设备验收为准。
