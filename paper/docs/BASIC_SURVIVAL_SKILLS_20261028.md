# 基础生存技能恢复

状态：已随2026-10-28[正式发布](BASIC_SURVIVAL_RELEASE_20261028.md)上线。当前为AF.25/桥0.2.4/Vortex qd29/Qwen频道0.3.2；实际摘要见[部署清单](../manifests/current-deployment.json)。本批包含此前RPG与CLI修复。

迁移Vortex时只保留了home/travel/prospect/night/feather，把六项原有基础技能也列入旧技能停用，范围过大。现在恢复寒霜、星芒箭、闪现、圣愈术、饱食术、造物术；归乡原本保留。人人可用，不需要选职业、学习点、经验或重新学习。职业专属技能仍归Vortex管理。

| 技能 | 命令 | 原有效果 | 魔力 / 冷却 |
|---|---|---|---|
| 寒霜（霜环） | `/mycli cast frostnova` | 身边5.5格最多4只可见怪物；基础2伤害、减速4秒 | 7 / 14秒 |
| 星芒箭 | `/mycli cast starbolt` | 准星18格或附近12格可见敌对怪物；基础5伤害 | 4 / 3秒 |
| 闪现 | `/mycli cast blink` | 沿视线至安全落点，最远约25格 | 4 / 8秒 |
| 归乡 | `/mycli cast home` | 返回村庄现有安全传送点 | 6 / 无固定冷却 |
| 圣愈术 | `/mycli cast selfheal` | 自己回复最多8生命，即4颗心 | 6 / 15秒 |
| 饱食术 | `/mycli cast food` | 自己恢复4点饥饿、2.5饱和度 | 3 / 30秒 |
| 造物术 | `/mycli cast give bread` | 固定配方生成普通物资；例如面包×4 | 4 / 每配方20秒 |

中文名同样支持。入口只需记 `/mycli skills list common`；具体条件、目标、冷却和用法查 `/mycli skills info <ID>`。寒霜复用霜环，不是另做一个同名伤害系统。

造物固定配方为bread×4、torch×4、oak_log×8、cobblestone×16、crafting_table×1、chest×1、cake×1、glass×8。其他物品仍沿原女神审批，不开放任意ID/数量或管理权限；申请送达不代表物品到账。倒地/旁观不可施放，目标遮挡、安全落点及原传送事件检查保留。

基础技能沿原回执和实际效果核对，**施放时不加 `--json`**；格式旗标或多余参数在执行前拒绝，避免当成造物申请。技能目录和单项详情支持JSON查询。`learn`基础技能只说明已可用、不扣点；`prepare`不会占用职业点击槽，提示直接施放或沿用原法杖绑定。不是恢复旧职业或解封全部旧职业法术。

效果复用既有CombatSpells、MagicSpells和TravelMagic；仍只扣Vortex原生魔力，不新建魔力、职业、装备或个人数据。未重新分配任何真实玩家的技能、物品或角色。

归乡另修复了原技能依赖Essentials命令权限的问题：仅固定的`home → village`走原TravelMagic传送，校验已生成区块、身体空间和安全支撑，成功后扣6魔力。未授予普通玩家Essentials传送管理权限，其他warp/home命令不改。传送事件仍可拒绝，失败不扣费。

配套短通知修订为release-revision3，沿原每账号一次的私有投递。正式安装时只把最新`onboarding.yml`的`release-revision`和`release-notice`合并到现有文件，其他配置保留；不能用仓库默认文件覆盖玩家的现有设置。
