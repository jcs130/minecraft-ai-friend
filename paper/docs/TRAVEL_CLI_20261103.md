2026-11-03 10:56 已正常维护上线 AF `0.4.47.50-rpg`，22项正式检查通过。E/F最新游戏和认证冷副本已核验，673份角色相关文件在安装阶段一致，75条原凭据及女神7任务/身份保持；核显相机恢复Intel、约30帧和40模型。实际范围见[部署清单](../manifests/travel-cli-deployed-20261103.json)及[当前清单](../manifests/current-deployment.json)。命令检索继续只返回建议，不自动执行。

## 传送修复

Youer 的 `getChunkAtAsync` 对已卸载的区块可能直接返回空。正式入口此前已使用 `ExistingChunkAccess`，但个人地点、地标、旧遗迹接近点以及两处救援路径仍漏用了旧接口。本轮统一复用既有的非生成式加载器；只加载原来存在的区块，读取错误不会当作创建新地形的理由。

旧遗迹接近点复用个人传送的同一请求门禁、十秒时限、原点与活动状态复核、临时区块票和落点保护。个人地点与地标仍为6魔力，遗迹接近点为8魔力；成功后才扣一次。个人点保持记录的精确位置，受阻时不穿墙另找落点。旧遗迹的 `--json` 现可返回明确的 `MC_SITE_DUNGEON_RESULT`，不再因缺少新版入口字段而直接拒绝。

## 搜索正确用法已经可用

错误输入会检索服务器当前加载的 `/mycli` 目录，结合真实目标、同义词、词元余弦相似度和拼写距离，最多返回三条候选，默认文字最多两条。职业技能由实际 Vortex 配置提供。以下例子已通过普通客户端验证：

| 输入 | 实际建议 |
|---|---|
| `/mycli teleport ag_TCB --json` | 在线目标已核实，返回 `/mycli locate tp ag_TCB` |
| `/mycli 传送 墓穴 creeping_crypt --json` | 地点已核实，返回 `/mycli dungeon travel creeping_crypt` |
| `/mycli waypont list --json` | 返回当前 `waypoint` 用法 |
| `/mycli cast dungeon info creeping_crypt --json` | 返回 `/mycli dungeon info creeping_crypt` |

检索只给建议，不执行、改参数、扣魔或发公屏。缺失、离线或不确定的目标引到帮助或列表，不填造目的地。外部神经向量索引是可选组件，现役默认关闭；本地目录检索无需等待网络。详见 [检索设计](CLI_RECOVERY_20261101.md)。

Agent 应通过聊天发送完整 `/mycli` 命令；施法工具只接受真实技能。收到建议后先核对目标和条件，再主动调用正确入口。查询工具只支持它实际列出的只读查询ID，不接受任意命令字符串。不要把 `dungeon info`、`claim` 或 `travel` 塞进 `cast`。

## 错误必须结束本次等待

程序明确请求机器字段时使用该命令支持的 `--json`。匹配本次请求的 `MC_CLI_ERROR` 或业务拒绝也是终态，不能只等待成功前缀。共享 SDK 的 `ServerQueryLane` 已通过真实服务器数据验证：拒绝变为 `phase=replied`、`failed=true`，保留 `nextCommand`，不重发或自动执行建议；随后另发的正确只读查询可正常完成。终态只投递一次，`goal_completed=false` 保持。原始回复没有请求 nonce，因此关联回执不等同于唯一请求的密码学证明。

远端 Cortico 宿主目前不可连接，未把上述共享层验证冒称为它的宿主版本已更新。它的适配器需要同时匹配成功和拒绝、保留代次和时间/消息序列边界；见 [MCP 消费规则](MCP_CLI_RECOVERY_20261101.md)。
