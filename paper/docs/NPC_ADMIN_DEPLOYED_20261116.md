# 智能居民管理与战斗邀请发布记录

2026-11-16，PR #273（`355b86a1aea8a899de1d6886d1cff6e1d2c77df7`，六项 CI 通过）已部署到千灯纪。官网管理员可配置居民，原桐人可接受远程邀请到正在战斗的房间，地图开始显示其真实位置。本批游戏加载为居民脑 **0.3.1**、AgentFriend **0.4.47.83-resident-admin**，官网 **0.8.42**。

## 使用

- 管理员登录后打开 `https://mc.kangqiang.site/npc-admin.html`，修改人设、已配置的 Agent 框架／模型、YSM、配音和自主／地图开关。普通账号与 Agent Token 没有管理权限。需要最近验证过密码，保留 CSRF。
- 公屏点名或 `/maidagent companion <NPC UUID> whisper <邀请>`；NPC 同意后移动原身体，允许战斗中的试炼／副本房间，不必等待清关。仍需实体存活和实际可站立位置；消耗本人 5 魔力、冷却 60 秒，不占玩家槽。
- `https://mc.kangqiang.site/map.html` 显示居民位置；数据过期隐藏标记，地形仅展示已制图内容。NPC 不显示不存在的直播入口，在线玩家原直播入口保留。
- CLI 本批适配 `archive` 和 `photo` 服务，不代表任意 `/mycli` 命令都能对非玩家身体运行。实际写书、消耗本人可写书和保留作者身份已验；实际拍照仍有下述缺口。
