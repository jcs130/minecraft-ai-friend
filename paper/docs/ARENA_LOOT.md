# 试炼塔奖励与功能装备（AgentFriend 0.3.62）

试炼塔有 15 层；第 7 层休息，第 10、15 层为首领层。每位玩家每个游戏日每层只能领奖一次，死亡、离线、箱满与重启不会使已经结算的个人奖励掉在地上。前版已经获得的钻石甲、下界合金剑、图腾等不会被收回；本版只改变**此后新生成的奖励**。

| 楼层 | 保底装备或补给 | 设计用途 |
| --- | --- | --- |
| 1 | 铜锭 ×6、铁锭 ×3、火把 ×16 | 早期材料与照明 |
| 2 | 蜂蜜瓶 ×2、闪烁的西瓜片 ×3、箭矢 ×24 | 消耗品、酿造与远程弹药 |
| 3 | 河豚 ×2、普通弓 | 水下呼吸酿造材料与远程入门 |
| 4–5 | 附魔铁盔、铁胸甲 | 逐步补齐防御 |
| 6、10 | 轮换功能装备 | 闪现匕首 → 寒霜剑 → 赤铜纹战盾 → 踏影铁靴，按玩家 UUID 继续轮换 |
| 8–9 | 附魔铁护腿、铁靴 | 首轮打到第 9 层后凑齐铁甲 |
| 12、14 | 附魔铁盔、铁靴 | 探索与防摔用途 |
| 10、15 首领 | 首通专属武器；重打轮换功能铁装备 | 高层纪念品与战术选择，避免重复发顶级剑 |

1.20.6 原版协议没有铜剑、铜甲物品 ID，因此“赤铜柄·闪现匕首”实际是**铁剑**，“赤铜纹战盾”实际是**盾牌**；铜锭是可直接识别和拿取的原版材料。所有名称、附魔和法术刻印通过原版 ItemStack 组件传送，不要求客户端安装模组或资源包。基岩玩家由 Geyser 收到可交互的原版物品，Agent/Mineflayer 可按 `minecraft:iron_sword`、`minecraft:shield` 等真实物品 ID 操作。外观仍是原版铁剑/盾牌；若以后制作跨端资源包，才改变造型。

闪现匕首附有 `agentfriend:imprint_spell=blink`，潜行使用触发现有 `/mycli cast blink` 的位移，消耗 4 魔力并遵守 MagicSpells 冷却；寒霜剑附有 `frostnova`，潜行使用释放霜环，消耗 7 魔力并遵守战斗技能冷却。两者仍能像普通铁剑一样近战。右键空气或方块均沿用现有刻印入口；手柄玩家可潜行使用，Agent 可直接执行 `/mycli cast blink|frostnova`。施法成败、魔力与冷却仍以服务端回执和私有状态频道为准，物品描述不构成无限施法许可。重复且未装备的功能装备可按报价回收，首通专属武器不可回收。

普通额外战利品主要是箭矢、铜铁锭、青金石、附魔之瓶、火把和少量金苹果；进阶档是附魔铁装备。稀有档仍有功能装备，但不再随机掉钻石套装、钻石剑、下界合金剑、三叉戟、图腾或附魔金苹果。普通/冒险/末日基础稀有率分别为 `(7 + 层数)%`、`(12 + 层数)%`、`(17 + 层数)%`，保底分别是连续 6/5/4 层未得稀有；第 1–3 层稀有档仍只给材料/消耗品。高难度会略微提升随机装备已有附魔，玩家等级高于所打难度时仍按 [难度与奖励衰减](ARENA_DIFFICULTY.md) 降低重复奖励。

第 10 层首次首领宝藏“深渊裁决”改为附魔铁剑，重复宝藏轮换闪现匕首、寒霜剑、铁斧；第 15 层首次宝藏“星灯誓约”保留一件附魔钻石剑作为稀有纪念物，重复宝藏轮换功能铁装备。第 15 层固定材料仍有钻石 ×1。旧版物品与已经写入个人箱或待领取队列的奖励保持原组件，不追溯替换。

`/mycli arena loot` 的本人回执 `MC_DUNGEON_SET schemaVersion=2` 使用 `equipmentIndex`、`next`（原版物品 ID）和 `nextName`（稳定英文标识）表示下一件功能装备；持久配置沿用旧 `dungeon-diamond-set-index` 路径，避免清零既有玩家的轮换位置。每次结算另向本人发送 `MC_DUNGEON_LOOT`。入口与楼层的个人箱可像原版箱子一样取放，Agent 可用 Mineflayer 标准容器 API。直接发成品药水仍暂缓，因为现有 1.20.6 Mineflayer 协议库曾无法解码 `potion_contents`；酿造材料与蜂蜜瓶、金苹果可直接识别。

调平需要观察正常生存挑战的死亡率、耗时、物资消耗和重复刷塔次数；隔离服通过命令清怪只用于验证发奖与物品协议，不能证明玩家或 Agent 的实际战斗难度。
