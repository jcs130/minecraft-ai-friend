# Numen 托管、系统 1 与网页语音

2026-11-13 千灯纪正式服更新了两份托管 Numen 组件至 1.21.1 的 `0.1.5-hosted.1`。专用服务随后加载 MC 核心 `0.5.7-rc.160-preview.59` 和自治运行时 `0.2.155`。第一轮停服经原服务正常存盘、E/F 两份冷备和恢复检查。MC 核心的后续 IPC 修复只重载托管进程与隧道。见 [托管源码 PR #196](https://github.com/jcs130/minecraft-ai-friend/pull/196) 和 [MC 核心 IPC PR #197](https://github.com/jcs130/minecraft-ai-friend/pull/197)。

- 托管首轮接管会先初始化该角色的原生执行循环。原生工具返回明确拒绝时保留连接，下一次查询可继续。传输中断后的动作按原编号核实。
- 官网托管选 Harness 时，由本机 StartLux-Decision-4B 根据当前血量、饥饿、位置和行动状态给出规划建议。低血、饥饿与原生动作进行中直接走已有规则。超时或低置信度时回到规则判断。角色仍使用自己的主模型配置。
- 网页观战对话沿用本机语音桥。录音识别生成待确认文字，确认后才发给 Agent。已说出的回复可以合成为音频。正式复验使用合成中文语音，真人麦克风和设备播放仍待实测。

隔离服实测 Qwen 经托管 Harness 驱动同一 Numen 身体移动约 5 格，StartLux 决策调用在该次联测耗时 47 ms。Gemini 经 Mineflayer 实际移动并收到终态。核心 preview.58 完整回归 3159 项通过、8 项跳过，preview.59 的 IPC 回归和打包版端到端走路通过。NeoForge 与 Fabric 的上游原生默认套件分别通过 458 项和 451 项。正式恢复后 Java 查询、基岩 LAN/NetherNet 探测和 15 处地下城只读检查均通过，旧 80 条认证和 9746 份角色相关文件已核对。首个启动探针漏列签名入口的 409 拒绝，修正探针后通过。未接管正式玩家角色。

经典 Numen 仍为 `0.1.4`，API 为 `0.1.4-qd-youer3`。新版经典候选已在隔离服恢复 mcbot 召唤、移动、原 UUID 离线常驻、踢出，以及 11 项基岩配置和召唤交互。经典版旧 Java 面板依赖已有协议兼容层。新版协议 8 对应的 Fabric 与 NeoForge 包已构建，正式替换仍待旧面板与完整游戏链验证。

回退只换对应 JAR 或托管程序包。世界、背包、认证和动作账本保留最新状态。
