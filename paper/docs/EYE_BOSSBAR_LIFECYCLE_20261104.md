# 观战 BossBar 生命周期

2026-11-04 核对正式 AgentFriend 0.4.47.52-rpg 和 CortiEyeMirror 0.1.17。隔离服使用同一 Youer 1.21.1 内核、ProtocolLib 及 SpectatorPlus。候选为 AgentFriend 0.4.47.53-rpg 和 CortiEyeMirror 0.1.18。

旧镜像只在附身时转发事件。晚附身看不到此前的 ADD，解绑后客户端也收不到原目标的 REMOVE。试炼塔只向本层参与者加入 BossBar，离层、退出和死亡的订阅没有独立撤销。

镜像现在按每条原生连接记录完整活动条。附身补发带原 UUID、标题、进度、样式和标志的 ADD，后续按原顺序转发更新。换目标或解除附身时撤销旧目标由镜像发出的 UUID。观战账号本人的原生条保持原传输，同 UUID 优先由观战账号本人持有。同名不同 UUID 均可存在，正常到期由各自来源撤销。无 ADD 的未知 UPDATE 不会被转发或变成合成条。观战连接断开时释放缓存。

试炼塔向在本层的有效参与者显示 BossBar。离场、死亡或断开会退订，首领死亡先发归零更新再发 REMOVE。修复范围限于 BossBar 显示与订阅。

构建器 `paper/ops/build-eye-bossbar-lifecycle.py` 固定两份基线的 SHA-256。输出以 JAR 内实际版本区分，现役 AF 文件名与版本不同。安装只能在正常停服、E/F 冷备完成后执行。回退只换回两份原代码 JAR，保留最新世界、玩家和账本。

## 验收记录

旧版 0.1.17 在隔离服复现晚附身 UPDATE 先于 ADD 和解除附身后漏 REMOVE。候选冷启动后通过 9 项检查并记录 58 个原生包。测试使用独立账号、原版命令创建的 BossBar 和独立服中的真实试炼塔事件。构建对比确认试炼塔类有 171 个原方法保持，另两份嵌套类的方法也保持。两份候选共保留 646 个其他归档条目。

- 晚附身 A 时观战端对 `0878999f-97d4-47d3-a526-9ddbece4c780` 先收到 ADD 83%，再收到 UPDATE 50%。切到 B 时先收到该 UUID 的 REMOVE，再收到 `99dac8d5-918d-488c-8cb4-416a3262a471` 的 ADD。
- 试炼塔离场时玩家和观战端同时收到 `25b68f02-5875-459a-a02b-5a8f5277a277` 的 REMOVE。首领死亡时，两端对 `1e014954-3582-45b5-9d48-e69ba53cd890` 都依次收到 ADD、UPDATE 0%、REMOVE。
- 同名不同 UUID 各自正常到期。同 UUID 若原生和镜像同时拥有，解绑保留原生条。摄像机断开重连及目标死亡也通过原生包检查。

正式服仍在使用原两份插件。正式 live 的原生画面、长期自然挑战以及代理转发后的包序尚待部署后验证。隔离测试没有改动正式角色与账本。
