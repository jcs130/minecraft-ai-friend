## 场景与照片

拍照命令保持不变。原生相机在干净 PNG 成片后，使用自己已经收到的世界保存 `mc-photo-scene/v1`：真实世界 UUID/维度、拍照位置和方向、方块及群系注册表、原始区块节和光照、附近实体姿态/装备、YSM 绑定及原文件校验值。默认半径3，最多49个区块列；不会额外加载世界。原生客户端和模型资源按 SHA256 私有去重保留，大文件直接上传现有 OSS。

照片编号沿用服务器原任务 UUID，并与作者 UUID、原始 PNG SHA256 同时校验；ImageFrame 重编码不会串档。场景保存失败不丢弃照片，管理页显示状态；旧照片不伪补历史场景。场景属于有范围和缺失说明的局部记录，不是服务器备份：未收到的远景、方块实体内容、完整实体元数据及精确投影矩阵仍未保存。

网站“我的照片”增加场景存档与原始素材下载。原片公开流程不变，场景文件仍只给所属账号与管理员；匿名不能直读私有对象。数据库仅保存元数据/资源索引，场景和素材在 OSS。ECS 使用仅能读写该桶 `photo-scenes/` 前缀的临时角色，不新增长期访问密钥。源码和公开下载不含私人配置、相册、场景、密码或密钥。

只更新官网、家庭资料同步和相机桥；共享网页包另与 SYSTEM 观战后台匹配切换。Paper、登录代理与玩家连接无需重启。正常桥重连须等相机空闲，使用原认证控制及原守护器，保留女神人设、模型和七项任务；SYSTEM 任务正常停启仍需操作者完成 Windows 系统确认。
