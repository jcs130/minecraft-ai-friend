# 亡灵墓穴的实体探索入口

2026-10-18 已在正式主世界建成，Paper 无需重启。地图标记为 X=-425、Z=677 的 `nova_structures:undead_crypt`，现在有可以步行往返的入口。

## 玩家怎么进去

1. 出发前去冒险者公会门口的公共补给箱准备装备、武器、工具和食物。用 `/mycli guild shared` 查位置，按需取用。
2. 到主世界 **X=-460、Y=65、Z=679** 的木棚入口。地图标记附近的路牌和有灯的石砖路会指向这里。
3. 沿三格宽台阶向北下行；上层平台向东转，沿第二段台阶向南下行。
4. 底部跟灯向西、向北，尽头向东，进入墓穴侧门 **X=-445、Y=28、Z=653**。
5. 在真实遗迹内探索，按 `/mycli tasks status` 显示的缺项继续。完成现场要求后沿原路返回原接单点，主动交付。

这是原图委托中的自然遗迹。地图标记是定位参考；进入墓穴后才开始记录遗迹走查。入口矿道本身不会计入遗迹探索。原图、原委托和已有进度都可以继续使用。

地下城保留原有怪物和风险，建议穿好装备、带上食物和照明。公共入口台阶与灯路受保护，可以直接步行通行；周边野地按现行拆建规则操作。

## 女神如何指引

先用 `read_player_world` 查询本人当前委托和 `guidance`。对这处已建入口的墓穴，可以指出上面的木棚与台阶路线；精确空间答复仍需用只读世界工具核对入口方块或已登记公共地标。资料里的路线不能代替实时世界查询。

普通玩家查询 `/mycli tasks status`，根据实际 `missingConditions` 与 `nextCommand` 继续。各场次门槛以本人冻结规则为准；不要把一个场次的分区数、照片条件套给所有人。
