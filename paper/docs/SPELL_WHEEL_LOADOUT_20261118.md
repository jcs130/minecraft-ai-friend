# 个人八槽施法轮盘

本批为候选实现。生产游戏服尚未加载此改动；代码、隔离验收、部署和真人设备验收分别记录。

## 玩家操作

技能罗盘打开冒险大厅，再点「施法轮盘」；潜行使用罗盘也能直接打开。已有千灯 Controls 的 NeoForge 整合包仍使用圆形轮盘和原快捷键，原版 Java 使用同一套图标菜单，基岩版使用可点选的表单。

轮盘默认打开「我的快捷」，八个位置可以混排通用技能和本人已学的职业技能。没有个人配置时，推荐布局先放至多四个已学职业技能，其余位置依次放治疗、霜环、闪现、队友支援等通用技能。

点「配置轮盘」→ 选择槽位 → 选择技能，即时保存。可切换通用／职业目录、清空单个槽位，或恢复推荐布局。已放入轮盘的技能再次选到别处时会移动，不重复占两个位置。返回轮盘后再点技能才会施放，配置过程不学习、不改原法杖绑定、不消耗魔力。

「职业技能」「通用技能」「我的快捷」可循环切换；完整技能目录仍保留分页，不受八个快捷槽位限制。需要队友或目的地的技能仍先选择目标。快捷位置保存在服务端本人 UUID 下，重登和换设备沿用。职业变化或后端暂不可用时保留旧绑定并提示不可用，不偷偷替换为别的技能。

## 实现边界

- `SpellWheelLoadout` 只处理八槽偏好；可配置的职业技能来自当前原生 RPG 的已学能力目录。
- `PlayerAdventureMenus` 复用已有 actor-bound 单次菜单票据、主线程动作和原技能施放器。配置提交时重新查询可用能力，不依赖旧菜单缓存授予技能。
- 配置位于 `spell-wheel.players.<uuid>.slots`，使用已有 `DurableConfigStore` 持久提交；不会覆盖角色、装备、学习、金币、冷却或队伍状态。
- 服务端菜单标题协议、36 格容器、八个施法槽位和导航槽位均与已有 Controls 一致。新增编辑和选择页为普通菜单，无需为本批更换客户端 JAR。
- 发布补丁只包含三个类及其内部类和版本描述，基于已部署的 `0.4.47.87-npc-combat`，目标版本为 `0.4.47.88-wheel-loadout`。不会拿仓库整包覆盖正式服的其他补丁。

## 可重复验证

纯规则与菜单票据：`python paper/ops/test-player-ui.py`。CI 同时检查新联机脚本与原武器轮盘脚本语法。

联机脚本：`paper/plugins/AgentFriend/tests/spell-wheel-loadout-stage.mjs`，只接受标记为 `SYNTHETIC_WHEEL_LOADOUT_ONLY`、Java `127.0.0.1:26875`、RCON `127.0.0.1:26876` 的隔离服。使用两名离线测试角色，不复制真实玩家背包。

隔离只读探针由 `paper/ops/build-spell-wheel-qa.py` 构建；仅从控制台读取两名测试角色、原生能力、资源、背包摘要及个人配置。将 Floodgate 官方 JAR 放在隔离根目录的 `qa-floodgate.jar`，只加载其中的真正 Cumulus 编解码器验证表单，不启用代理登录、包注入或模拟真人触控。探针拒绝非标记环境，**不随生产补丁发布**。

运行前设置 `WHEEL_LOADOUT_STAGE` 和已有 Mineflayer 安装的 `MINEFLAYER_PACKAGE`，执行上述 `.mjs`。`--before` 在旧版应因缺少配置入口而失败；候选执行完整检查；正常停服重启后使用 `--restart` 回读原配置和角色摘要。

验收记录与制品摘要在候选清单中归档。基岩真机触控、手柄和 NeoForge 实际画面须另行验收；服务端协议检查不冒充这些设备的视觉验收。

本轮使用 Youer `1.21.1-e3158632` 的独立测试世界、现役 RPG 与 AgentFriend 基线，仅两名轮盘测试角色及原武器回归角色。旧版本在等待完整菜单内容后确认缺少配置入口；候选通过原生职业技实际施放、魔力扣除、冷却拒绝、两玩家独立配置、普通物品保留、重连回读与真实 Cumulus 编解码检查。武器回归额外覆盖命中、右键、潜行右键、原法杖绑定、随机刻印以及轮盘共用冷却。正式整套模组、原玩家设备与现场战斗验收不包含在这些隔离结果里。

## 发布和回退

加载需要正常重启游戏服，不能在线替换类或 `/reload`。正式发布前重新校验现役基线摘要及安全窗口，按既有流程公告并只在 F 盘留回退。

回退仅还原 AgentFriend 代码制品，保留最新世界、角色、背包、其他配置和本批快捷偏好；旧版本会忽略新增偏好字段。不得用整份旧配置或世界覆盖玩家的新进度。恢复新版本后可继续读取已保存的快捷槽位。
