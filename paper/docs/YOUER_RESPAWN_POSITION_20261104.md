# Youer 重生位置修复

Youer 1.21.1 build 920 的三参数重生流程创建了新玩家实体，但发送重生位置时，网络连接仍指向已移除的旧实体。传送保护检查因此提前退出。客户端收到重生与血量恢复，却收不到位置，可能一直等到重连才恢复操作。

补丁在原有的传送调用前把连接绑定到已初始化的新实体。传送保护、落点及传送确认继续走原有流程。NeoForge 21.1.252 服务端库仅有 `PlayerList.class` 内容改变，其余 2558 条归档记录内容相同。此前的实体持久化补丁保留。

[Youer 上游重生实现](https://github.com/MohistMC/Youer/blob/e315863237815205021e0255f3057cca22eb28a0/patches/net/minecraft/server/players/PlayerList.java.patch#L665)

## 隔离验收

- 原库通过普通死亡复现缺少位置包，未涉及试炼塔或遗迹规则。
- 同一候选通过两次 Java 1.21.1 直连重生和一次独立 Velocity 转发重生。代理测试收到原生位置包，回送匹配的传送 ID，随后服务端观测到角色实际行走。
- 第二次构建的 SHA-256 与候选一致。构建器固定输入摘要并检查归档变更，部署与回退均只替换这一个库。
