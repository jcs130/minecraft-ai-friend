# 村庄练习塔掉落平衡（候选）

正式服当前仍为 AF.66，本页是下一批候选，不能把规则测试当成已经上线。

普通难度的低成本练习不应同时刷出大量保底装备、首领轮换和高稀有度物品。原 `roll` 的传奇门槛只看六层以上，未按难度隔开；保底装备除个别深层武器外可每日重复，十/十五层宝箱又独立叠加，普通十五层首通还固定给钻石剑。新奖励仅影响未来结算，既有物品、待领队列、首通标记、积分和角色不迁移。

| 规则 | 普通 | 冒险 | 末日 |
| --- | --- | --- | --- |
| 随机额外掉落 | 补给、材料及基础研习物品 | 按层数的既有池 | 按层数的既有池 |
| 分层保底装备 | 每层仅首通一次 | 保留原轮换；深层两件武器仍仅首通 | 同冒险 |
| 十/十五层重复宝箱 | 材料补给，不再轮换成装 | 原轮换；十层不发光环 | 原轮换；十层不发光环 |
| 随机传奇 | 无 | 无 | 十二层起才可能进入 |
| 随机/轮换光环 | 无 | 十一层起 | 十一层起 |
| 十五层首通剑 | 铁剑 | 铁剑 | 钻石剑 |
| 新附魔上限 | 前五层1条/I；六层起最多2条/II，无修补 | 前十层最多2条，深层最多3条；等级最高III | 深层最多4条，等级最高IV |

种类、数量与等级仍随机，遵守原版物品适配及互斥规则，保留呼吸/摔落保护等用途。附魔存储结构及旧 `enchantmentSchemaVersion=1` 不变，新增 `rewardProfile=village_training_v2` 表明新平衡。`arena loot` 明确是练习奖励，并把轮换预览与本人本次保底分开。正式楼层与新遗迹继续沿原 SiteDungeonManager/Vortex 奖励权威，不让训练掉落替代正式攻略。

回归先在旧实现复现普通附魔超预算，再校验普通全层预算、传奇/光环门槛、首通与重复差别、原版互斥及高难品质差异。原生物品回读须独立完成；正常装备实战、经济流通和真人体验仍需观察。不得因为平衡调整清理玩家现有装备或回灌奖励账本。

候选需独立 CI、制品摘要、正常停启及当前 E/F 冷备；已消费的 AF66 维护入口不复用。
