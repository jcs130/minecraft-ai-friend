# 艾恩葛朗特第一层 · 失联信标

首个可玩章节配套 AgentFriend `0.4.47.82-lost-beacon`。村庄试炼塔仍可用来练习远近程配合和救援。本章在艾恩葛朗特原图的环形建筑内展开，使用既有前哨、拱廊、石梯和斗技场。运行章节无需搭建新地图或下发客户端模组。

1. 在东侧前哨集结，查看普通、冒险和末日的准入要求。队员可以各选一个局内祝福，由当前节点内第一位确认的合格队员决定全队路线。
2. 暗道要调查北廊两处印记，能提前掌握守关者的震地节奏，首次震地多预告 2 秒。东门则有三名守卫，可以利用低拱的柱脚躲箭，通关多得 1 铁锭。
3. 在西廊接出失联队员，陪同这个真实村民实体走进安全区。接应失败时，在原接应点带回信标也能继续。成功护送在营地有强化收益。
4. 在南廊营地可以把个人祝福更换一次。锋刃增加近战基础伤害，远望增加本人发射的箭或三叉戟伤害，守势减免当前战场敌人的伤害。基础修正是 2。救援成功后在营地选择的祝福修正为 3。每人只有一个生效，且只对当前战斗室的合法事件生效。
5. 走石梯上看台关闭两处供能封印，守关者会失去震地。也可以在下层宝库廊击败精英，保留震地并在通关时额外获得 1 铁锭。
6. 到中央斗技场挑战守关者。震地在地上标出 4 格红圈，蓄力结束时按圈的实际位置及高度计算命中。可沿廊道撤开。守关者或队伍退出战斗会终止本次震地。
7. 实际参战或参与现场目标的人获得个人结算。已在场且能安全返程的玩家回到东侧前哨，可以领取个人箱奖励或留影。

沿用正式第一层的 Vortex 职业准入、每日奖励份额、原有三档难度、三次战败和存档点续接。普通难度候选为 12 绿宝石和 4 至 6 铁锭，最高材料量与旧第一层一致。局内祝福保存在本场记录中，补给和长期装备继续由现有经济与奖励系统管理。首领血量、收益和路线耗时仍需不同职业的真实玩家实测。

## 游戏内操作

在技能罗盘打开「正式楼层攻略」。开启「失联信标」时，地下城菜单展示当前目标、祝福与路线。金色地砖标记可以右键交互，也可以走近后在菜单确认。每个选择会校验所在维度、房间和接近情况，隔墙和跨层操作会被拒绝。

Agent 使用 `/mycli dungeon info aincrad_01 --json` 查询准入。从 `/mycli dungeon status aincrad_01 --json` 读取 `participant`、`chapter.objective`、`chapter.options` 和 `chapter.intent`。`available=true` 的选项附有绑定本场与当前节点的 `command`。同一选项重放返回既有结果，冲突选项返回当前状态。结果未知时查同一场次。对队员而言，`release` 表示开始接应，`rescue=safe` 才表示实体已经到达安全区。奖励使用既有 `/mycli dungeon claim aincrad_01`。

## 候选安装和旧进度

使用 [章节布置](../config-candidates/aincrad-lost-beacon/aincrad-beacon.yml) 作为独立的 `plugins/AgentFriend/aincrad-beacon.yml`。新版会在启动时读取它，并核对原 `aincrad_01` 和版号。旧 `dungeons.yml` 仍是正常攻略和其他遗迹的定义。原场次使用原地图签名，后续空闲开场才采用章节布置。含新章节的存档会核对路线与现场标记，布置不匹配时保留原存档待处理。

正式服原第一层仍有一份在第三段前因存储故障暂停的场次。两段参战记录需保留。候选新增的续接路径要求该队无人在线参战、本人已有原参战记录、到原遗迹且战备合格，并核对存储没有未知提交。原队员可用 `/mycli dungeon resume` 续接同一场次。新章节与旧场次共用斗技场，空闲后才可开新章。

发布要使用实际地图核对入口、标记、保护和原检查点，通过既有维护窗口正常停启。只用 F 盘备份。需要回退时先停止新开场，保留运行中的章节与最新记录。场次结清后再调整章节配置或代码。

## 测试入口

`scripts/build-lost-beacon.py` 先按 `.81` 正式制品逐字节核对受影响的旧类，再制作候选 JAR。规则测试覆盖分岔、祝福、重复选择、两处封印和持久状态。`tests/LostBeaconQa.java` 和 `tests/lost-beacon-stage.mjs` 只允许有专用标记的回环隔离服，使用合成角色。走路和菜单使用普通 Java 协议。机制测试对真实刷出的怪物注入伤害、触发受控失败，与玩家自然通关分开记录。原可米会话、手机手柄、Eye/Web画面以及长期数值平衡另行验收。

玩法依据是千灯纪的[分支远征设计](ROGUELITE_ADVENTURE_DESIGN_20261115.md)。路线收益取舍来自对 [Mega Crit 游戏说明](https://store.steampowered.com/app/646570/Slay_the_Spire/) 的参考。永恒世界的对照采用用户提供的公开规则调研，落实在入口、准入和结算的可查性。
