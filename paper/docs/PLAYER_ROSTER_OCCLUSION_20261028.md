# 遮挡过滤导致的假上下线：候选0.1.3

2026-10-28：正式仍为AgentVision0.1.2；本修复已在独立Paper验证，**尚未重启或替换正式JAR**。CortiOriginal客户端不需要改动、重置记忆或背包。00:04:40的真人授权客户端重启是另一事件，不计入此前的毫秒级假上下线。

## 实际原因

旧`AgentVisionPlugin.hide()`对玩家调用Bukkit `hideEntity`。Paper同时移除场景实体和TAB玩家信息；随后插件为了保留在线名单立即补发`PlayerInfoUpdate`。最终名单看起来正确，中间的`PLAYER_INFO_REMOVE → ADD_PLAYER`却会使标准Mineflayer触发`playerLeft → playerJoined`。

隔离服使用旧正式字节码、两条不间断的真实连接及五次石墙/玻璃切换复现了五组以上虚假事件。旧测试只检查最后仍有TAB行，漏掉了中间的数据包。委托方提供的Corti/CorMy时间线与此机制一致，但短时生产诊断窗口没有抓到目标包，不能冒充已有那次生产事件的完整包栈。

## 修复

- 玩家只从Paper原生实体跟踪器解绑、恢复场景配对；不再移除、重建TAB身份。非玩家沿用Bukkit实体隐藏。
- Paper1.21.1在可取消跟踪事件之前就加入`seenBy`，取消后不回滚。对没有真正发送过出生包的玩家配对只撤销这个登记，避免既泄露后续实体数据又无法重新显现。
- 同一检查间隔复用可见性结论；预算不足不重复对已处理的目标做整套隐藏。
- 替换的身体实例重新建立目标记录；跨世界不补发旧世界玩家，真实退出不先重新显现被遮挡的身体。
- 原遮挡几何、距离、付费技能揭示、观察者例外及其他插件的vanish规则保留。不是关闭反透视。
