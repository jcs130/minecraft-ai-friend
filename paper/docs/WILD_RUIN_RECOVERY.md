# 野外副本和建筑的自动复原

已经登记在 `plugins/AgentFriend/dungeons.yml` 的野外副本，共用每个地点的运行状态、保护范围和方块日志。玩家步行来到遗迹也使用同一份记录。十境遗迹已经登记，包括黑帆海盗湾、潮汐沉没圣所、霜落古堡、深岩失落矿城等。没有登记的自然建筑或玩家住宅保持原有规则。

结束一场副本后，系统等待在场的人离开，再分批还原这一轮记录的修改。闲时探索的修改在该地点连续空闲约五分钟后复原。每批施工前，服务端会重新检查在线玩家（含旁观、Mineflayer 角色）与已加载的托管居民身体。在同一地点有进行中、暂停或无法读取的场次时，野外定时器会等待。重启后从第一次空场观察重新计时。副本恢复时，下一队可先去别处，待场地恢复后再入场。

运营可以在 `plugins/AgentFriend/wild-ruins.yml` 添加独立展馆、遗迹等公共建筑。配置在服务启动时读取。省略该文件时，已登记的副本仍启用默认五分钟空闲恢复。下例仅演示格式，坐标须换成现场核准的两角，以免误圈其他建筑。

```yaml
schema-version: 1
empty-seconds: 300
buildings:
  gallery:
    name: 山间展馆
    world: aincrad
    bounds: [12000, 70, 12000, 12020, 88, 12030]
```

六项坐标依次为整数 `minX, minY, minZ, maxX, maxY, maxZ`，包含两端。独立建筑的六个外表面受保护，内部可按副本规则使用。配置只接受已加载世界，拒绝与已登记领地、副本或其他独立建筑相交，最多可设置 64 处。空闲等待支持 1 至 86400 秒。调整或移除登记前，应先清空现场并等待原登记的日志完成恢复。

自动复原按首次受支持修改前的状态回放，只处理记录过的方块。它不会全图扫描、重新生成区块或补发副本奖励。已经发生的历史破坏需要从之前的备份恢复。WorldEdit 也可以在管理维护时选择一个区域并从已有备份恢复。[WorldEdit 快照文档](https://worldedit.enginehub.org/en/latest/usage/snapshots/)

## 墓穴临时搭建

启用 `crypt-temporary` 后，亡灵墓穴的生存参战者可在预先登记的内部格放置圆石等稳定方块或工作台。每格原本须为空气。已有领地、建筑外壳、入口平台和保护插件仍按现有规则校验。回放使用副本的方块日志，在原有空场检查通过后还原，下一场等复原完成再开。

下面的世界 UUID 和坐标用于说明格式。启动前替换为隔离服实测值，再启用。

```yaml
crypt-temporary:
  enabled: false
  world-uuid: '00000000-0000-0000-0000-000000000001'
  reserved-boxes:
    - [102, 42, 104, 104, 45, 106]
  materials: ['minecraft:cobblestone', 'minecraft:crafting_table']
  maximum-cells: 128
```

编辑以现有正常参战时段为准。上限按同一场地日志里的原始格计数，包含为安全回放而登记的相邻格。
