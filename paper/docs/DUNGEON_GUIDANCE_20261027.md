## 可米为什么总回到墓穴

只读记录显示她仍接着10月21日冻结的 `tm_crypt_report`：首阶段要求在接单后清完 `undead_crypt` 三室、返回首室并实际结算，下一阶段才交两张纸。当前阶段0/1，最近场次结束原因为 `party_left`、清理0室、没有待领奖凭据。当天日志在09:16–11:20反复出现info/status，不能据此断言模型的主观原因。

服务端存在两项可复现的误导：`active=false` 实际指当前无活动场次，未注明它不是未开放；SITE_CLEAR通用指导仅返回“清场还差1次”和继续查任务状态，没有连接运行中的房间、入场、冷却或领取步骤。旧说明还把“亡骸地窖调查”和当前显示的“亡灵墓穴·三室封印”并列，增加了认知成本。候选按稳定地点ID解析当前名称，保留冻结任务和奖励条件。

## 保留的入口

```text
/mycli status
/mycli tasks status
/mycli skills status
/mycli dungeon list
/mycli dungeon info <ID>
```

不添加另一套入门、任务或施法命令。已有 `start/join/resume/leave/claim` 仍兼容；先看当前一步再操作。帮助只读，每页最多七项；默认精炼中文，`--verbose` 查完整路线，`--json`按需取得原字段及实际引导。JSON是格式选择，start等动作仍真实执行；不支持JSON的旧menu在打开前拒绝。旧无固定入口的远征传送明确拒绝JSON格式，不假称已支持。

info显示普通难度星级、建议战斗等级、武器护甲/盾/食物、当前角色装备概况、单人或队伍搭配、对应职业技能。建议不是新硬门槛；正式攻略原有最低等级/前层条件照常生效。冒险/末日的生命倍率为1.5/2.1、伤害倍率为1.25/1.6；info明确普通远征和Mythic精英的区别，正式首层普通也启用Mythic首领。

| 实际情况 | 下一步 |
| --- | --- |
| 空闲，人在外面 | 明确可开，先传送到入口，再沿实际路线进首室 |
| 已在场地但没到首室 | 给首室坐标与原路线，步行进入，不反复传送 |
| 到首室且可开 | 本人start普通难度；不等系统自动开 |
| 正在10秒集结 | 留在本次集结；队友主动join，不重复start |
| 正在战斗/移动 | 给当前房间和剩余敌人数；行动后再查 |
| 全室已清 | 返回首室并结算，不能把清怪当领奖 |
| 已保存领奖凭据 | 直接claim，不要求重新打一遍 |
| 他队占用或场地冷却 | 给明确原因/剩余时间，改选空闲地点，不原地死等 |
| 运行故障 | 保留进度，明确不能靠等待推进；服主处理后本人一次resume再核对 |
| 地点/配置不可用 | 明确不可用，原任务保留；不自动取消、重开或补奖励 |

五处建议是本服Minecraft战斗平衡建议，不冒称SAO官方未公开的数值。现有任务、参战明细、冷却、去重、个人奖励箱与物品不迁移；没有替可米完成委托或发放通关证据。
