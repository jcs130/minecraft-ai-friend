## 范围与实现

根据原免费首层地图的墙体、水道和地形核对，起始之城中心为 `aincrad (-584, 934)`，保护沿半径约 366 格的 64 点多边形覆盖城墙与护城河。矩形包围范围 `X=-950..-218，Z=568..1300` 只用于已有 BlockAccess 策略；四个矩形角落另有放行多边形，不会把圆形城外的角落误判成城区。高度为世界完整高度。

复用既有 WorldGuard 与 `mycli admin blockaccess reload --json`，没有修改 JAR 或增加 CLI。城区显式 `build: allow / block-place: allow / block-break: deny`，使现役 AgentFriend 的权限预检与真实方块事件一致。只改 block-place 而继续 build:deny，会导致 Agent 预检与实际放置不一致。[WorldGuard 规则说明](https://worldguard.enginehub.org/en/latest/regions/flags/)。

`/aincrad` 私有说明已同步；Agent 按需用现有 `/mycli protect place|break <x> <y> <z>`，多个点用 `protect batch`。不重复查询同一拒绝，也不向公屏转发工具结果。具体副本要求仍以当次回执为准。
