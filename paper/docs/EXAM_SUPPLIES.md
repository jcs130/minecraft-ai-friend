## 玩家怎样操作

公会→训练与考试→当前考试指引与材料。六张步骤卡按顺序说明准备、接取有效委托、实地调查、现场摄影、按本单返程、最后交付考试。下排可点击领取材料、免费取出材料、打开女神相机、选择探索委托、核查缺项与交付；原版箱式菜单可用手柄操作，不必输入命令。命格书补充该入口。

调查考试有不同路线：

- **入门走查**`tm_starter_trail`：不要求藏宝图或寻找稀有遗迹。真实走过主世界3个不同的16格区域、48格新路线及15秒有效行进，并完成本场摄影。
- **自然建筑调查**：按已接任务的具体结构、区域、距离、时间与高差走查。指引读取这张在途委托的冻结数字，不靠名字猜要求。已接的沙漠神殿走查仍保留，不自动换单。
- **原图寻宝**`tm_map_hunt`：主手拿真正带目标的地图，先`guild map`核对，再接单。完成天然结构走查和现场照片后，回接单点16格内交付。已有埋藏宝藏图仍遵循[原图寻宝](TREASURE_MAP_TASKS.md)的真实开箱规则。

照片必须在开考、接单后于目标现场拍摄；每个探索阶段至少1张，要求多群系时每种各1张。相机无需空地图或主背包空位，实际开始拍摄默认耗2魔力，成片自动入个人奖励箱；箱满原片排队。拍摄队列、冷却和相机就绪条件保留。旧照片、复制图、查询和领材料不能代替实操。整张委托及照片完成、考试`state=ready`后，才交付证书或晋级。

## 考场提供什么

**摄影直接成片**：0.4.47不再分配新的空地图。`supplies info photo`返回`not_required/required=false/count=0`；`claim photo`为成功且`changed=false`的空操作。原0.4.44测试时的8张地图分配保留，`take photo`仍只取已发原物，不复制。菜单对应位置改为打开个人奖励箱取照片。

**遗迹探险图**：在指引主动领取。它是原生`filled_map`，有实际地图ID、中文名称、原生`map_decorations`目标标记；不是改名纸或空白地图。当前目录包括黄沙神殿、亡灵墓穴、蔓生墓穴。若已经接下指定结构调查，只匹配该结构的已勘察地点，不发一个无关建筑的图。无匹配地点或天然结构无法核验会明确拒绝，不伪造可用地图。

黄沙神殿目标为主世界 **X=-1926、Z=-966**，按天然结构元数据验证；不提供藏宝深度。后两处使用真实注册键`nova_structures:undead_crypt/creeping_crypt`。这些都是既有天然建筑；地图不会报名地下城战斗或发放战利品。**考试发的是遗迹探险图，不承诺一个未被别人开启的藏宝箱。**

明确领取时异步读取最多25个已有区块；验收期间只临时持有本次新增的插件区块票据，完成/失败即释放，不清除其他功能的票据。缺失区块或天然结构无法核实则不发图，查询不加载目的地。

材料首先安全登记到本人的原个人箱，返回页码和全局槽位；箱满进入原待入箱队列。再点击**免费取出考试材料**，只把对应原物品转入本人主背包；不要求先学传送术、不扣魔力，也不开放其他箱中物品。主背包满时不移动、不丢地，腾出空间后再取。原个人箱普通取放及远程费用保持。

如果已经用普通箱子操作取走或移动材料，免费取物命令不会重新生成；先核对本人背包和原分配记录。同一次考试的地图分配可在掉线后查询原地图ID，不会因重试改发下一个目的地。每人每目的地仅提供一次，目的地完成/领奖去重规则继续生效。

## Agent 命令和私有数据

```text
/mycli guild exam status --json
/mycli guild exam guide --json
/mycli guild exam supplies --help --json
/mycli guild exam supplies list --json
/mycli guild exam supplies info map --json
/mycli guild exam supplies claim map --json
/mycli guild exam supplies take all --json
/mycli guild exam supplies status --json
```

`claim/take`也接受`photo`；`take`可选`photo|map|all`。查询不会报名、发物或加载地图目的地。新入口支持逐层帮助，参数错误在动作前拒绝；`--json`只改变格式。

沿用本人私有`MC_GUILD_EXAM`与`mcagent:exam`，UTF-8 JSON，`schemaVersion=1`、`scope=self`、`subjectUuid`。新增：

| 字段/状态 | 用法 |
| --- | --- |
| `guide.steps[]` | 有序`id/title/instruction/command`，按需读取，不必盲试所有任务 |
| `guide.currentContract` | 本人已接的冻结要求、当前阶段和摄影缺项；不是全服状态 |
| `type=supplies`、`action`、`id` | 区分查询、申请发放、取物及材料种类 |
| `status=pending` | 原有天然建筑核验中；不是已经发图。查询`supplies status`，不循环接单 |
| `reason=allocated_to_personal_storage`、`saved=true` | 已保存分配；`allocation.items[]`给原箱页码/槽位或`queued` |
| `reason=already_issued` | 沿用原分配，不重复发；图有原`mapId`可对账 |
| `reason=taken_into_inventory`、`saved=true` | 对应实物已免费转入本人主背包；`items[]`为实际数量 |
| `reason=already_taken` | 成功的重复调用空操作，不多给一份 |
| `inventory_full` / `already_taken_or_moved` / `supply_save_failed` | 腾空间、查现有物品或联系服主修复存储；不能当成功自动继续 |
| `map` | 原生地图ID、维度、世界UUID、绝对X/Z、实际结构键；`heightKnown=false` |

普通玩家不接收别人的回执。原授权Eye镜像规则保留，本轮不改直播客户端或远端Web。
