## 同一条命令，有限范围内恢复

入口仍为 `/mycli cast home`，通用、无需学习，6魔力、无冷却。原点安全则保持原坐标、朝向；原点受阻才搜索水平半径3格、上下2格的附近落脚面。按到原点的距离确定顺序，同距优先保持高度，结果确定且不会拆任何方块。

`HomeLanding` 沿用智能闪现已经核验的原生 VoxelShape 坐标约定，独立用于公共归乡，不引用另一个插件的数据目录类加载器。检查完整人物宽高、世界高度和边界、脚下中心与四角支撑、液体、浸水及伤害方块。可以使用真实半砖表面，不把栅栏顶点当成稳定地面。

每次最多读取512个已加载方块。只允许原目标的一个已生成区块以 `loadChunk(x,z,false)` 加载；不生成新地形，不逐个加载搜索邻区块，不扫描整个村庄。看不到的候选不会被选中。

原有传送保护事件仍有最终取消权；事件改写的目标须再次通过同一范围与身体检查。成功后、扣魔前再核对实际位置，异常改写则不扣魔并尝试退回出发点，不强制绕过其他插件。成功的 `MC_DESTINATION` 使用实际落点的原有整数坐标格式，`MC_TRAVEL` 仍使用原协议与单一 Vortex 魔力池。
