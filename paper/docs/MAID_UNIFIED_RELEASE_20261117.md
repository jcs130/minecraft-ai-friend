## 控制、对话与记忆

`NativeMaidBridge` 使用本机鉴权端口，仍操作原 EntityMaid 和原主人绑定，不需要创建玩家连接。`bind` 默认暂停原自主控制；`companion` 明确委托原跟随、护卫和所选原生对话脑。有限行走、工作、停留会收回委托并递增回调代次，旧模型结果不能继续操纵身体。更新装备、拾取或施法后可恢复原委托。释放或过期后取消端口动作，回到原生控制，不自动重放旧任务。

肥鱼保留原 DSH/native/codex 选择、TLM 历史、纳西妲音色与原私有伙伴法力池。此实现没有把肥鱼登记为公共居民，也没有把桐人的 PowerContext Scope 复制给她。`spells` 明确标注 `original_private_companion_magic`；`cast` 回读原执行器结果，不能把模式设置当成命中或目标完成。

网关修复一个真实联测发现：DSH 的已完成、单一纯文字回答曾被 JSON 计划解码器拒绝。现在只在女仆原生链路把单一完整文字封装为无工具回复；不接受截断 JSON、代码围栏、歧义多帧或额外函数调用，不生成工具、不重试模型。模型文本本身不是世界动作的完成证明。
