## 自行部署与媒体镜像

默认仍从本地`data/media`提供管理员选定的文件。需要OSS时，在已有私有配置中显式设置：

```json
{
  "downloads": { "baseUrl": "https://YOUR_BUCKET.oss-cn-hongkong.aliyuncs.com/releases/" },
  "publicMedia": {
    "objectStorage": true,
    "videoLink": "https://b23.tv/Ppfd3Ne",
    "videoTitle": "让玩家和智能体一起来自由探索冒险吧～【B站AI创造公开赛】"
  }
}
```

只有固定清单里的已选媒体会跳转；其他本地视频保持原来的范围读取。先上传并校验清单对象，再启用。服务不接受访问者提供的资源URL，不替访问者抓取网页，也不会把相邻数据库暴露为下载。

外部视频入口只接受无凭据、无查询参数的HTTPS Bilibili视频页或b23短链，打开新页并使用`noopener noreferrer`。不会自动嵌入第三方播放器。原MP4入口按固定SHA路径直达OSS，支持手机Range拖动；CSP仅给媒体增加已配置OSS源，脚本和连接策略保持同源。
