# 肥鱼驻点正式发布

2026 年 11 月 13 日，千灯纪正式服加载 0.1.28-residence。肥鱼作为第一个驻点 NPC 使用原女仆实体，不占玩家名额。主世界初始村庄工位旁 (-547, 63, -378) 是据点。可米离线且她处于空闲随行时会回岗巡逻，访客靠近会转身挥手。可米回到据点 24 格内会恢复随行。

行走、转身和挥手由服务端原生 AI 执行，不消耗模型 token。访客可点名交谈，沿用现有模型。私人合成工单仍按既有在线条件处理。

[PR #189](https://github.com/jcs130/minecraft-ai-friend/pull/189) 的六项 CI 通过，主干 d0b727cf74ab98f461957f1a2effce52d64193bf 与候选源码树一致。隔离服通过 21 项联机和重启、314 项规则检查。Mojang 原版和未改动的 Mineflayer 已完成联机。正式服在正常停机及两盘备份后安装两份文件，21 项启动检查通过。原女仆归属及大肥鱼模型已读回，公网 Java 状态和基岩网络握手正常。

正式服采样观察到肥鱼在可米离线时回岗，随后到达一个巡逻点。原生闲逛接管过寻路，观察到肥鱼偏离固定路线。持续巡逻、自然会合、访客招手和基岩真机画面仍待正式验收。

回退前请让原伙伴通过现有随行入口解除驻点，核对原作息已恢复。随后走正常维护流程，按摘要恢复旧桥并撤下本次驻点配置。保留最新世界、玩家和女仆库存、归属、生命记录、认证和回执。原实体暂时不可用时，先保留驻点状态和备份，待可观察时再核对。
