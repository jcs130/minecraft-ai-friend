# 位移与远程物品操作的施法成本

从 AgentFriend 0.3.81 起，玩家主动发起的非原版瞬移统一通过 AuraSkills 魔力结算。Java、基岩、Mineflayer Agent 使用同一服务端判定；成功后给本人原版标题、粒子、音效和 `MC_TRAVEL id=<ID> mana=<数值> dimension=... x=... y=... z=...`。`mcagent:event` 的 `home` 或 `travel` 事件与本人 `mcagent:state` 魔力更新同步提供给 Agent。未找到目标、落点受阻、保护规则取消、魔力不足时不扣费，也不发送成功特效。

| 主动能力 | 魔力 | 入口 |
| --- | ---: | --- |
| 归乡术、公共/私人传送点、试炼场入口、公会大厅、生活公会、PvP 大厅或加入匹配 | 6 | 罗盘、`/mycli`、已授权的 Essentials `/warp`、`/home` 等玩家指令 |
| Essentials 其他玩家指令传送（含经同意的 `/tpa`） | 6 | 指令真正把玩家移动时结算；发请求本身不扣费 |
| 队友安全传送、自然遗迹远征、解锁后的深层驿站直达 | 8 | 罗盘、`/mycli locate tp`、`guild travel`、`arena rest` |
| 支援传送术（20 秒冷却） | 8 | 罗盘、警报按钮、`/mycli village support [事件ID]`、`/mycli cast support`；重查活敌人及安全落点，失败不扣费 |
| 闪现术 | 4 | MagicSpells 既有技能，仍只按原有成功施法路径扣一次 |
| 远程打开个人箱，或用文字指令成功远程存取/领取一次 | 2 | `/mycli arena stash|rewards`、公会个人箱；成功后 `MC_STORAGE_MAGIC` |

站在试炼场实体个人箱旁操作免费，仍可用原版容器界面存取。副本入口按钮开始挑战、正常换层、死亡或掉线后的恢复、离开副本回地面、PvP 对局开始及结束后还原原位置，都属于活动流程或安全恢复；不构成玩家随时任选目的地的传送术。原版末影珍珠和维度传送门保留原版消耗与规则。观战账号不参与施法。管理员从控制台执行的救援传送不扣目标玩家魔力。

新增可能绕过原版移动、感知或物品流转的能力时，先确定实际收益，再写明对应魔力、生命、饱食度、物品或活动门票成本、失败时的退费和展示方式；不能只添加一个方便的免费命令。若已有内置资源成本，例如商店绿宝石余额或副本奖励资格，须在说明里明确其来源。所有会消耗资源的快捷入口需要同步更新罗盘提示、`/mycli explain`、Agent 状态/事件以及隔离服验证。
