## 经验显示缺陷

原生侧栏错误地把累计经验`xp`放在升级剩余经验`xp_next`前，出现8353/2372。实际默认曲线下，Lv5起点4980，Lv6起点10725：累计8353时本级3373/5745，剩2372。没有丢失经验，也不应强制改等级。

候选只新增只读`ExperienceProgress`投影，复用实际加载曲线；不修改升级、溢出经验或点数发放。侧栏`{xp_display}`、CLI和观战共用读数。API保留`xp`累计、`nextLevelXp`剩余的旧语义，新增`xpTotal/xpProgress/xpRequired/xpRemaining/isMaxLevel`。满级显示“已满级”，不显示0/0。

## 归乡术

村庄warp原Y66.9375位于Y66整块草方块内。已只把落点改到Y67.0，经Essentials支持的配置重载生效。世界、XZ与朝向保持，未传送玩家或降低脚下/头部/危险方块检查。

通用home正常成功消耗6魔力；不安全落点拒绝、不传送、不耗魔。候选同时删除外层重复的“公共传送点未受理”，保留实际原因和查询入口。截图FAWE报错尚未与本次home调用关联，不据此归因。

夜视/羽落还有独立缺口：通用目录已列出，但`goddessSpell`与菜单`castOrLearn`仍读旧PDC学习标记。候选仅在Vortex后端跳过这项旧门槛，不伪造PDC学习、不扣原版经验或学习点；原魔力、效果、冷却和旧后端资格保持。冷却拒绝给明确原因和查询入口，不再次扣费。

远处副本入口还有当前内核的区块兼容问题：Youer的`CraftWorld.getChunkAtAsync`及其回调只读取`getChunkAtIfLoadedImmediately`；远处已生成但未加载的区块返回null。`SiteDungeonManager.travel`因此返回`entry_unavailable`，这个分支没有检查装备或魔力，旧提示把多个原因混在一起会误导玩家。

候选新增`ExistingChunkAccess`，先走原异步接口，仅在无异常但返回null时，于主线程核对既有区块并`loadChunk(...,false)`，一次最多补读入口所在的一块。不会生成地图、无限重试I/O错误、放宽保护或直接替角色传送；后续原角色状态、安全落点、活动与8魔力结算全部保留。读取失败、尚未生成和传送资格拒绝分别提示。本批只适配正式遗迹travel入口；其他异步区块调用未据此自动宣称已完成核查。

“入口锁了”必须结合原因码判断：

| 原因 | 实际含义与下一步 |
| --- | --- |
| `entry_unavailable` | 入口区块读取失败；未传送、未耗魔。本次修复已生成冷区块返回空值的兼容缺陷。 |
| `entry_not_generated` | 目标地图尚未生成，联系服主；不能让Agent靠拆墙或反复重试解决。 |
| `boss_room_locked` / `site_busy` | 已登记队伍占用Boss房或整场；查`dungeon status <ID>`，选其他地点。 |
| `site_cooldown` | 上一场结束后的120秒冷却；不是地图或装备故障。 |
| `conquest_profession_required` / `conquest_level_required` | 正式开场缺职业或最低战斗等级；按`profession list`、`dungeon info <ID>`查询。 |
| `previous_floor_required` | 正式攻略前层未通关；练习塔成绩不能替代。 |
