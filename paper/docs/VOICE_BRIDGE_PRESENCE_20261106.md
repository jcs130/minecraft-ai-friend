# Agent 语音连接状态

状态：2026-11-06 已随 QiandengVoice 0.1.3 部署服务端修复。正式只读查询确认已有 Agent 返回 `VOICE_BRIDGE_CONNECTED`，保留真实 `installed=false`。MC 核心 `0.5.7-rc.160-preview.21` 仍为已验证的本地候选，不会自动替换远端 Agent 的插件或宿主。

## 问题和行为

Agent 已经通过当前游戏连接注册 `mcagent:voice`，可以上传音频并接收附近字幕，但 Simple Voice Chat 不知道这一接入方式。于是原生玩家看到 Agent 的红色断开图标，容易误认为服务器没有语音功能。

服务端现在使用 [Simple Voice Chat 的正式连接接口](https://voicechat.modrepo.de/de/maxhenkel/voicechat/api/VoicechatConnection.html)：仅为完成实际语音协议请求、注册了语音通道、有使用权限且未安装原生语音模组的角色设置桥接连接状态。保持原 UUID 和游戏连接；原生客户端的连接和静音状态不被覆盖。每次读取新状态，避免使用 API 返回的旧快照。

Velocity 会向后端声明代理自身注册的通道，因此单靠 `minecraft:register` 不能证明玩家启用了语音桥。新版适配器复用已有 `subscribe` 请求，按原选项选择 `events` 或 `chat`，不增加新命令或合成调用；仅声明通道的普通客户端保持断开。旧适配器发送第一个有效语音请求后也能同步状态，不要求新增协议版本。

注销通道后撤销桥接拥有的状态，退出后清理会话；重新连接必须重新注册。不抢占其他提供方已有的连接，不新增轮询、模型调用或音频重播。核心和兼容适配器的 `close()` 只注销自己的通道；网络已断开时不再发送。

`/voice status` 返回 `VOICE_BRIDGE_CONNECTED` 时，会说明这是上传和字幕桥接。`installed=false` 仍然真实保留，服务端不把该角色算成原生音频接收者。语音媒体处理失败继续返回对应请求的错误；连接图标不是媒体服务健康、客户端输出或实际听感的证明。

## 隔离验证

- 旧版在最初 22 项测试中先失败：3 项连接状态检查失败，另外 19 项通过。音频可以到达附近客户端，但它收到的 Agent 状态仍为断开。
- 通道声明方案在代理声明模拟中另复现 2 项误标失败，最终增加实际协议确认。候选在独立 Youer、Simple Voice Chat 2.6.27 和合成账号下通过 25 项网络检查。客户端实际收到相同 UUID 的 `disconnected=false` 状态；注销后为 true，再接入后为 false；代理声明不会把普通玩家标为已连接，旧适配器有效请求仍能接入，原生客户端静音与 UDP 连接不变。
- 加密 UDP 接收：附近可用端 50 包，远处端和关闭语音端均 0 包，解密错误 0。旧请求不重播。此结果不是扬声器或真人耳听验收。
- Java 规则和生命周期检查 74 项通过，其中 14 项覆盖新连接状态逻辑。MC 核心另有 4 项适配器生命周期回归，覆盖重复关闭、替换适配器、网络结束和注销写入失败。
- 正常重启后 5 项检查通过：重新确认协议才恢复桥接状态，只有代理通道声明的角色仍断开，旧回执保持且 UDP 没有重播。兼容客户端 11 项通过。
- MC 核心完整回归 2,932 项通过、8 项按原条件跳过；独立引擎构建、397 份声明及打包后公开接口验证通过。使用 4 个测试进程，未放宽超时或修改无关测试；此前缺少构建产物和高并发超时的运行记录保留。此次没有改动网页渲染器或重新发布其资源。

测试只使用回环隔离服、合成音频和合成账号；没有操作玩家密码、背包、身份或原语音请求。完整本机证据保存在受控运营目录，不将运行日志、令牌或玩家资料入库。

## 上线和回退

服务器只需替换 QiandengVoice 插件；已实际调用桥接协议的 Agent 不必安装原生语音模组。新版客户端适配器补齐连接时的订阅确认和同一连接内主动关闭语音桥时的注销。旧适配器第一次有效订阅、查询或上传后同步状态，仍会在游戏断线时清理状态，但不保证在仅关闭适配器时立刻通知服务端。

依照 [维护要求](OPERATIONS.md)，候选通过后正常停服、保留当前 E/F 冷备、单一插件替换、正常启动；不能通过 `/reload` 在线替换。保留 QiandengVoice 的 profiles、receipts 和内部配置；回退只恢复旧 JAR，不回滚玩家或语音数据。上线后按现有账号只读核对桥接状态，再由附近原生客户端检查显示和一次新请求的实际听感。历史失败或未知请求不重播。
