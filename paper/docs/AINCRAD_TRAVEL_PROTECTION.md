# 艾恩葛朗特探索地图：保护与往返

地图位于独立的 `aincrad` 世界，不与主村庄、旅人营地共用地表，不能用主世界坐标计算步行距离。当前入口为起始之城附近 `(-582.5, 69, 934.5)`。保留原村庄与营地，不迁移家园、人物或物品。

玩家和 Agent 使用相同入口，不增加另一套 CLI：

1. `/aincrad` 查看说明；`/mycli rules` 第一页也有入口与个人箱用法。
2. `/mycli skills info travel` 核对传送点术。尚未学习时，用 `/mycli skills learn travel`，需要 1 技能点。
3. 有 6 魔力后执行 `/warp aincrad`。以实际所在世界和坐标为准；命令发出不等于抵达。
4. `/warp village` 返回主村庄，同样需要 6 魔力。魔力不足先恢复，不反复重发。

远程个人奖励箱使用 `/mycli arena stash`：已学 `travel`，成功开页耗 2 魔力，无需先传送。`/mycli arena stash pages` 选页；`/mycli arena rewards list` 是待入箱奖励，`/mycli arena stash list` 是实际箱格。等待窗口与槽位确认后操作，超时先查询而非重复存取。

## 保护范围

整张艾恩葛朗特地图禁止普通玩家拆建、倒液体、点火和爆破，防止末影人搬块、活塞移动及其他环境破坏。允许正常开门、开箱、拾取、探索和怪物战斗。原先明确授权的两位建设者维持拆建权限；不扩大 OP 或通配权限。

`BlockAccessRules` 原本最多容纳 8 处保留区域，现有村庄、公共设施、矿洞入口已全部占用。上限改为 16，仍保留最多 256 个补集区域的限制；新增全世界 `aincrad` 保留范围，停止生成该世界的野外放行区域。原世界的八处范围不变。

WorldGuard `qd_aincrad_map` 为全图立方体，优先级 1000000，低于原建设者覆盖、高于普通私人领地。这样新建私人领地不能绕开地图保护。只在 `aincrad` 打开 `regions.high-frequency-flags`，用于液体和火焰检查，不做区块扫描。

参考：[WorldGuard 区域规则](https://worldguard.enginehub.org/en/latest/regions/flags/)、[按世界配置](https://worldguard.enginehub.org/en/latest/config/)。
