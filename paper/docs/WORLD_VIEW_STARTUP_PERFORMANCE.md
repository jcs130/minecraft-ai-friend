# 观战首次加载与默认第三人称（已合入0.8.17）

2026-10-25 18:42 随官网0.8.17匹配前端19768897上线；实际可米原YSM、默认第三人称可见，单次地形约3.98秒、模型约3.52秒，不能与此前不同场景直接计算倍率，也不代表手机性能。副本切换后的自动恢复仍待修，见[发布记录](WORLD_VIEW_CORMY_ANIMATION.md)。下述为0.8.16候选时的可重现测试。原共享前端源码已发布至
`jcs130/mc-visual-console@0fbf73fbf9efc9f24e31e1586d3d135729a9d90f`。

## 改动与原因

线上首次地形构建实测约 57.9 秒；隔离回放排除公网后仍为 27.3 秒。
原缓存实现每读一个材质都等待写磁盘并枚举缓存目录，阻塞了后续模型依赖。
新版把经过原 SHA 校验的缓存持久化移到有界后台队列，并将稳定缓存容量从
256 增至 512 个小资源，减少反复切换场景时的淘汰重下。

原模型层元数据、草地/树叶色图和外观目录并行准备。门户在后台准备场景时就
预加载固定哈希的公共前端代码；待就绪轮询为 1 秒，正常续租仍为 4.5 秒。
私有场景、模型、背包和聊天仍逐请求鉴权，不公开上传的模型或游戏资料。

官网新打开角色默认使用第三人称跟随，保留用户主动切换到第一人称/3D后的
选择。刷新资料不会重建已有 iframe。原游戏客户端的默认视角不受影响。

已有压缩、方块内部面剔除、保守地下可见性裁剪、原碰撞状态和地形增量继续使用。
本次不通过缺失地形、简化模型或降低人物动作采样频率来换取速度。
已只读核对线上 Nginx 的 JSON/SSE gzip 配置开启，无须新增 WebRTC 或公网端口。

## 发布和回退

候选固定页面与家庭观察源须使用同一共享提交及打包摘要；不能只替换官网页面。
部署只正常重连官网和 SYSTEM 观战后台，Paper、登录代理、Agent 客户端无需重启。
依此前维护安排，候选验证及 E/F 回退文件准备完成后，再请求此次切换确认。

切换前用 SQLite backup API 创建新的网站完整前像，核对当前账号、归属、邀请、
照片和游戏记录。回退采用原 0.8.15 网站镜像、原渲染目录及观察配置，保留最新
账号数据库，不恢复旧世界或玩家存档。原始抓包、截图、备份和凭据不进入 Git。

新增只含耗时的 DOM 诊断 `data-startup-timing`，以及 `data-terrain-progress`
中的预取/准备阶段，用于分别衡量模型就绪与地形实际首帧，不向游戏聊天发送。
