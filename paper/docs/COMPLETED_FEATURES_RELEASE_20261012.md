## 现在可用

- `/mycli intro`：本人状态、规则、能力目录、统一进度和安全下一步。普通 `/help` 与 `/rules` 权限开放，另有独立 `/mycli rules`。
- `/mycli progress`：分别列主线、六项特色实练和公会委托；专项完成与主线毕业独立。
- `/mycli capabilities info <ID>`：参数、权限、副作用、游戏消耗及结果查询。`coach lessons` 只读；`coach enroll` 主动报名，原证明保留。欢迎修订7。
- 商旅交易板：罗盘世界生活菜单或 `/mycli trade find <物品>`，聚合已加载村民和商店的真实出售/收购报价，正常交易仍到场。
- 特色物品：大背包、技能罗盘等通过原生名称组件及本人私有用法提示说明；保留真正物品注册表 ID。
- 探矿、探敌、商人和队友定位：引导线从本人实时身体完整指向准确目标，目标消失及时停止；方向直线不是可通行路线。
- YSM：代理分发原手部及额外动画资源，新相机使用当前共享查看器；支持范围内按原动作和双手物品绘制。可米等比0.7→0.82、NEKO0.9→1.0，只改模型定义，不改碰撞箱或角色绑定。
- 共享 Web：OBS 透明手持层、吃喝/挥击等动作；20类组件显隐、拖动、缩放、布局保存和复制链接。`/?obs=1&obsEdit=1` 设置，F8再次编辑。
