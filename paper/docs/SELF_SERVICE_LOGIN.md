自选新密码至少六位，避免常见弱密码；不再要求管理员输入十六位新密码。
首次尚未设密码期间，名字本身还没有密码保护，应尽快设置。系统每分钟
最多私聊提醒一次，不把密码操作广播给其他玩家。

名字大小写沿用既有账号记录；同名的正版/离线两种连接共用原背包、领地、
技能和奖励箱。不会因为正版 UUID 不同而新建第二个人物；官方身份已经
关联另一存档的冲突不会自动合并。

## 实现与配置

- LibreLogin 0.24.0 的两份监听器使用锁定源码补丁，路径 `integrations/librelogin-dual/`。
- LoginGuard 添加首次进入提醒、本人设密码、正版找回密码；保持认证服务异常关闭入口、错密持久锁定、Eye 本体检查。
- `auto-register=false`：停止只凭名字存在就创建强制正版绑定。正版免密由本次经过验证的官方 profile 决定。
- `new-uuid-creator=CRACKED`、`session-timeout=0` 保持；不按 IP 免密。
- `minimum-password-length=6`、`ip-limit=20`；允许同一来源的 16 个 Agent 加少量观战/玩家登记。`max-login-attempts=3`、两分钟登录超时保持。
- 新设置的密码只保存 BCrypt 哈希；不生成或分发统一初始密码，不写仓库、参数或日志。
- 旧版客户端没有登录 UUID 时走密码流程，不能保证自动识别正版；1.20.6 及 1.21.4 已验证相应连接流程。

登录开始包的 UUID 只是选择“尝试正版校验”或“密码验证”的提示。声称正版
UUID 仍须通过实际 Mojang 加密和会话检查；LoginGuard 同时核对原始已验证
profile，不能用名字、IP、客户端 UUID 声明或改写后的存档 UUID 证明正版。

## Agent 门禁

`ops/mineflayer-login-gate.mjs` 对新账号的短暂 REGISTER 提示等待服务器
结果，不自动生成密码；仍只接受完整私有 `[MC_AUTH_SUCCESS]` 才开始任务。
已有密码的 Agent 继续从各自环境变量取密码。远端客户端需要自行同步
此模块，本机不能更新另一台电脑的启动代码。

`[MC_AUTH_PASSWORD_SETUP]` 只提示设置密码，不是登录证明。
`[MC_AUTH_PASSWORD_SET]` 表示本人新密码已保存；改密码后需同步 Agent 环境变量。
错误密码/锁定不自动重试；离线未认证时 `/mycli`、真实背包和聊天仍被拦截。
