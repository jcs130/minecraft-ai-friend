# 冒险者公会的物品归属

## 规则

AgentFriend 0.3.86 将冒险者公会大厅的实体储物、展示物和掉落物归萌萌所有。身份使用现有专属装备规则中的 Floodgate UUID `00000000-0000-0000-0009-00000d9f9c7b`（`.MicroKQ`），不按显示名或 Agent 名称猜测，也没有游戏内 OP 绕过。

大厅中心 `(-489,66,-502)`；保护范围沿用建筑边界：X `-498..-480`、Y `64..76`、Z `-509..-495`。新增箱子、木桶、熔炉等实体储物也适用。其他人不能开箱取放、破坏或往里面塞物品，也不能取走展示框/盔甲架上的物品、捡取私有掉落物；漏斗不能跨边界搬运。双箱任一半属于大厅，两半都按私有储物处理。展示物与储物矿车移动后仍保留归属，私有掉落物离开大厅后也不能被他人捡走。

萌萌可正常操作实体储物；原有建筑防拆规则仍对建筑生效。实体物资不会被批量改写为灵魂绑定物品；萌萌领取后可自主存到公共箱。接待员任务、商店、个人奖励与个人储物按原有账本和 UUID 提供。

## 明确拒绝与 Agent 协议

实际无权操作由服务器取消，并只对操作本人发送中文「无权操作：公会内物品归萌萌所有，物资装备请用门口公共箱」和私有 `MC_GUILD_ACCESS` JSON；同样的结构走已有 `mcagent:protection` 频道。核心字段 `status=deny / allowed=false / reason=guild_owner_only / owner=萌萌 / ownerUuid / action / x,y,z / publicCommand=/mycli guild shared`。相同操作和目标的重复提示最多每秒一次，执行拦截不受提示节流影响。配置主人 UUID 无效时继续锁住，实际操作返回 `guild_owner_unavailable`。

开箱前可免费查询 `/mycli protect container <绝对x> <y> <z>`，仅检查同维度 16 格内的已加载方块；返回 `MC_PROTECTION` 和私有频道。`deny` 应停止操作并改去公共箱，`unknown` 应暂缓，`allow_likely` 仍以实际服务器事件为准。`/mycli list protect` 和 `explain protect.container` 可发现接口。已登记且正在附身的 Eye 镜像该 Agent 的拒绝聊天；其他连接不收到私有错误。
