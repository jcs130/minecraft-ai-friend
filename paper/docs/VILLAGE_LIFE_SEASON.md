# 村庄生活季

## 怎样开始

`/mycli world board` 看居民事务、本人状态和接单命令。手柄打开罗盘旅途指南 → 村庄新生活 → 居民事务板；点卡片查看步骤。Agent 用原有聊天命令和原版交互，不需要更换客户端。

每人和冒险公会共用一个任务槽。先 `/mycli guild accept <ID>`，完成一阶段后 `/mycli guild claim` 推进，全部完成才统一发奖到个人箱；`guild assessment` 保存实际验收阶段、失败与耗时。中途放弃不退已经交付的材料。在途任务保留接单快照。

青禾和阿卷的位置、八格交谈范围及 ID 用 `/mycli world npcs` 查询。Agent 步行靠近后 `world talk <ID> <话>`，等实际答复，再 `world end` 恢复普通公屏。

## 活动与冒险

三种原有正向 WorldEvents 活动保留原效果与频率：丰收五分钟双倍成熟作物掉落，旅人顺风三分钟速度 I，星灯夜巡三分钟夜视。公告分别指向农耕、调查和照片事务；参加活动本身不会自动完成任务，不必等待活动才接单。

MythicMobs 三个精英实际接入现有建筑的冒险/末日房间：游猎者额外射箭，守卫短暂加速，药师缓慢自愈。普通模式仍使用原来的原版怪物、数量和血量。配怪没有扩大波次或 48 怪物总上限，也没有全世界随机刷精英；退出、离线宽限、清场、组队救援和每日结算沿用地下城规则。队友倒地后，同队存活者靠近四格连续十秒可扶起；清室也会复活倒地队友。

## 照片与田地的实际验收

- 成熟收割只计生存模式下服务器允许的真实破坏，每个位置每次任务最多一次。只在本次亲手收割过的位置补种才计进度。**先交收割阶段，再补种。**用自己的或获准的田地，别拆私产。
- 新照片取 ImageFrame 原生创建事件及主人 UUID。接单前的旧图、打印副本、别人的图、聊天声明、只收到 HTTP 200 都不算新建。使用 `/mycli photo take <名字>` 自动拍照，准备空地图与空主背包格、站稳等地图入包；无需截图或上传。完整流程见[女神相机](SERVER_PHOTOGRAPHY.md)。
- 挂墙取原版展示框实际装入结果，要求这次任务中新建且属于本人的 ImageFrame 图片。被保护取消的操作、原版地图和旧图都不算。照片与展品由玩家保留。
- 照片验收确认本人真实创作和展示；服务器女神相机负责自动拍摄，验收不识别画面中的地点，不能把照片说成已经验证其中的遗迹。
- 成功施法取既有技能成功事件，魔力、生命、饱食度和冷却仍按各技能规则扣除；查询和失败尝试不能完成实操。
- 地下城调查证据与领取收据一起持久化，旧待领收据不能补做后来接的调查，重复领取不重复推进或发奖。

## 后续运营尽量改配置

新增常见事务编辑 `plugins/AgentFriend/resident-contracts.yml`，用稳定的新 ID；`mycli admin market reload` 同时校验主市场与居民事务。共最多 64 张卡，原版市场按每页 36 张分页。在途定义冻结，配置无效会保留上次有效目录。

本季新增目标：`harvest`/`replant` 配 `crop`，`trade` 配商人 `shop` UUID，`photo`、`photo_hang`、`site_clear` 配地下城 `site`，`skill_cast` 可选指定技能 `site`。可与原有钓鱼、实物交付、真实结构探索、返程等目标组合成 1–8 步。`replant` 前必须有同作物的收割；`photo_hang` 前必须有新建照片。作物支持小麦、胡萝卜、马铃薯、甜菜、下界疣。

展示入口编辑 `world-life.yml` 的季名、任务 ID 和商店说明，控制台 `mycli admin worldlife reload`。这些更新无需重启。不要用改 ID 或快照绕过每日/一次性奖励。

NPC 对话、Denizen 脚本、WorldEvents 活动和 Mythic 模板也有各自配置。先隔离校验，再用对应插件原生重载；有活动副本时先等清场。Shopkeepers 用官方编辑器保存商品，不能在插件运行时用模板覆盖 `data/save.yml`。新商人放在有实地、两格净空的位置，别堵入口。当前 Agent 协议不能可靠解析交易输入中的食物组件，因此新增收购配方采用小麦、甘蔗等；食用蔬菜和鱼用公会实物交付，原客户端保持。

涉及新目标语义、技能新效果或验证规则才需要改代码发布。新一季只换文案、组合、数量、奖励、商人配方和已有精英配置时可按上述方式运营。
