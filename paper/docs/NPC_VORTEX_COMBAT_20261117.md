# 智能居民接入现役 Vortex RPG（候选）

用户明确指的是服务器已有的 **Vortex RPG**。居民 0.3.9 在千灯纪使用这套职业、技能、经验、学习点、冷却和魔力，不再运行另一套居民职业数值。此前独立 NeoForge 的轻量职业只是没有 Vortex 时的旧后端，不能称为现役职业系统。

本轮没有改正式 JAR、角色、物品或记忆。最终候选的 95 项隔离联机检查与 225 项独立回归通过；这不代替完整 NPC 项目的长期多体、各客户端外观与正式住房验收，`releaseReady=false`。[按构建归属的证据清单](../manifests/npc-vortex-combat-candidate-20261117.json)

## 身体与战斗

身体仍是原 UUID 的 `EntityMaid`，不是登录的玩家或占名额的假玩家。每 5 tick 为登记居民检查可见敌人和实际装备；原生 TLM 执行寻路、挥击、拉弓、装填、射箭及消耗弹药。逐次攻击没有模型请求；模型负责目标、职业成长、装备准备和日常生活。

- 只自动锁定当前维度、视线可见、16 格以内的合法敌对实体；排除玩家、村民、宠物、其他女仆、固定 NPC 和无 AI 实体。中立生物需要实际敌对行为。继续检查居民本人领地/副本资格。
- 只在本人已解锁的背包槽中找武器和弹药。默认原生小背包只有 6 格，不能拿锁定槽当作有物资。
- 距离超过 5 格且射线没有友方身体时优先远程；已持远程可保持至 3 格，减少反复换装。弓/弩缺箭时切到真实近战武器；有多把近战武器时按实际攻击属性选择。
- 普通攻击不直接伪造伤害。`combat.actualHits/lastHit` 来自实际受伤事件，包含目标 UUID、类型、绝对位置、伤害、投射物标记和时间。选择攻击任务或技能执行完成都不等于命中。
- 玩家要求停留、身体睡眠/坐下、正在打开菜单、倒地、有限动作或未知结果未核对时，不抢身体。对话招募的同行与工作模式沿用原契约；战斗结束恢复原工作任务，不凭快照重建装备。
- 自动施法读取原生已学技能、魔力、冷却与目标范围。牧师有伤员才用治疗；范围治疗使用真实同行/试炼队伍和视线规则。原执行器仍重复检查资源与保护，不能通过选择逻辑绕过规则。
- 没有实际造成伤害的目标会暂时退避，状态说明原因；不把“发出攻击意图”计为击杀。

普通私人女仆和原肥鱼仍走原链路。这套新战斗循环只覆盖 `tlm-residents.json` 登记的独立居民；没有全局把所有女仆改成攻击模式。

## 原生数据和工具契约

`ResidentRpgApi` 按居民本人的 UUID 加载 Vortex 原档案。仅尚未选职业时采用配置职业；已有档案的职业优先，重启和改配置都不会重选职业或再次领取初始装备。旧配置 `guardian/healer/artisan` 分别迁移为 `knight/cleric/engineer` 的初始化请求；`farmer` 是生活定位，不擅自选战斗职业。

`ResidentActors` 仅扩展 Vortex 内部的魔力玩家查找、群体法术身份分类和伤害来源解析；Bukkit 在线玩家名单、真实登录和认证均不变。现役 Vortex 的公式、升级曲线、学习点、目标保护与冷却原样执行。没有可用的原生适配时返回 unavailable，不回退为另一池“20 魔法”。

已进入居民按需发现目录：

```text
profession list
profession info <ID>
skills list
skills tree
skills points
skills info <ID>
skills learn <ID>
skills prepare <ID>
cast <ID>
```

这些是居民 `action=cli` 的命令正文；真人继续用原 `/mycli`。`action=cast, skill=<ID>` 也走同一原生执行器。`prepare` 只是设置点击技能，`learn` 才消费学习点；只读查询和施法回执有各自的 `operationEffect`。当前 `profession choose` 仍为内部兼容入口，未加入自主发现目录，初始化使用实际原生选职接口。

每笔有副作用动作保留原 requestId。技能生效与异步终态可能相隔数个 tick，验证须查询原请求；未知结果不换 ID 重放。明确的 `UNKNOWN_SKILL` 且 `changed=false` 是“未执行”，现在不再误锁成“操作结果未知”。真正 unknown 仍保留原阻塞。

工作方块已经改变后，即使后续经验提交失败，也先移除已执行作业，单独记 `progressionStatus=unknown_no_automatic_replay`；不会下一 tick 再挖一次或再放一次。原生公共玩家专用法术尚未适配的部分不向居民广告为可用能力，也不假成功。

## 验收与限制

最终组合：居民脑 0.3.9、AgentFriend .87、QiandengjiRpg .21、基于现役 qd29 摘要构建的 Vortex 居民适配，以及原候选权限桥 .40。

| 最终构建实际检查 | 数量 |
| --- | ---: |
| 冷重启：六份职业/经验/学习点/已学技能/装备，旧请求不重施 | 20 |
| 六职业原生资源、技能发现、门槛、自动施法和真实伤害/治疗 | 33 |
| 弓命中、耗箭、缺箭切近战、停止及友方保护 | 14 |
| 弩的同类实际检查 | 14 |
| 真实同行队友自动治疗、停留及解除同行 | 6 |
| 实心遮挡、按需职业/技能查询及准备技能 | 8 |

较早 r4 构建还实际验证经验升级、学习点扣除、同请求去重、辉光脉冲学习和选择；最终冷重启检查验证其数据保存。不得把这组早期学习动作写成在最终构建又学习了一次。独立 Java 回归 225 项通过。

失败证据保留：第一次箭放到未解锁槽；一次测试低估升级所需经验；一次过早读取异步终态；一次队友挡在弩的射线上。测试现检查物资确实入包、实际等级、原请求终态，并在独立射击场验收武器；没有通过关闭友伤/碰撞/等级门槛来制造成功。

本轮机械战斗使用原生 AI、真实移动怪物和实际伤害，测试规划模型关闭；不能据此宣称 LLM 已学会战术或长期自主战斗。新角色正式住房、独立模型/记忆 Scope、长期并发和 Java/基岩/Web 的整套模型表现仍按[总候选门槛](NPC_GAMEPLAY_CANDIDATE_20261117.md)验收。
