# 错误命令的只读纠正建议

2026-11-03 `.49` 已正式加载，补齐多参数错误路由：先以当前目录识别误放在 `cast` 下的副本查询、领奖和开场，再给 `COMMAND_ROUTE_MISMATCH/nextCommand`。这条确定性修正不等待嵌入服务，真实技能 ID 冲突仍归原验证器；不存在的目标引到帮助。41 项普通客户端验收及实际部署见 [本轮记录](NPC_CLI_LIFECYCLE_20261103.md)。

当前目录检索、多参数路由纠错已随 AF0.4.47.49-rpg 上线；传送入口的后续修复见[11月3日联机验证](TRAVEL_CLI_20261103.md)。下文 AF.47 的候选与旧正式服描述是当时的构建记录。

沿用早期 `world/src/mc-magic.ts` 的精确匹配、余弦近邻思路，纠正层只检索当前 `/mycli` 目录并返回建议。没有代施法、自动转发、扣费或生成任务证明，也没有新增玩家命令。普通聊天默认精炼文字，程序明确要求时使用 `--json`。

例如把“去墓穴”误写成 `/mycli cast travel undead_crypt`，服务器确认 `undead_crypt` 是当前配置里的地点后，返回原因为入口不匹配、正确用法、条件和 `/mycli dungeon travel undead_crypt`。向真实在线伙伴传送则建议现役 `locate tp <名字>`；未知、离线或多个目标需要先查列表，不能编造落点或随意选择一个人。建议仍受原有权限、费用、冷却及安全落点检查。

当前覆盖未知顶层命令、未知目录ID、帮助参数、基础能力路由错误、遗迹参数错误，以及Vortex确认未知的技能ID。桥只在原验证器拒绝后调用建议接口；真实职业技能由Vortex当前配置提供名称、效果、目标、等级、魔力和冷却，不抄写另一套职业库。目录约一秒刷新缓存，旧异步结果受目录修订检查；节点、锁定技能和已停用技能仍保留原本明确原因。其它领域的业务失败仍由原插件返回原因；本次没有重写所有玩法错误。有效动作继续经过原有解析和执行器。

宿主消费规则见[MCP接入](MCP_CLI_RECOVERY_20261101.md)。冻结Skill1.3.7保持原字节，当前参考更新不伪装成同版下载包已经重发。

候选只返回最多三项，文字最多两项；字段包括 `errorCode/reason`、`changed=false`、`autoExecute=false`、`nextCommand`、`catalogRevision` 和 `suggestions`。每项包含实际 `id/usage/summary/requirements/nextCommand/lookupMethod/rankingScore`。相似度仅用于排序，不是执行成功率；`readOnly` 指本次建议查询，下一条建议动作可能有原有消耗。调用者、会话和时间戳保持，错误建议不发公屏。

本地路径复用实际目录、同义词和拼写召回，预计算并缓存299条目录的词元向量。另有可选 OpenAI-compatible embeddings 后台索引，文档按目录修订号复用；只把返回向量映射到已有目录，模型回复不能提供可执行命令。它与本地词元检索分别标记，不冒称同一能力。

```yaml
cli-recovery:
  embeddings:
    enabled: false
    endpoint: '' # 操作者明确配置的 /v1/embeddings 完整URL
    model: ''
    api-key-env: '' # 可选环境变量名；不填写密钥正文
    timeout-ms: 1500
```

正式默认关闭神经向量查询，旧Ollama服务没有因此被重启。启用需配置实际服务并按插件正常维护流程加载；仅在错误后异步查询，一个工作线程、四个等待位、每人十秒一次。服务缺失、配置错误、超时、返回无效或拥塞均保留即时本地建议；没有生成式模型兜底。索引绑定目录修订、端点和模型实例，最多512条，每批32条；请求和响应有超时、大小及维度约束，重定向拒绝。新的/mycli命令、退出或插件停止会使旧请求失效，不能把迟到建议交给后来的操作。

错误输入先限制长度并排除凭据类文本，已确认的角色/地点名和不透明标识从语义查询移除；仅向明确配置的服务发送剩余查询和公共命令说明。不要配置含凭据的URL，也不要把查询接口当成任意代理。没有配置服务时状态为 `semanticLookup=disabled`，受控HTTP向量测试不代表生产神经模型召回质量已经验收。
