## 原因与修复

原版兼容流将女仆投影成悦灵，并剔除原版不认识的模组元数据。
原有网页因此收不到真实女仆模型编号；相机改用 NeoForge 不会自动修复网页。

WorldObserver 现在仅对当前观战目标已跟踪、可见的女仆补充公开渲染状态。
UUID、实体编号、世界、维度和观战代次共同绑定；沿用已有 32 格范围、
128 实体上限及四刻采样，不额外扫描世界、不加载区块、不创建观战身体。
不含女仆主人凭据、背包、私聊或 AI 记忆。

共享可视化使用 TLM 1.5.3 原包的模型、纹理、骨骼及原生基础动画规则。
资源按内容摘要缓存和复用，加载资源不阻塞地形、生命值或物品更新。
原版/基岩兼容投影、游戏内 YSM 和 NeoForge 女仆渲染保持各自原路径。

## 发布边界

本批游戏插件、worker与网页资源已配套部署；正式女仆同框像素验收仍待实际现场。后续发布需一起冻结游戏观察插件、worker、共享渲染源码、
原资源目录和官网可信观战站点。发布前保存 E/F 两盘候选和回退；按维护
规范正常重启加载游戏插件，并切换匹配的观战后台与官网可信站点。
不得在线替换类或重放已消费的旧维护入口。

正式验收须检查当前女仆 UUID/modelId 与网页实际画面一致，普通 YSM
人物、地形、HUD 和退出观战正常；私有游戏数据不回灌旧快照。

GeckoLib 动画格式、部分自定义动作及背包/装备等附加层尚未完整适配，
这些情况明确标记，不冒称全模组像素一致。此候选处理官网公共/本人
观战；独立 Web 游玩连接仍需显式接入自己的同身份女仆状态源。
