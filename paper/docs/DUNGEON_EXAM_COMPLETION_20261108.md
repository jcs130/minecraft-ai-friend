# 遗迹攻略考试与每日奖励分离（候选，未部署）

本次基线为主干 `29e2e6a9f6e68a8ee0e1a4d591fdf17770e1e8cf`。2026-11-08 正式日志及账本只读核对发现：一场墓穴正常完成全部三室、本人参战三室，但已领取当天奖励，结算返回 `daily_limit`；另行发起的晋级考试没有得到攻略证明，并在退出时变为 `interrupted/logout`。旧证书不等于这次晋级已完成。

## 根因及改动

1. `SiteDungeonManager.complete()` 在每日限奖或已有待领奖凭据时直接跳过 `applyCompletion()`；后者同时承担考试证明。现在在新场次完整通关边界登记证明，再独立处理原奖励。每日奖励、任务奖励及凭据幂等规则保持。
2. 原 `nativeSiteCompleted()` 还会由领取旧奖励触发，没有比较副本与考试开始时间。移除这条路径的考试证明；新证明要求副本在当前考试开始后启动，考试尚未到期、本人逐室参战且没有未知房间记录。历史奖励不能用于新考试，部分参战仍按原规则领奖但不取得完整攻略认证。
3. 原退出、普通传送、停服均按连续动作考试中断攻略考试。`contract_record + native_clear` 改用与调查记录相同的持久生命周期，保留原编号、冻结要求、证明及截止时间。连续飞行、跳跃、支援等考试仍会中断。旧 `logout/server_restart` 中断只在未过期、题目仍开放且成功存储时恢复；取消、过期、旧 `teleport` 等原因不自动恢复。
4. 已结束的旧记录仍携带“回到遗迹续接”提示。查询投影及新结算统一生成下一步；完成且每日限奖时提示查询考试、不必返回首室，不自动交卷或发奖。历史事实不改写。历史 `not_returned` 不再引导无意义返程。
5. 新考试描述及在途攻略考试指引改为自动结算，取消“返回首室”。冻结证书定义不重写；上线时只合并现役 `skill-assessments.yml` 的 `conquest_basic.description`，不能以整个候选文件覆盖其他题目。
