## 保留的失败与恢复

首次游戏检查错误地要求 LoginGuard0.1.10；实际在维护前已是 `0.1.11-web-rc2`。本次 E/F 冷备、当前 JAR 摘要和启动日志完全对应，修正版检查锁定该精确版本和摘要后通过，没有降级登录代理，也没有再次重启游戏。

官网首次切换的校验错误地要求整个下载目录与旧版相同，而本次本来就更新 Skill。程序自动恢复旧镜像，数据库未回滚。独立对比确认仅 Skill 元数据变化，其他下载包逐项一致后重试成功。原失败及重试证据均保留。

原账号、音频回执、图片、私钥、令牌、后台配置及完整诊断只保留于私有 E/F 证据目录。已消费的维护入口不得重放；回退仅恢复代码，不能以旧世界、玩家、认证库或相册覆盖新进度。
