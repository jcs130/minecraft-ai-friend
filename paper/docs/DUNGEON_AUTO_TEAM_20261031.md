# 遗迹自动参战与血量显示

2026-10-31 21:32：本页功能已随 AF.43／桥.15／原生平台.6／Observer.2、官网0.8.33及Skill1.3.6正式发布并核验。下面保留先前候选与验证过程；当前状态和限制以[正式发布记录](VANILLA_MAID_RELEASE_20261031.md)为准。

2026-10-31：源码与隔离验收完成，正式服仍为 AF.37；本页不代表已上线。AF.43 基于已批准的 AF.41 相册/组队/归乡组合增量构建，不覆盖玩家账户、背包或 Vortex 职业记录。

一人在首室开启挑战，进入同一地点挑战区的合格生存角色自动加入本场。真人与 Agent 使用同一套位置、装备和职业等级检查，不要求先 create/invite/accept，也不限制开场十秒内 join。旧 join 保留为幂等兼容入口。日常 Vortex 队伍保持原样，不把整队离线成员作为开场障碍。

离开挑战区或断线后移出当前战力，已经实际参战的房间记录保留，回场自动续接。主动 leave 会暂停本人本次停留的自动加入，走出再进入可续接；倒地先走原救援流程。当前角色上限40，单场历史最多256个UUID，仍只有一个地点场次、原30分钟时限和三次战败机会。首领房允许达标同伴中途参战；不同时创建第二队或第二份怪物。

全场通关后，每个有真实房间贡献的角色都生成原有个人奖励凭据，包括已离场/离线者。无需返回首室，claim 进入原个人箱队列，原日期限额、原子保存、满队列保留和重复领取去重保持。正式楼层解锁还要求实际参与首领战；旧完整探索凭据保留原效力，不根据截图补造凭据。

菜单原先把难度参数附到每个动作上，导致 claim/info/leave 被解析器拒绝；现在只给 start 附难度，leave 不带地点，其他动作使用各自参数。`dungeon menu <ID>` 也进入指定详情，不再忽略ID打开列表。帮助、路线与错误提示按同一规则更新，不增加顶层命令。

试炼塔原有附近自动参战保留；暂停场次在合格成员实际进入当前层后可自动续接，不再只有旧名单的登录事件能恢复。

Vortex 继续掌管真实HP。AuraSkills 旧等级和基础被动保留，只关闭旧爱心缩放；现有原生RPG定时更新只在仍有旧缩放标记时移除它，不改当前血量或上限。原版语义为2HP一颗心，24HP对应12颗实心，35上限对应17.5颗容量。官方说明见 [AuraSkills stats](https://wiki.aurelium.dev/auraskills/stats/) 和 [Bukkit Player health scaling](https://hub.spigotmc.org/javadocs/spigot/org/bukkit/entity/Player.html#setHealthScaled(boolean))。

验证：四个独立无OP客户端14项实际流程，包括自动在场组队、装备不足提示、中途加入/离开、发起人倒地后同伴清怪、离线贡献者领奖、真实菜单按钮与拒绝重复领取。正常停启另8项确认原场次ID、已清进度、离场贡献及去重保存。148项既有规则检查通过；地图材料的离线检查依赖运行中的Paper注册表，未计入通过数。夹具造平台、配装备、补魔并给予标记怪实际伤害，仅运行在回环隔离服，不是自主LLM战斗验收。

沿用现有 runs.party 记录当前成员、runs.attendance 和 roomAttendance 记录真实贡献，增量保存 declined。恢复时读取离场历史，不因当前成员为空而丢弃仍有有效贡献的检查点。未清房间仍按原规则重刷，不虚构历史房间贡献。Skill/MCP参考已更新为按实时帮助识别自动参战；旧下载包不会因源码变更自动更新。

新 Skill 1.3.6 已按当前说明单独打包，入口1455字，8项真实归档/逐文件摘要/链接/重建验收通过，内置SDK保持rc.130；两个OSS目录均保留固定摘要对象，官网指针尚未切换。另补公开构建缺失的两个官方插件API依赖，不改变正式服JAR。旧1.3.5及更早对象不覆盖。
