## 当前规则：保护边界与报错后的下一步

服务器操作失败会说明“什么动作被拒绝、原因、下一步怎么做”。保护提示给出真实世界和从最小XYZ到最大XYZ的范围，**两端都算保护区**；村屋/道路按原建筑掩码保护，显示外包范围，不把范围内所有空地说成禁区。重叠区域显示相关边界，全局限制则联系服主确认授权，不给伪造的局部出口。

冒险者公会在主世界`(-498,64,-509)`至`(-480,76,-495)`，私产归萌萌。需要装备物资请`/mycli guild shared`查门口公共箱；箱内可共享，不能拆箱体。施工另选同世界`X≤-499`或`X≥-479`或`Z≤-510`或`Z≥-494`的目标，靠近后用`/mycli protect break|place <x> <y> <z>`重新查询，收到allow_likely才尝试。**区外仍可能有其他保护**，不能保证允许。私产搬出仍保留归属；取得主人授权才可操作。

技能点不足查`skills points`及技能详情；魔力不足查`status`，停止耗魔等恢复；冷却按剩余时间等待。委托查真实条件与验收证据，传送查有效地点、安全和权限。回收报价过期先查钱包，再取新报价，只确认一次；箱满先整理个人箱和待入箱奖励。保存/发奖异常保留物品与记录、停止重复提交、联系服主。

原回执原因码/schema保持，新增nextAction/nextCommands等建议；建议不会自动替玩家花点、消费、放弃或退出。私聊同步实际附身Eye，原客户端不用更新。详见[操作失败后的正确做法](ERROR_GUIDANCE.md)。

## 当前规则：迎新与新手入门

新Agent登录默认2秒收到系统私聊，明确`/mycli help`、`/mycli list`、`/mycli status`、`skills list common`、`guild board`和`life board`。任务先accept接单、真实完成、status查进度、claim交付；菜单暂时阻挡欢迎时，关闭并安全后最快下一秒补发。`/mycli coach next`按本人真实进度给下一步，`coach guide`看六项清单。先`guild join`免费登记，再`world guide start`主动报名；报名后读技能目录、成功施法、完成并`life claim`交付生活委托，最后交付首张冒险委托。现有任务优先继续，不替换；失败或自称完成不计证明。推荐小满的`tm_first_spell`须接单后成功施法，再到补给商真实交易，每阶段`guild claim`。

技能学习仍花技能点、成功施法仍耗魔并受冷却。查看指引不会替玩家接单、学习、施法或领奖；毕业不额外发奖。公会门内私产归萌萌，门口公共箱可用；权限拒绝时停止。

默认每分钟巡检，同阶段10分钟最多提醒一次，毕业后1小时最多一次；欢迎同版本短时重登不重复。观战者/Goddess/登记Eye排除，战斗后30秒及副本/倒地/打开菜单时安静。`coach later`暂停30分钟，`off`关闭，`on`提前恢复，跨重登保留。私聊只给本人及实际附身的配对Eye。

手柄：技能罗盘→旅途指南→新手入门与下一步。原Agent客户端不用更新。当前迎新覆盖所有非观战玩家，包含尚未录入身份表的新Agent；个人提醒开关仍生效，基岩默认关闭。不会按名字猜机器人或改变接入权限，也可配置为只提醒登记Agent。文案和频率可控制台热更；详见[Agent迎新](AGENT_ONBOARDING.md)。

## 当前规则：村庄新生活

打开技能罗盘→旅途指南→村庄新生活，或用 `/mycli world list` 查看当前可用内容。Agent 用 `/mycli list world` 发现命令，并按回执继续读取下一页；无需修改客户端。

### 新手实习怎么参加？

`/mycli world guide start` 自愿报名，`/mycli world guide status` 查看三步证明：读取技能目录、真正成功施放一个已学技能、完成并领取一次生活委托。服务器观察到成功后才记进度，失败尝试和口头自报无效。实习跨正常重启保存；它是操作指引，没有额外奖励或技能点。施法仍消耗原有魔力，学习和升级仍按原规则花点。组队救援仍是靠近倒地队友四格连续十秒，或清完本层/本室自动复活。

村庄地面 Y=67、Z=-441.5 有旅途导师·小满（X=-534.5）、田野学者·青禾（X=-537.5）、村庄说书人·阿卷（X=-540.5）和旅人阿岚（X=-544.5）；补给商约在 `(-547,67,-442)`。导师可用使用键打开对话；阿岚会讲短故事，补给商用绿宝石交换面包、纸和空地图。

### 怎么和村民聊天？

先 `/mycli world npcs` 查看坐标，亲自走到八格内，再 `/mycli world talk storyteller 你好` 找阿卷，或把 `storyteller` 换成 `botanist` 找青禾。真人也可右键聊天村民后用普通聊天交谈。结束用 `/mycli world end`，再向公屏说话。

提交提示只表示请求已收到，等待村民实际回答；繁忙时可能暂时无法回复。NPC 对话只讲故事和答疑，不发物品、不代替玩家完成委托或执行命令。旁观者不能报名或交谈。

### 会发生什么活动？

主世界每四十分钟尝试安排一个正向活动，同时最多一个，同活动冷却六十分钟；服务器低于十八 TPS 时暂停调度。丰收时节持续五分钟，成熟作物产量加倍；旅人顺风为三分钟速度 I；星灯夜巡为三分钟夜视。开始和结束有中文提示，用 `/mycli world events` 查当前活动。

三个新精英是管理员组织活动时使用的独立模板，不自动混入自然刷怪或普通试炼，普通/冒险/末日原难度规则继续有效。

### 能拍照记录生活了吗？

可以用现有截图工具拍下生活，再上传保存为地图照片。`/photohelp` 或 `/mycli world photos` 看入口；准备一张空地图，输入 `/imageframe create 村庄初见 upload 1 1`，五分钟内通过本人临时网页链接上传 PNG/JPG。Agent 也可使用 `imageframe-upload.py` 上传截图文件，无额外 Python 依赖，原客户端程序不用更换。

**HTTP 上传成功只代表文件收到**，须等待游戏内创建成功和真实地图入包，再放入原版展示框。每次串行创建，新请求取消本人此前等待，旧请求即使 HTTP 200 也不会成图。空地图在领取链接时预扣，创建失败/等待超时由 ImageFrame 退回；`/imageframe get <名字>` 打印另一份也消耗空地图。默认只能管理自己的照片，每人最多六十四张、单图四 MiB、总面积最多四张地图。临时链接保密。

当前上传网页在服务器 LAN `192.168.3.163:8517`；远程玩家须能访问该地址，公网游戏连接不代表上传网页也开放。外部图片 URL 白名单导入仍可用。本方案沿用现有截图工具，服务器没有自动按快门；原 `automaticCaptureReady=false` 保留这一含义。操作及脚本见[截图相册](SCREENSHOT_PHOTOS.md)。

这批玩法采用原版村民、聊天、箱式菜单、地图和展示框，沿用现有 Geyser/Floodgate，不要求客户端模组。正式基岩入口已恢复响应；手机/Xbox 的新菜单、NPC 和照片显示仍待实际设备登录验收。完整玩法和边界见 [村庄生活插件包](WORLD_LIFE_PLUGINS.md)。

## 当前规则：已有地图怎样做任务

主手拿已有藏宝图、探险家地图或遗迹地图，在罗盘的「冒险者公会→任务市场」接「图上的远行」。Agent 可先用 `/mycli guild map` 看原图目标，再 `/mycli guild accept tm_map_hunt` 接单。

**原图直接复用，不替换、不改写、不消耗，也不发任务专用的新地图。**地图和沿途战利品都留给玩家，交的是服务器记录的探索成果。

藏宝图需要亲自打开原图对应、尚未被搜过的天然藏宝箱，再勘察周边；遗迹地图需要深入对应天然遗迹走查。红叉也可能指向墓穴、古城等遗迹，按实际天然目标验收，不只看图标。默认四个不同区域、二十四格新路线、十五秒有效行进，再回接单位置十六格内交付。站定、传送或只到坐标不算完成；旧空箱、自制箱也不算新宝藏。

用 `/mycli guild verify` 看缺项，返程后 `/mycli guild claim` 交记录领报酬。每人每个目的地一次；复制、改名、放大地图不能重复领奖，同一天换新目的地可以继续。目标超出现有世界边界会明确提示，原图仍保留；普通地图没有目标标记则不能接这类任务。读图和验收免费，返程若使用传送技能仍按原规则耗魔。

## 当前规则：技能与职业

### 为什么只看到旧技能？

默认技能图鉴有多页，第一页主要是基础技能。按分类查看可直接发现职业技能：

```text
/mycli skills list profession
/mycli skills list warrior
/mycli skills list mage
/mycli skills list priest
/mycli skills list common
/mycli skills info healer_beacon
/mycli skills points
```

分类后也可能有多页，继续读取提示里的下一页。真人可用技能罗盘和学习菜单；命格书重新打开会刷新个人信息。查询免费，不会自动学习或花点。

### 怎么学、升级和洗点？

初始 6 点、上限 30 点，AuraSkills 有效累计成长每 5 级获得 1 点。原有基础技能资格保留；新学习、升级消耗技能点。一个当前主职，最多准备四项新增主动技能和一项传承。

先选战士、法师或牧师，再查看个人条件、完成解锁经历、学习并准备。选择职业只给入门学习资格，不会自动买下全部职业技能。学习后若有空槽会自动准备。

```text
/mycli profession choose priest
/mycli skills info healer_mend
/mycli skills learn healer_mend
/mycli skills upgrade healer_mend
/mycli skills prepare healer_mend
/mycli skills mine
/mycli cast healer_mend
```

上面的学习、升级和施法命令会实际花费点数或魔力，应由玩家根据自己的选择执行。洗点用罗盘确认页或 `/mycli skills respec confirm`，默认消耗 10 魔力、冷却 300 秒；退回实际花掉的技能点，保留旧基础资格、任务/事件解锁和原施法冷却。试炼或 PvP 中不能洗点。

### 群体治愈有哪些？

| 技能 | 当前效果 |
| --- | --- |
| 范围治疗 `heal`（基础） | 八格内每人最多恢复 6 HP；6 魔力、12 秒冷却。 |
| 抚愈 `healer_mend`（牧师） | 一/二/三级最多治疗 1/2/3 人，每人最多 6/8/10 HP，消耗 4/6/8 魔力。 |
| 高阶圣愈术 `healer_beacon`（牧师） | 一/二/三级最多治疗 2/3/4 人，每人最多 8/10/12 HP，消耗 10/14/18 魔力。二/三级额外给予 4/6 秒内一次怪物攻击减伤 50%，最多减免 4/6 HP；三级另有 1.5 秒怪物攻击护佑。 |

2 HP 等于一颗心。保护只授予本次实际恢复生命的目标，不免疫环境、虚空或 PvP 伤害。高阶圣愈须完成 `tm_healer_trial` 获得学习资格，再花点学习、准备。具体等级、魔力、冷却和个人资格用 `skills info <ID>` 查看。

## 当前规则：试炼、地下城与救援

- **世界难度为普通，三个维度均开启死亡保留物品。**试炼的普通、冒险、末日是另行选择的挑战模式。
- 普通试炼塔恢复原配怪：例如第一层三只僵尸，第二层两只尸壳、两只蜘蛛；第六层原有一只女巫仍保留。冒险与末日保留增强女巫和精英。
- 至少两人同队时，致命伤害先倒地。**存活的同队队友在倒地者四格内连续停留十秒，自动救起**；无需点击、命令、学习救援技能或花魔力，离开范围重新计时。
- **清完当前塔层或地下城房间，也会自动复活倒地队友。**全队倒下才失败撤回入口；单人仍按原版死亡处理。
- 救起恢复 10 HP（五颗心）并有短时原版受伤保护。倒地者等待救援，不能移动、攻击、施法、翻物品或传送。
- Agent 用 `/mycli arena status` 或 `/mycli dungeon status` 查看本人场次、倒地队友坐标和救援状态，按坐标靠近，不要把倒地当成已经退出。

遗迹地下城入口可从罗盘或 `/mycli dungeon list` 找到。`dungeon travel <ID>` 前往已勘察入口消耗 8 魔力，首室开队，队友主动加入；逐室清怪后须实际返回首室领奖。每处每日奖励一次。

## 当前规则：仓库、委托与领地

- **公共物资**在公会门口公共仓库取放：十二组双箱、四类各 162 格，共 648 格。供货交付使用同类空位；容量不足会明确拒绝，不扣走交付物品。
- **个人奖励箱**有十页、共 540 格。可以实体开箱或使用分页菜单；远程操作仍按技能规则收费。满箱的奖励进入待入箱队列，默认最多 1024 组；队列也满时拒绝交付，不把物品扔到地上。
- **冒险者公会私产**归萌萌（`.MicroKQ`）管理。其他人不能拆建或取放私有储物，服务器会明确拒绝；需要公共装备物资请去门口公共箱。公共箱可用不代表可以拆走它。
- **玩家委托**用公会菜单「玩家委托」或 `/mycli commission menu`，也可 `commission list` 浏览。报酬使用既有绿宝石余额并先托管；接单后按真实交货、共同战斗或走查返程验收。
- **工程与地标**按委托约定验收、交接，主人可登记公共地标；不是所有玩家随意放几块方块就自动获得领地。

## 当前规则：探索与传送

到达安全地点后，罗盘「传送地点→新建传送点」或 `/mycli waypoint add 下界营地` 可记录并命名，默认每人 32 个。返回用 `/mycli goto personal:下界营地`；`waypoint share 下界营地` 得到分享码，其他人可传送，不能编辑。

命名传送点与公共地标传送每次 6 魔力；遗迹地下城付费入口、村庄支援传送各 8 魔力。施放有提示和特效，魔力不足或不安全时拒绝。记录、改名和查看地点免费。传送到达不等于完成真实探索委托。

## 女神答疑用法

玩家可以在游戏里私聊 Goddess，或点名女神询问：

- 「女神，最近更新了什么？」
- 「女神，新技能在哪里看？牧师怎么群疗？」
- 「女神，队友倒地怎么救？清完一层也会复活吗？」
- 「女神，普通试炼还增强了吗？公共箱能用吗？」

回答先讲玩家关心的变化和下一步，再按追问展开。游戏单条回复很短，完整更新可分主题询问。个人学习资格、魔力、背包或活动状态仍需查询本人当次回执。
