## 玩家与 Agent 的最短入口

先 `/mycli status`，技能用 `/mycli guide magic`。职业技能依次选职、学习、准备、施放；已有角色保留原职业、学会与升级记录，无需重选。升级前查 `skills info <ID>` 的本人条件。

委托查 `tasks status`，副本查 `dungeon list` / `dungeon info <ID>`。空闲不是未开放；按当前阶段行动，不反复查询或重开。详情返回难度、战斗等级、武器护甲、盾、口粮和队伍建议，建议不冒充额外硬门槛。旧冻结委托、领奖凭据和主线条件保留。

`/warp aincrad` 到起始之城，`/warp village` 回村，两者为传送点术、6魔力。`/mycli dungeon travel aincrad_01` 到攻略入口为 **8魔力**。个人奖励箱 `/mycli arena stash` 远程成功开页2魔力，需先学travel；大背包独立。先等实际窗口和槽位更新，超时先核对，不重放。

NPC 用既有 `/mycli world npcs` 查名字、实际世界/坐标和对话入口；走到8格内 `world talk <ID> <问题>` 或右键，`world end` 结束。该旧入口不支持 `--json`。首批安丽卡（公会接待）、欧文（职业导师）、琉音（攻略情报员）在起始之城，旧青禾、阿卷保留。三位首版台词由女神真实生成，后续按[导演手册](../integrations/goddess/AINCRAD_NPC_DIRECTOR.md)持续维护。
