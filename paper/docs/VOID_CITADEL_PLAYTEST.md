# 虚空回响城试玩候选

2026-11-22 的现场试玩用了约 130 秒。可米 Lv.17 和肥鱼在普通档打完三室，出怪到清场约 41 秒，两次转场约 78 秒。末室执政官倒下后还需要找剩余女巫。本版保留原地图、进度和每日奖励规则，调整战斗节奏并补上回程。

| 房间 | 普通 | 冒险与末日 |
| --- | --- | --- |
| 前庭 | 一波三敌，利用柱子压制远程 | 保留热身，沿用档位倍率 |
| 卫所 | 原哨队之后出现侧翼弓手、斧卫与封路守卫 | 两侧同时有远程。末日再加援军炼金师 |
| 末室 | 先清投影与护卫。随后只出现执政官本体，看见紫圈时及时撤步 | 冒险用需要横移的贯穿光带。末日增加投影副官，保留圆形震荡 |

两次加波都只有约两秒预警。两段室内路线上有粒子与坐标，Agent 可从 `dungeon status` 的 `route` 读取同样的途经点。预警包含战术、范围和剩余时间。试练时记录 `encounterTiming` 的作战阶段耗时、转场和波间耗时，以及每室实际见到的波次。作战计时包含躲避和临战移动。普通双人目标为约 3–4 分钟，服内实测再决定是否调整敌群、转场或奖励。

## 高处遗迹往返

悬高的遗迹由地面入口进入。罗盘打开遗迹详情后选择前往，沿地灯走到入口牌，按使用键操作石钮，免费抵达首室，再选难度。Agent 可以顺序使用 `/mycli dungeon info <id>`、`travel <id>` 和 `enter <id>`。`travel` 需要 8 魔力，石钮与 `enter` 共用同一段进场传送。

挑战结束后，任一战斗房间均可从菜单选择返回地面入口，也可点击结算后的回程文字。Agent 的 `status` 提供当前位置可用的 `returnToGround.command`，同一动作可用 `/mycli dungeon exit <id>`。通关原地可以领奖，奖励进入待入箱队列，满箱时继续保留。入口和回程继续检查游戏模式、保护、目标区块和安全落点；有效参战期间沿用原退出条件。

## 下一轮试玩

普通双人先验证换侧、报招和撤步能否自然发生。冒险单独比较交叉射击与贯穿技能对站位的影响。记录本场贡献、可领凭据、实际入箱、随身物品和总经验净变化。单次经验快照无法区分战斗获得和固定结算经验。每轮用真人或原有队伍真实跑图计时，并记录武器、弹药与辅助状态。

黑旗林营继续承担短线救援，先修领奖和撤离的动线。下一批可在黑帆海盗湾试登船夺旗，在深岩失落矿城试守住补给台和恢复照明。潮汐沉没圣所用可辨认的水位或换气点，霜落古堡和熔火铸造厂分别试掩体与灭火配合。剩余遗迹先补真实体验，再定是否延长。

## 开关与存档

仅在已核对坐标的艾恩葛朗特回响城启用 `dungeon-encounters.void-citadel`，同时要求 `dungeon-enemy-moves.enabled`。关闭后新场次使用旧波次。已开场的新版检查点仍按原版本续接；重启保留已结算房间，在当前未清房间从第一波继续。正常退回旧制品前应等新版场次结束，保留现有奖励、秘宝、角色和世界。
