# 配置阶段的单一物理状态管理

经过 Velocity 登录大厅和 Youer 后端的多轮 CONFIGURATION 后，Skill 兼容层曾把核心保护暂时设下的 `physicsEnabled=false` 当作原状态，在 PLAY 位置包之后再次写回，导致角色登录成功却不能正常走动。

PR75 初稿强制恢复 true，但会覆盖调用者主动暂停的物理状态。修订后由核心 `installConfigurationPhaseGuard` 独自保存与恢复；Skill 的旧版兼容层只过滤过渡期移动包，不读写物理开关。核心同时拦截 `entity_action`，直到收到当前 PLAY 位置，避免旧世界动作穿过配置阶段。未授权任何动作重放，也不强制开启飞行或改变身份。

7 项跨层回归覆盖两种安装顺序、原状态 true/false、多轮切换、轮次间状态变化、尚未收到位置、关闭兼容层和断线。初稿 6 项失败，修订后 7 项通过；核心真实 minecraft-protocol 插件的 4 项回归通过。测试使用显式连接替身，不把它们称为真实服务器行走验收。

源码修复不自动更新已下载的 Skill。新候选 1.3.8 继续固定 rc.130，其 Bridge 已包含核心保护；同一组 7 项跨层回归在 rc.130 实际编译模块上也通过。新包只更新版本和本次兼容层，1.3.7 及更早下载保持原字节，不冒称其他机器自动升级。

1.3.8 固定包为 4,290,298 字节，SHA256 `10ce45fa4e14b61fd65e2cd1287863b7c824282dcbd6bd8342c2f5f65e05f2a6`；归档及说明存入现有 OSS 的摘要目录。官网目录切换、远端安装和真实服务器行走分别验收，合并源码不代表这些步骤已经完成。

8 项打包回归通过，覆盖可重复构建、LF/CRLF、归档完整性及包括 1.3.7 的旧包不变；HTTP/接入/配置阶段 16 项通过，3 项因当前 Windows 执行账户不支持 CurrentUser DPAPI 按既有条件跳过，交由 Linux CI 验收。新 ZIP 实际解压、安装锁定依赖、校验运行时及导入 SDK/MCP 通过，安装包上的 7 项跨层回归通过。OSS ZIP/JSON 均已匿名下载核对摘要；本地核验没有连接游戏。
