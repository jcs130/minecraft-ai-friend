## 普通用户的步骤

1. 完整解压，双击 `一键安装.cmd`。不要在压缩包中直接运行。
2. 等待中文入口完成资源准备，按自动打开的指南在 Neko 插件中心导入相邻 Windows 插件。
3. 绑定自己的模型，选择服务器，再显式开始。升级前正常停止旧版游玩，保留原配置和数据。若提示旧离线环境不匹配，点击「使用已安装的新版运行环境」再开始；只重选运行资源，不改账号/模型/记忆和数据，也不自动启动。外部/自定义路径不自动替换。

安装器自动采用短用户缓存，不需要管理员权限、注册表修改或手动打开长路径。第一次准备会校验并复制约 7.4 万个文件，有分阶段进度；原始解压目录移动后，已准备的缓存继续独立工作。若解压工具先报路径太长，应完整解压到较短目录，例如 `D:\NekoMC`，不能跳过失败文件。
