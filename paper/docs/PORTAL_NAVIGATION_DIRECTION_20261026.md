# 首页、导航与渲染方向修复候选

此页描述候选，正式官网仍为 0.8.25；源码提交与发布包不代表已切换生产。

## 页面

官网 0.8.26 的首页与内部页面复用一份导航：主入口保持首页、居民、直播和加入；
世界状态、足迹、挑战与成长在「探索世界」，照片、回忆和书库在「世界作品」。
登录后的背包、连接与账号管理在账号菜单，原路由与权限保留。
首页首屏将标题、介绍和按钮放在一起，场景图在桌面并排、手机叠放；
原照片、宣传片、角色与作品内容继续使用。
手机菜单支持遮罩关闭、Escape、切页自动收起和当前页标识。

## 共享渲染

修复已进入 `jcs130/mc-visual-console` 的 `0311fcac046c1f7adcbf7fd22b137b6d89af64e0`，服务器候选消费同一冻结源。
Paper 的 YSM 输入把相对头部朝向传反；可米原奔跑 `Root.rotation.z = 0.4*ysm.head_yaw`
因此向转弯外侧倾斜。现在统一成 YSM 的负 Java 相对偏航，并在 Y-down 头骨空间转换一次。
不改原动画文件，也不把所有 Z 旋转整体翻转。

旧现代画面底层还把怪物主手挂到左臂。适配在绘制边界按原版 Mob LeftHanded 标志修正，
不交换原始装备槽数组，不影响玩家/YSM/库存的数据含义。
官网原生路径的怪物本来使用真实主手，但弓、弩此前没有动态模型提供器；
新增依据真实未使用状态及完整装填组件选择原待机、箭或烟花模型，继承原左右手 display。
已选弩模型继承基础弩的合法关系不再被当成覆盖规则循环。
缺少拉弓/装填进度仍明确不可用；三叉戟专用三维模型等未支持内容不冒充完成。

原生模型、纹理、材质、UV、资源来源和校验限制保持。
Java 1.21.1 是验收目标，1.20.6 旧现代画面适配继续保留；
该修复不要求修改 Agent 客户端，也不要求重启 Paper 或登录代理。

## 验收与发布

页面 DOM 与实际浏览器桌面/手机检查、共享渲染回归和原始资源持械画面分别记录，
不能以模拟状态或截图代替生产移动负载验收。
发布须冻结共享提交、重新构建匹配原版本的页面及资源、记录摘要，
并核对官网容器和家庭观战源实际提供的文件；只正常切换官网及必要观战后台。
当次停启仍需服主确认。保留原网站资料、资源来源和 E/F 前像，不恢复旧玩家数据库。
