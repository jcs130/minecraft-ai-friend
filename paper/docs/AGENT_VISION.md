## 相同的可见性规则

所有 Numen 同伴的普通实体扫描、实体 `scan.sight`、自动防卫和路线威胁场共用 `NearbyEntities`。服务器侧 AgentVision 使用同一个实现处理联网 Agent 的生物、玩家与掉落物同步，客户端无需安装补丁。

- 按 AgentFriend 已登记身份及 `ag_` 名称识别普通 Agent；身份识别不授予登录或管理权限。原观战账号、Goddess 和真人不作这种实体同步过滤。Numen 虚拟身体在自身感知工具里过滤，不重复执行联网检查。
- 玻璃、染色/遮光玻璃、玻璃板、冰、黏液、蜂蜜、树叶和水可以透视；栅栏保留空隙，铁栏沿原版视觉形状处理。身体一部分露出也算可见。完整实墙、地面和岩浆仍遮挡；普通隐身可见性按原版对观察者的规则判断，观战目标不作为普通实体报告。
- 先看目标眼睛，被挡住时最多采样身体盒内27点，不以盒外采样绕过整墙。一次查询里复用已命中的遮挡形状，后续查询重新读取，不缓存过期的方块或目标位置。
- 联网普通感知范围默认64格。在线名单保留原版玩家名与UUID；隐藏世界实体后仍可识别私聊发送者，退出时清除名单条目。显示实体、气泡和引导标记继续由原插件控制。
- 付费探敌术仍按原魔力、范围、持续时间与冷却执行。AgentFriend仅把实际已施法的轮廓目标交给可见性服务，结束时撤回；不会因过滤而取消合法的心眼轮廓。

这是服务端形状和材质近似，不是逐纹理像素判断，也不限制视场角；没有改写地形、容器和声音协议，不是面对恶意客户端的完整防作弊沙箱。看得见不等于能穿墙攻击、交互或通行。

## 性能与诊断

AgentVision只维护客户端原本进入追踪范围的目标，不逐玩家遍历整个世界。每tick轮转处理，默认最多128次检查、512次队列访问，目标通常每4tick重查；约2毫秒为协作时间预算，单次检查必须完成，故不是硬实时上限。超出预算的首次追踪先隐藏，稍后补查；只在可见性改变时发送隐藏/恢复，离开已发送区块的目标会释放。

控制台或有 `agentvision.admin` 权限的管理员执行：

```text
agentvision status
```

仅向调用者返回 `MC_VISION`，含实际检查数、峰值每tick检查数、完整世界射线、形状复用数和延迟处理计数，不在公屏广播。2毫秒预算、检查上限与半径可在 `plugins/AgentVision/config.yml` 配置，下次正常启动加载。
