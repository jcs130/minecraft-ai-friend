# 官网存储与发布门禁

公开安装包和 Skill 使用 OSS，官网 `/downloads/<文件>` 返回跳转，不代理大文件。
Cortico、DSH、NEKO、音频等使用同一个 `packageLocation`，源码只保存下载清单。
账号库、归属、私人设定图和原角色观战缓存不能因此转成公开 OSS 对象。

2026-10-25 发布时，云主机普通用户可用空间为零。磁盘虽仍有 root 保留
空间，网站以 UID 1000 运行，SQLite 无法建立共享内存文件，新旧容器均无法
启动。释放空间后原库自行恢复，完整性检查及 17 类资料对照通过，没有用旧库
覆盖。此次清理了经验证可从公开 Git 提交恢复、没有修改及服务引用的旧源码
副本，以及一个与现存 CARLA 镜像的原配置、六层和 OCI manifest 完全匹配的
重复临时导出包。CARLA 镜像、其他项目、网站资料和游戏数据保持。

发布前执行只读门禁：

```sh
python3 paper/ops/portal-storage-guard.py /var/lib/qiandengji-portal/data /opt/qiandengji-portal --write-budget-mib 256
```

检查 `f_bavail`，不把 root 保留块当作网站可用空间。默认要求备份／发布预计
新增占用后仍保留 2 GiB 和 1024 个 inode。低空间须在停止现役网站之前退出。
该工具不删除文件、不修改分区保留量、不改变用户或容器权限。

恢复或回退必须重新检查 HTTP 健康和 SQLite 完整性；只收到 Docker 的
`start` 成功不代表网站恢复。重试使用独立场次目录，保留首次失败与自动回退
记录，不删除旧的 once-only 标记后盲重放。游戏 Paper 不随网站维护重启。

原安装包继续在 OSS；云端至少保留现役和最近回退镜像、当前一致性备份。
更多历史完整备份应先核对 E/F 双份摘要，再移除云端重复副本。其他项目和
未知文件不能按“大文件”或“旧日期”批量删除。
