# 体验池临时名额回收（SIG-1，未部署）

2026-11-05，基于 `main@cbf2c6d3b83006b8d8aa550c6cc74c24a924e8b0`。
对应 [Issue #43 / SIG-1](https://github.com/jcs130/minecraft-ai-friend/issues/43)。
本次仅实现源码候选和隔离验证；没有访问、清理正式数据库，没有部署官网、重启游戏或修改现役角色。

## 完整状态关系

1. `public/agent-register.mjs` 在发请求**之前**保存 `clientId/requestId`、`clientSecret`、游戏建号 `gameRequestId` 和独立 `gamePassword`。中断后复用文件，不能另建身份。
2. `AgentAccess.publicRegister()` 在 `BEGIN IMMEDIATE` 中检查原请求、名字、网络限流、体验池容量，写入内部邀请、网络计数及 `agent_clients`。这里只保存预期离线 UUID 和 API 密钥哈希，尚未创建游戏账号。相同请求、名字和密钥重试返回原身份，不续期、不重复计数；更参或抢占原名拒绝。
3. `login()` 签发一小时 API 会话；会话更新、状态查询和注册重试不延长临时名额。API 密钥不是游戏密码。
4. `activate()` 先检查原请求状态、桥就绪、密码及已有游戏角色。`GameAccounts.start()` 在最终持久化处使用同步内部回调，将**名额复核、客户端请求号绑定、建号任务插入**放入同一 SQLite 写事务。事务中没有异步等待，提交后才允许发送加密请求。
5. 本地桥或 `CloudAccounts` 发送加密请求。云端出站标记、送达回执、游戏执行成功是不同状态。LoginGuard 在不可逆操作前保存 running 回执；异常或请求超时均不能推断账号不存在。官网保留原任务并查原结果，迟到成功需通过原请求、名字和预期 UUID 核验。
6. 成功后持久化 `portal_agents`、体验池的 `ownerships` 和成功任务。角色此时占用正式体验名额。网页退出、API 会话过期或邀请撤销均不会移除游戏身份。
7. 主人认领必须通过现有 LoginGuard 游戏内认证证明。`transferTrialAgent()` 在认领事务内迁移归属、原 API 客户端、原成功建号回执及现有外观归属；不发第二个 create，不改游戏密码、UUID、背包或成长数据。认领成功后才释放体验池容量。

## 名额规则

总容量仍为 100；普通网站主人自己的邀请码及五角色配额不变。未使用的管理员体验邀请仍按原有效期占位。

| 状态 | 识别依据 | 占体验池名额 | 后续处理 |
| --- | --- | --- | --- |
| 待用体验邀请 | 未使用、未撤销、未过期 | 是 | 兑换时转为注册名额，不另占一席 |
| `awaiting_activation` | 体验注册不足 24 小时，没有建号或身份记录 | 是 | 使用原身份激活 |
| `registration_released` | 体验注册已满 24 小时或已撤销 API，且无任何建号或身份记录 | 否 | 不删除身份；未撤销的原客户端激活时重新竞争名额 |
| `creating` | 存在未到期 pending 建号任务 | 是 | 查询原请求 |
| `creation_unknown` | unknown、过期 pending、异常任务状态或悬挂请求号 | 是 | 保留并核验原请求，不能按年龄回收 |
| `creation_failed_review` | 有历史失败建号任务，但无已确认身份 | 是 | 不把通用 failed 当作账号不存在；原失败任务仍可按既有协议重试，断链记录需核验 |
| `created` | 已成功建号，或已有 UUID/名称对应的门户、归属、归档记录 | 是 | 保留原身份，等待主人认领 |
| `claimed` | 体验来源客户端已随认证认领转至主人 | 否 | 原身份、原回执及 API 接续保持 |
| `custody_review` | 体验池托管记录缺少可信体验来源 | 是 | 保守保留，人工核验 |

24 小时从原始 `agent_clients.created_at` 计算，不是最后登录时间。该值为代码固定策略，选取与现有公开内部邀请的一天期限一致的保守窗口；没有新增后台清理任务。

容量由只读查询计算。超时仅释放**预留名额**，不删除或撤销 `agent_clients`、邀请、网络限流记录、任务、归属或游戏数据，也不释放名称给另一个人。旧记录在新代码下按同一规则判断；仅新增两个任务查询索引，无数据清理迁移。

证据检查不限于当前 `game_request_id`：历史建号任务按请求号、预期 UUID 或规范名字匹配。断开的历史任务、已建身份和撤销后的真实角色仍被保护。缺失当前任务关联却存在身份/建号证据时，status 返回 unknown 并要求核验，激活不能重建。

## 并发、重试和中断

- 公开注册、体验邀请批次和过期身份激活共享同一容量计算及 `BEGIN IMMEDIATE` 边界，支持独立 SQLite 连接/线程争抢最后一席。
- 预检失败不写任务；客户端请求号和任务插入任一步失败则整体回滚。任务提交后的桥异常保持原 pending/unknown 记录；重启后仍占位，不能再次发送新建号。
- 保留旧版「请求号已写入但任务未插入」的恢复：只在全库确实无对应任务时清除悬挂指针；存在不同归属的任务时保留 unknown。历史同名/同 UUID 任务仍阻止新建号。
- `TRIAL_POOL_FULL` 明确发生在建号任务持久化之前。独立 helper 收到该明确拒绝后保留全部凭据，撤回本地 attempted 标记并返回 `awaiting_trial_capacity`，以后同一命令可接续。网络异常、响应无法解析和未知结果不清除该标记，也不自动重发；继续查询原状态。
- 原身份注册重试和登录不重新占位，因而不能用心跳把废弃预留无限延期。过期身份有原凭据仍可恢复，但不保证立即获得名额。

## 只读诊断

从 `paper/integrations/agent-portal` 执行（要求 Node 22.13+）：

```sh
node scripts/trial-capacity.mjs --database /path/to/portal.sqlite
node scripts/trial-capacity.mjs --database /path/to/portal.sqlite --details
```

建议先使用一致的 SQLite 备份/隔离副本。工具必须显式指定现有文件，使用 `DatabaseSync({readOnly:true})`、`query_only` 和一致读事务；不构造会迁移/清会话的 Store，没有 apply/delete/repair 模式，也不连接游戏或读取网站私有配置。

默认输出总容量、占用、可用、待用邀请数及各状态计数。`--details` 另列客户端 ID、角色名、UUID、当前游戏请求号和预留到期时间，输出应由运营私下保存；不输出密钥、密钥哈希、会话、网络哈希、密码或加密请求正文。

`created`/`creation_unknown`/`creation_failed_review` 等仍占位是保护机制，不能据此执行批量删除。尤其不能把超时、撤销 API 或 failed 等同于可销毁游戏身份。

## 隔离验收

`tests/trial-capacity.test.mjs` 使用真实门户方法、独立临时 SQLite、受控时钟、独立连接和 Worker 线程；不向正式站点发送注册请求，也不伪造 HTTP 来源头绕过限流。

- 原始主干：100 次不同合成网络来源注册、零个建号任务，第 101 次被拒；推进到 24 小时后仍 `TRIAL_POOL_FULL`，新增回归稳定失败。
- 候选：同一回归通过；23:59:59.999 仍满，24 小时边界释放，100 条旧身份逐字段保持，原注册可幂等恢复。
- 120 次并行注册恰好接纳 100 次；6 个过期身份争抢最后一席只产生一个任务；混合注册、邀请及激活共享容量。
- 同一身份不同激活请求竞争、相同请求号并发重试、预检期间另一工作进程读取 status、任务插入失败回滚均覆盖。
- 未知派发、独立连接重新打开数据库、超时、迟到成功、加密云端回执和认证认领均覆盖；原密码密文/请求号/UUID/API 密钥哈希保持，没有第二次 create。合成背包及成长文件字节保持；这不是正式游戏联机验收。
- 已撤销但已建号、历史断链 pending/unknown/成功/失败任务均保护；只读诊断不改数据库字节、不创建缺失数据库、不泄露凭据。
- helper 从明确满池拒绝恢复，保留同一个本地身份文件、建号请求号和游戏密码。

最终结果：15 项新增容量回归包含在 **431 项官网非浏览器测试全部通过**中，另有 136 个顶层 JavaScript 模块语法检查和 Worker 文件语法检查通过。公开源码边界检查通过。

首次全量执行还发现本检出缺少锁定 Skill ZIP，补齐本地已有公开包并按原 SHA/字节数验证后，其下载及分发 CLI 测试全部通过。两项原有 Chromium 浏览器测试因当前执行环境禁止所需 socket/ptrace 而无法启动，最终非浏览器集合明确排除了 `music-browser.test.mjs` 与 `site-shell-browser.test.mjs`；没有改测试绕过限制，也不宣称浏览器验收通过。

复跑命令：

## 发布及回退边界

本补丁没有被部署。未来发布必须另获本次生产确认，先做一致备份及上述只读分类。应正常停止旧官网写入进程，再整体切换相关模块；不要让旧版先写指针的激活流程与新版同时写同一数据库。游戏服不需要因本补丁重启。

不清理真实账号，不重置 UUID、密码、存档、背包或成长；不对未知结果自动重放。若需回退，只切代码，保留最新数据库与游戏进度；旧版会重新把所有注册计入容量，可能再次满池，不能用旧数据库覆盖来掩盖。

本次解决未激活注册的永久占位，不承诺阻止持续注册在 24 小时内临时占满，或攻击者真正建号后占用名额。已建号及无法证明无身份的失败记录需要认证认领或单独核验。身份/名称及网络计数保留也意味着记录仍增长，数据库保留策略属于后续工作。
