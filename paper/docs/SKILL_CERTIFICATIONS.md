旧技能ID、旧学习资格、原16项职业效果和技能点池保持。已经选职业的旧角色也能看到新增一级学习资格，无须重建资料；学习由本人主动花点。满级累计支付各级费用。二级要求对应`*_basic`证书，三级要求`*_advanced`证书，考试不赠送额外点数。

御空与通用`flight`共用同一临时飞行管理器，不可同时开。退出、死亡、倒地、传送、换世界、切换模式、洗点、职业切换及关服会清理本系统持有的权限；原始飞行权限与速度保存在玩家PDC恢复标记中，用于异常退出后的登录恢复。实际验证范围见[0.4.18发布清单](../manifests/gameplay-release-0.4.18.json)，正常重登和正常冷启动不代表断电测试。

祝福只选择同世界、可见、有效生存目标，沿用PvP和倒地限制。更强或更久的原效果保持；只有实际增加或延长的效果才记录受益人。全部被保护插件取消时退还本次费用并清除本次冷却。自己可以自保，协作证书需要其他玩家的实际受益和行动。

## 能力证书

| ID | 服务器实际验收 |
| --- | --- |
| `flight_basic` | 一次本场付费飞行；空中水平至少24格、上升3格、转向60°、面朝前方后退4格、依次通过至少3个航点，落到指定平台稳定2秒 |
| `flight_advanced` | 基础证书前置；水平48格、上升6格、后退6格及更长的有序航线，稳定落地 |
| `leap_basic` | 本场本人施放高跳，真实跃高至少6格，水平至少2格并落到指定高台稳定2秒 |
| `leap_advanced` | 基础证书前置；两次独立施法、各次至少6格，依次落上两平台，累计水平至少5格 |
| `support_basic` | 同次祝福实际作用于至少一名其他玩家，队友在效果时限内实际行进4格 |
| `support_advanced` | 基础证书前置；至少两名其他玩家各行进4格，另有本次抗性I对怪物攻击的实际减伤，或既有治疗恢复怪物伤量 |
| `inventory_basic` | 成功查list、技能详情、本人状态；普通大背包存入并重开取回、总量守恒，以及合法木门通行和连续爬梯；可复用已完成的真实实练 |
| `shelter_basic` | 本场交付`builder_home`，检查地面、墙、屋顶、外窗、完整通行门、完整床与本人施工证明 |
| `survey_basic` | 本场交付已有市场真实结构走查或原图寻宝任务，复用实际调查与返程要求 |
| `cooperation_basic` | 本场真实扶起倒地队友，或至少两人共同通关一层试炼；单人清场不计 |

正式四项移动题已在云阶考场开放：村西梯口约(-676,64,-424)，起点(-671.5,101,-423.5)。已先勘察、隔离实走并逐块核对163个方块再施工，登记实际世界UUID；只有构筑物受保护，周围地面仍可用。源码默认`courses: {}`仍作为新世界的关闭模板，不能把本世界坐标直接用于其他存档。

轨迹按5 tick采样，连续距离只用实际相邻位置；超过750毫秒的采样间隔不补算。飞行和高跳使用不同的原版速度上限，防止合法高跳被误拒。传送、模式变化、死亡、退出、骑乘、鞘翅、漂浮及真实伤害会中断移动题；当前位置超出考场或速度跳变也会中断。服务器只证明所观察到的动作，不断言客户端按键或自主规划质量。

进度只在开考、施法、航点变化、中断、达成及交付等节点持久化，不逐tick写盘或留全量轨迹。同一轮采样内的多人航点、到期中断和达成记录合并为一次强制原子写入；持久化成功后才提示通过或推进委托，写入失败停止验收。重登/重启保留证书、已交付记录与待交付成果；未完成的连续移动需重新开考。两跳题在同一次在线考试内保留已落台段；本版冷重启后重新做本题，没有跨重启续接独立跳台阶段。

## 冒险者18阶

沿用青铜、黑铁、白银、黄金、白金、钻石，每段III→II→I。最低声望分别为：

| 大段 | III | II | I |
| --- | --- | --- | --- |
| 青铜 | 0 | 4 | 7 |
| 黑铁 | 10 | 17 | 24 |
| 白银 | 30 | 44 | 57 |
| 黄金 | 70 | 97 | 124 |
| 白金 | 150 | 217 | 284 |
| 钻石 | 350 | 450 | 550 |

旧有效大段按UUID一次映射至同段III，保留声望、旧认证、点数、委托履历和奖励。旧`min-rank: 0..5`、倍率、限额继续读取大段；新增`gradeIndex: 0..17`和`division: 3|2|1`单独显示。

声望只开放资格；本人主动选择下一阶题目，完成本场实操并交付才晋一级。不会因声望超额自动跳阶，失败不降级，晋级不发额外声望或点数。旧大段的深层远征、海渊、宝库、千灯之巅、不同委托数量和能力类别履历门槛继续检查。

首版采用“已有能力证书组合＋本场一项新实操”。同一证书不能同时填充两个必选能力组。进阶阶段增加调查、住房及协作履历，仍可选择生活路线。提案中的多阶段现场综合题库、完整独立阶段冷重启续接和BossBar尚未实现，不应宣传为已完成。

```text
/mycli skills list warrior|mage|priest

/mycli guild exam list
/mycli guild exam info flight_basic

/mycli guild exam status
/mycli guild exam submit
/mycli guild exam cancel
/mycli guild exam promotion
/mycli guild exam start promotion <题目ID>
/mycli guild certificates
```

公会原版菜单增加“训练与考试”；选择题目、查看条件、主动确认开考。命格书显示当前段位、声望与能力证书，学习详情列出升级所缺证书。移动题每秒向本人投递下一航点粒子；`exam status`显示世界UUID、绝对坐标、距离、已测量数据和下一步动作。原Agent无需修改客户端即可查询和施法。

独立考试与市场委托共用本人任务槽。`contract_record`考试允许接取匹配的真实调查、工程或供货单作为证据；不能嵌套另一个能力验收单。已有实操证书可以重练，不重复发奖励。

新增`MC_GUILD_EXAM`、`MC_GUILD_CERTIFICATES`及`mcagent:exam`都是本人私有回执；JSON含schemaVersion=1、subjectUuid、scope=self及type。`mcagent:state`和`mcviewer:state`仅追加精简`academy`摘要，保留原schema与16384字节预算；Eye/live读取实际附身对象，不按名字猜旧角色UUID。Web尚无独立考试面板，现有聊天/状态桥可传输这些数据；远端页面仍需各自更新。

## 配置运营

`skill-assessments.yml`登记课程及最多32题，每题至多8航点/证明，原语为`flight_route`、`leap_route`、`support_route`、`native_lesson`、`contract_record`。`adventurer-grades.yml`保留18阶及旧大段阈值。六张职业升级证书的固定ID不能被误配置成简单CLI查询，也不能下调最低动作要求。

默认建房和协作考试限时2小时、远途调查24小时，行囊教学10分钟；飞行、跳台和祝福使用各题的短时限。配置上限分别为真实合同24小时、原生教学2小时、其他动作10分钟，避免远途任务被短时技能考试的上限截断。

```text
# 仅服务器控制台/RCON；不是玩家指令
mycli admin assessments reload
mycli admin assessments audit
```

加载时同时校验考试与任务市场引用，失败保留上次有效目录。开考和市场接受时冻结完整条件与摘要，热改只影响后续接受；撤下/禁用题目会停止正在执行的活动。更改新技能价格或效果仍须按现有职业整体验证加载，不能靠考试配置修改技能价格。

任务市场新增goal示例：

```yaml
steps:
  - title: 云间送信
    description: 在登记场地完成本人的飞行路线
    goal: SKILL_ASSESSMENT
    assessment: flight_basic
    target: 1
```

只有真实完成的服务器考试才推进该目标；客户端没有上报距离、伪造通过或直接发证的接口。市场阶段用`guild claim`交付，独立`exam submit`不会旁路市场奖励。
