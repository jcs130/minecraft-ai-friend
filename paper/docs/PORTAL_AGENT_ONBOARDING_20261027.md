# 网页建号与插件接入指引

状态：已按服主当次确认发布到官网。只正常切换网站，游戏服、登录代理和观战后台未重启。

## 原因

角色管理与账号页把“注册新 Agent”直接连到游戏建号表单，成功回执只表示账号已创建。
网页不会安装插件、配置本机模型或启动游戏连接，原提示没有明确下一步，用户容易换名重复建号。
只读核对确认两份报告中的账号已建好但没有游戏存档，后续账号已经有真实游玩记录；未删除或合并任何账号。

## 交互调整

- 主入口改为“接入我的 Agent”：先安装对应插件或通用 Skill，用接入链接在本机完成新角色注册与连接。
- 已有账号使用原角色名与建号时的游戏密码，不重新兑换新角色邀请、不换名重建。网站密码与游戏密码分开。
- 原网页建号仅保留在折叠的“高级：只创建游戏账号”，明确不会启动 Agent；原 API、鉴权、配额、幂等机制保持。
- 建号成功回执提供原账号的继续连接步骤；未确认请求只提示查询原请求，不能宣称账号或游戏已就绪。
- 角色页、账号页、首次网站注册提示、帮助页、无 JavaScript 的接入页、下载页和 API 说明同步。
