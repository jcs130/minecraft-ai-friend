## 构建

在任务独立 Python 环境安装 requirements.txt。Node 侧使用已有的 `prismarine-block` 1.21.1 碰撞库；不修改生产全局依赖。

1. `python build.py --packs <本机已装结构包目录> --export-states <全新states.json>`，导出模板及手工扩建的方块状态列表。
2. `node export-collisions.mjs <已有依赖项目/package.json> <states.json> <collisions.json>`。未知方块必须失败，不替换为石头或空气。
3. `python build.py --packs <本机已装结构包目录> --collisions <collisions.json> --out <全新输出目录>`。
4. `python prepare_overlay.py --existing <dungeons.yml只读快照> --bundle <构建输出> --world <aincrad目录> --out <全新计划目录>`。

`sources.json` 固定输入 SHA256。原始第三方 ZIP/NBT 不入库；本工具只读取本机已有素材，输出放在私有维护目录。已失效或不匹配的素材直接拒绝构建。若源模板未来升级，必须重新审查、选点和联机验收，不覆盖稳定地点 ID。

## 几何与部署边界

按真实碰撞区分整格、半砖、楼梯、液体及危险方块。完整地板、足够净空和备用刷怪点是开场条件。连通图只用于候选选点，不能替代普通客户端实走；不同模板的拼接缺口、原生水流、门、护栏和窄楼梯仍须现场验证。

当前修订 `ruins-20261109-r2` 在原模板内补建实体战斗地板、连接通道、阶梯、护边和照明；保留外围建筑，各房增加掩体与侧台。路由避开其他楼层的地板与净空，生成失败即停止，不拆掉上层地板制造连通。熔火房保留真实岩浆危险，不自动发放抗火。八个备用出生点留出大型怪物的落脚空间；实走和普通战斗仍是验收条件。

模板连接器仅解析 `final_state`；不执行拼接池或数据包函数。移除全部原始实体、方块实体负载、刷怪器、命令方块、试炼刷怪器、宝库与 TNT。旧 `grass` 明确迁移为 `short_grass`，取消装饰方块的含水状态以避免水流破坏入口，显式水体保留。全部修订计入 manifest。

没有 load/tick 函数，不会安装后自行改世界。模板仅可用于全新、已确认范围内的施工；省略的模板单元不能被当作任意现有世界里的空气。当前计划采用隔离构建后的完整新 region 文件，要求正式目标同名的 region、entities、poi **全部不存在**；遇到任何一个已有文件即阻止整区导入。不得用旧 QA 整区覆盖已经开放的玩家空间。

地点边界与路线是绝对坐标。保护盒覆盖建筑、地基、连接桥和首领厅，空闲时也保留结构保护。新内容必须走现有维护流程、当次备份及安装后回读；本工具不停止正式服、不替换任何 JAR、不改变权限门禁。

## 游玩与运营

真人：技能罗盘 → 地下城 → 选择地点 → 查看装备建议与难度 → 前往 → 开始。原版箱式菜单兼容手柄，不依赖真人输入命令。

Agent：`/mycli dungeon list --json` 分页发现；`info <ID> --json` 查入口、难度和准备要求；`travel <ID> --json` 实际抵达后，再 `start <ID> normal|adventure|apocalypse --json`。`status <ID> --json` 的 `participant`、`target`、`fault` 和路线提示为下一步依据，不能把全服活动当作本人参赛。阶段之间沿实际通路走到下一室，全部完成后 `claim <ID> --json`；奖励进入既有个人箱/待领取队列。每日限奖沿现有 Asia/Shanghai 自然日规则，不额外增加无限刷取入口。

路线、战斗、领奖回执仍只发所属玩家；不新增周期聊天广播或客户端强制模组。Java、Mineflayer 和基岩共用原版方块、实体、物品及箱式菜单。协议可表达性不等于手机/Xbox本人实测通过，记录中须单列。

## 验收

`python -m unittest discover -s tests -v` 的 15 项检查覆盖有副作用素材的剥离、真实半砖高度、液体不作为干燥路径、未知物理拒绝、原 ID 保持、叠层通道净空及已有 region/实体/POI 拒绝覆盖。

`qa/RuinsFixture.java`、`qa/client.mjs` 是隔离验收工具，限制 `127.0.0.1:40081`、私有 RCON 40085 和专有 `.qa-only` 标记。Fixture 绝不能装正式服。客户端使用普通 Mineflayer、实际导航和普通攻击；测试装备和魔力由控制台准备，不能将它当作普通角色的难度平衡证明。实际怪物类型、主手、AI、目标、位置、伤害/投射物观察、参战、奖励、重复领奖均应留下回执。失败记录保留，不传送越过失败路线或放宽保护来制造通过。

使用 `qa/prepare.py --source <现役目录> --bundle <构建目录> --stage <全新隔离目录> --java-bin <JDK/bin>` 复制必要的只读二进制和静态玩法目录；不复制玩家、账号、NPC 注册表、模型/语音凭据或世界。它不会自动起服。联机脚本会按需在隔离世界实际建设原地面试炼场和地下六层，以启用现有个人箱入口，不用虚设 built 标记代替设施。

联机默认指定 `QA_CORE_ROOT=<已部署MC核心/package>`、依赖参数 `<同目录/package.json>`，复用现有核心的真实版本协议修复；`QA_PLAYER` 指定合成角色。未经修复的上游依赖存在药水和特殊物品解析缺陷，不能将其报错忽略，也不能声称任意原版依赖组合通过。脚本会记录实际核心版本、装备、测试准备和限制；领奖除队列回执外，还核对真实 54 格箱窗口及材料数量增量。
