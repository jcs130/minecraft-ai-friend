## 质量与来源

模型来自 [YSM文档推荐的公开合集](https://github.com/Elaina69/Yes-Steve-Model-Repo)，固定提交与原包SHA256在 [catalogue.json](catalogue.json)。原贴图、几何、动作和作者信息保留。17份ZIP中3份不完整或超出几何预算；另有禁止自由使用、贴图过大及尚未支持的表达式/骨骼/时间轴，均未进入本批正式目录。加密模型不解包。

14套原生选装验收、12套真实WebGL模型审阅后，8套通过站立/走路/跑步。其中5套已适合当前官网，另3套需要共享渲染器 `9958361a` 的可选手臂修复。不同原包的攻击和进食轨道有缺项，逐项保留在清单，不能将“能跑步”写成完整动画一致。缺失第一人称手臂不会再阻止独立第三人称模型；相关改动已推到[独立可视化仓库](https://github.com/jcs130/mc-visual-console/commit/9958361a)，尚未替换官网。

40份普通皮肤均来自现有SkinsRestorer签名推荐；PNG尺寸、来源、摘要核对，三种风格及启动后新加的预设由普通非OP客户端选装，第二标准客户端收到原签名属性，13项检查通过。两套新模型的完整动作和其他模型的局部动作以实际清单为准，不补画虚假服务器状态。

## 维护与回退

新增前完整备份公开模型目录及SkinsRestorer皮肤库到E/F两盘，校验两份前像；185份旧模型逐份保持。新模型和签名预设按原摘要先准备再原子放入，既有同名资源不同则停止，不覆盖玩家自定义内容。原模型链JAR、配置、鉴权与玩家绑定未写入。

回退只处理本次清单中的新增资源。先核实没有角色正在使用新模型；在用时保留文件，先由本人选择替代，不能删除后覆盖其旧存档。随后通过既有YSM生命周期控制器执行资源重载，核实目录和原角色状态。皮肤预设删除不应删玩家绑定、账号、背包或世界；恢复前像须避开之后新增的其他资源。
