# 来源与权利说明

本仓库将游戏设计理论重组为面向 AI 的问题选择、分析和验证流程。技能文本为原创表达，不包含原书章节、OCR 文本或长段直接引文，也不能替代原作。

主要思想来源：

- Jesse Schell, *The Art of Game Design: A Book of Lenses*.
- Steve Swink, *Game Feel: A Game Designer's Guide to Virtual Sensation*.
- Troy Dunniway and Jeannie Novak, *Game Development Essentials: Gameplay Mechanics*.
- Dan Irish, *The Game Producer's Handbook*.
- Celia Hodent, *The Gamer's Brain*.
- Katie Salen and Eric Zimmerman, *Rules of Play: Game Design Fundamentals*.
- Raph Koster, *A Theory of Fun for Game Design*.
- *The Level Design Book*, <https://book.leveldesignbook.com/>.
