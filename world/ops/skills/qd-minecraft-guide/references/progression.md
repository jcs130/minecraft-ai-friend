# 生存与装备成长

适用：千灯纪 Minecraft 1.21.1。目标由角色根据现况选择，不把“木器→石器→铁器”当成必须从头重走的脚本。

先查看实际生命、饥饿、当前位置、背包容量、装备和正在执行的任务。遇到真实危险，优先安全位置、进食或当前已会的防御手段；当前桐人没有自动进食反射，背包有食物也不等于会自行吃。一次紧急进食不需要先编程。

用“下一项能改善生活的缺口”选目标：食物不足可调查补给或种植，工具影响采集可查询替代装备，夜间缺少安全设施可改善住所；也可以履行已承诺合同、交流或探索。已有高阶物资可以直接利用，不为了完成教学步骤制作低阶套装。

## 采矿与制作

- 用 `look`、必要的 `scan_blocks` 和 `inspect_block` 确认附近实际材料与通路。扫描只覆盖已加载世界，不能声称掌握未探索群系和地下全部矿藏。
- 选择当前阶段所需的少量自然资源，确认工具、容量与返程条件。不要按旧文章坐标直奔矿点，不把玩家墙体当资源。
- 原生任务结束后看实际入包数量；矿石方块消失不等于掉落已收到。要加工材料时按需读 crafting，不在成长计划里猜模组配方。

移动每步限水平二十四格，使用不挖不搭的步行模式。只在当前观察支持目标脚部高度时传 `y`，合法高度为 -64 至 319；未知时省略。到达同一平面坐标不代表走上了楼或已经接近高处 NPC。

## 成长的证据

人物成长看实际装备、库存、生命保障、可用工具、原生等级/属性、法术能力和公会功勋，各项分别验收。`adventure` 是整理后的事实提示，`other` 中的模组物品只是未分类，不等于无用。一本技能书在包里、一个 JS 程序已晋升，都不能替代人物变强的证据。

重复且已理解的步骤适合复用经过测试的程序；真实缺料、路径受阻或结果未知时应等待观察或重新规划。把“本次实测通过”与“可在各种环境可靠复用”分开记录。休息也是合理目标，沿用控制器的复盘和预算，不另建持续问模型的循环。
