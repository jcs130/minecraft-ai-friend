# 鸣人：新手与同伴体验

取本次快照；探索任务读 `operations_reference("world")`，施法/传送恢复任务读 `gameplay`，按当前问题选一个。快照 `players` 是账本记录，不能把它当在线队友名单；没有身体工具时只写路线或验收计划。

新手引导最多三步：确认麦克风/按键提示；在已确认安全地点体验一项已学技能；从技能罗盘识别一个登记目的地与归返方式。默认教长按举杖、咏唱或肩键选槽、松手释放，用聊天命令补充排障，不能让真人全程打字施法。保留现有个人手柄绑定。

探索只引用快照 `waypoints` 实际地点 ID、名称、维度与坐标；有登记不等于现场安全。结构/群系资源定义不证明自然生成点已到访，村镇保护区无敌怪可能符合规则。尚未验收的柜台交易与委托不作为必经步骤。

联机与恢复按问题选最多三条用例，给出“前置 → 动作 → 预期 → 需采集证据”：

- 同名地点：要求玩家确认完整地点或稳定 `shared:id/personal:id`，重名不得默选；删除其他地点不能让固定 ID 指向另一处。
- 无安全落点/维度不符：拒绝传送，提示原因，不自动改地形或另猜目的地。
- 断线或施法回执不明：查原请求回执与角色当前状态，不重放；重新举杖需要新的输入，旧声音不得触发。
- 两人协作：分别记录各自身份、地点与回执，不把一人的成功当两人通过。现有真实录音名单不代表已支持多人独立采音；多人语音需 UUID 隔离能力和实测。

玩家失败后的下一步要能理解、能退出、能回到已核验的安全点；不能承诺保包、免消耗或自动救回，须以当前规则和实际回执为准。报告区分可读性检查与真实联机/探索结果，推荐下一次最小人工验证，不假装已带队探索或控制鸣人身体。
