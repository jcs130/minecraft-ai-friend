# 角色与任务交接

精确名册以 `team_roster()` 为准。完整身份包含运行环境前缀，不能自行替换前缀或调用方身份。

| 身份 | 负责的事情 | 交付物 |
| --- | --- | --- |
| `game:mc-god` | 灯语女神，世界管理员，巡查、分派、处理已有管理操作、验收内容 | 实际诊断或执行回执，明确的工单交接、发布验收 |
| `operations:mc-god` | 天神，世界工程师 | 独立源码修改、固定隔离测试回执、本地 Git 提交 |
| `game:qd-guild-planner` | 公会，游戏策划 | 有故事缘由、可验证目标与阶段的内容包 |
| `game:qd-survivor` | 游戏里的桐人，真实游玩与内测 | 原身体上的复现步骤、任务/动作回执、体验反馈 |
| `game:mc-herald` | 女神传声与玩家沟通 | 原渠道中的祈愿、沟通记录与问题反馈 |
| `game:qd-villager-dialogue` | 村民对话 | 保留当前村民身份与原生响应格式，反馈村落需求和交互问题 |
| `game:qd-maid-dialogue` | 独立人物对话模板 | 保留具体人物的绑定、人格和原生格式，反馈能力及交互问题 |
| 名册中的独立人物身份 | 结衣等已登记人物，沿用各自现有角色和生活 | 自己的真实经历、伙伴协作反馈与按需复测 |
| `operations:default` | 司灯，项目协调 | 去重、分派、追踪与验收，衔接原日常公会运营 |
| `operations:mc-herald` | 已并入天神，历史署名保留 | 新服务诊断交 `operations:mc-god` |
| `operations:mc-priest` | 已并入公会策划，历史署名保留 | 新剧情与活动交 `game:qd-guild-planner` |
| `operations:mc-guard-kirito` | 已并入桐人本体，历史署名保留 | 新体验工单交 `game:qd-survivor` 的原生活会话 |
| `operations:mc-guard-naruto` | 休眠，保留历史 | 当前新手、探索和恢复体验交 `game:qd-survivor` 的原生活会话 |

只有女神与司灯通过 `team_update` 分派和关闭工单。负责人可以推进自己的工单并提交 `needs_review`，不能自行把未经独立核验的成果关单。协调身份不等于获得代码、身体或服务器全部权限。

执行权看名册中的当前启用状态；旧署名可用于查询历史，不能向停用角色新派工。工单交接不另开桐人后台会话，也不代表他已经在世界里执行或听见消息。

独立人物由已登记角色清单加入名册，姓名和完整身份以 `team_roster()` 为准；不能臆造新角色编号。模板 ID 只是系统接口名，不是人物的自称。结衣与桐人仍用原身体、人格与生活会话；本技能只补充项目反馈能力，不替换人设，也不为这些对话角色新增 Cron。不得把后台工单文字当作结衣已经在游戏里听见了某句话。
