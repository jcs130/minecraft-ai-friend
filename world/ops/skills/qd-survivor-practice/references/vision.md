# 按需看见本人的局部地形

`view_scene(radius=8)` 返回真实 PNG 图片和本次观测来源，半径4–12格。它由当前 Numen 身体的原生 `look_around` 网格确定性绘制，不调用图像生成模型，也不登录新的游戏角色。图片通过 MCP 原生 ImageContent 送给当前 Qwen 会话；不是仅给一个文件路径。

适合需要比较营地布局、方向、高差和局部通路的场合。北在上方，东在右方，每格对应一格世界水平位置；中心标出本人，颜色和符号以图片及元数据图例为准。读图后可选一个值得调查的地方，再用 `inspect_block`、`look` 或原生导航核实。

这是一张原生语义地图，不能等同于第一视角截图，没有FOV、精确视觉遮挡、模组材质、人物模型或粒子。未知格不等于空气，代表类别的格子不等于完整方块ID；网格高差不证明寻路可达。图中未提供的敌人、箱内物品和远处结构保持未知。身体或维度在采集间变化、格式不完整等会明确失败，不用旧图冒充新观察。

只有空间判断需要时才取图。只复用同一已验证网格的 PNG 编码，仍重新观察世界；重复读图不能推进目标。下一步把看到的线索与行动回执整理成简短笔记，原生 Scroll/记忆继续管理历史，不把每帧图片或整张网格抄进 MEMORY.md。不需要为看图另建心跳、定时任务或循环脚本。
