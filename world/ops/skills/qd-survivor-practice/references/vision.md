# 按需看见桐人自己的画面

`view_scene()` 默认返回桐人当前眼位的第一视角 PNG，不借用女神或观察者的相机。画面为 640×360、垂直 FOV 120，HUD 标出准星方块距离和附近物体；“附近”只说明距离，不证明处在视线内。返回的元数据包含身体、维度、位置、截图与几何采样时间。缺失视点、过期画面或渲染失败时明确返回无图，不能用旧图推断当前地形。

需要北上东右的局部俯视图时，调用 `view_scene(mode="map", radius=8)`；`radius` 只用于地图，可取 4–12。地图从 Numen 原生局部观察确定性绘制，每格对应一格水平位置。这张语义地图与第一视角截图用途不同，不能把地图方格当成有完整视觉遮挡的游戏画面。

连续导航受阻、需要辨认台阶或建筑入口时，取一次第一视角，再用 `look`、`inspect_block`、`scan_blocks` 或原生导航勘察核实支撑、高差与可达性。图像显示的通路不等于已验证路径；附近物体也不等于可接触。身体移动或维度变化后须重新取证。不要每轮重复取图，也不要把整张图复制进记忆。
