# 生存实践与两种学习

当前任务先读取 status 并复用后台感知：检查饥饿、生命、背包容量、正在执行的原生任务，以及观察时间。状态快照不覆盖全部模组内部状态；缺失信息先用只读工具获取，不据聊天猜坐标、装备或背包物品。

选择一个与当前目标相关、满足条件的动作。移动遵守有界距离与严格安全寻路；只有可靠观察脚部高度时才提供 y。近柜台、交付、交易和放置仍以实际距离、维度、容量与原生回执为准。公会领取不是完成，扣货、奖品入包需实际结算；遇到未知结果不重放。一次身体动作或 skill_start 受理后结束动作派遣，等对应 taskId/epoch 终态与后续观察。

反复做的已理解行为适合编程：先 skill_draft，再真实 fixture 的 skill_test，最后 skill_promote。不要手改测试通过标志；程序内核变化须重测原版本。纯观察和已验证程序不逐步请求模型。与此分开，learning_* 只维护自身 Markdown 判断流程，其校验不是程序或世界效果验证。

真实游戏法术通过 game_skills 查询、game_learn 参悟背包技能书、game_cast 施放，遵守原等级、法力和冷却。没有装备或书本并不等于已经学会。

有必要与附近玩家沟通时 speak 一句，speech_status 读取结果；queued/started 都不等于已被人听到。remember 留下目标状态、事实与合理复盘间隔；计划未完成时保留下一步，已完成时依据当前观察选新的目标。预算耗尽继续已派遣的安全快程序，不自动制造第二条模型循环。
