# 技能罗盘接口与验证

本目录构建的 botgate 将原技能罗盘统一为原版 `GENERIC_9x3` 容器（27 格）。指南针上已有的 `custom_data.skillbox=true`、原法术书入口、`skillchest self` 和 `wheel/panel/open <玩家> [页]` 都进入主菜单。使用 Controlify 的容器导航与 A 确认；键鼠用左键。实体手柄与真实游戏界面由集成验收确认。

| 位置（从 0 起） | 主菜单 | 传送阵 / 造物页 |
|---|---|---|
| 0 | 铁魔法法术书 | 第一个地点 / 物品 |
| 4 | 分页与秘术状态快照 | 地点 / 物品 |
| 8 | 传送阵入口 | 第九个地点 / 物品 |
| 9–17 | 每页最多 9 项已学精选主动秘术 | 第 10–18 个地点 / 物品 |
| 18 / 26 | 上页 / 下页（边界禁用） | 上页 / 下页（边界禁用） |
| 20 | 只读旧技能档案 | 铁魔法法术书 |
| 22 | 关闭 | 返回罗盘 |
| 24 | 刷新 | 刷新 |

`skillchest waypoints <玩家> [页]`、`skillchest archive <玩家> [页]` 支持主 CLI 打开对应页。页码从 0 起，越界自动夹取。普通玩家仅能打开自己；代开他人需 OP。测试点击命令只在显式 JVM 测试开关启用且 OP 权限时注册。

目录从 `settlementsfix.mcdataDir`（默认 `/mcdata`）读取 `skill-catalog.json`：`featured` 为 ID 数组，`archived` 为 `{id:{reason,nativeHints:[原生ID]}}`，`icons` 为技能 ID 到物品 ID 的映射。已学与出生天赋取并集，被动不进入施法栏。目录损坏或缺失时不回退到全部旧技能。旧档案保留说明、成本与原生替代建议，点击不施法，绝不写回玩家进度。

主菜单原生入口以当前玩家身份执行 `qdspell self menu`。精选秘术执行 `/mycli cast <id>`；造物先打开物品页，再执行带引号的 `/mycli cast give item="名称"`。展示基础消耗、默认参数和出生天赋豁免；参数成本与即时状态由统一 CLI 在确认时检查，不伪造实时资源判定。

传送阵每页 18 个地点，共享点使用 `shared:<id>`，个人点使用 `personal:<id>`，执行 `/mycli goto <引用>`。缺 ID、超出安全整数或同范围重复 ID 时只读；从不替换成可变列表序号。旧命格书传送页也使用相同读取器，每页 6 个地点；“记住这里”为 `/mycli waypoint add`，名称由世界端生成，原重名地点不修改。

图标不可取走：不调用容器默认点击处理，拒绝移动、拖拽、丢弃、快捷移动与非主确认键，只接受本人当前菜单。每个已打开菜单最多派发一次动作，在关页前锁定，重复包不重施；原生菜单继续负责它自己的装备、法力、冷却和确认。

离线构建与验证（不启动世界、不部署）：

```powershell
python world/botgate-src/build.py --pack
python world/botgate-src/tests/run_tests.py
```

测试覆盖目录筛选、出生天赋、被动和归档保留、损坏输入、23 个传送点分页与稳定 ID、重复/缺失 ID 禁用、造物参数转义、一次派发门禁，以及真实 Minecraft 物品组件的名称、颜色、分行说明和图标回退。同时继续运行 RCON 分帧与原版物品协议测试。所有 17 个原 mixin 注册保留；只有传送书页逻辑随本次授权调整，其余门禁、RCON 与装备逻辑不变。

尚需集成验收：正常停服后替换本目录构建 JAR，启动后实际右键原罗盘、打开铁魔法菜单、检查多页传送阵与归档只读，并记录游戏画面。离线通过不等同于已接实体手柄或在线施法成功。
