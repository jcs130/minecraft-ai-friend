- **指派**：司灯（修码）；天神复核裁决链。

## AUDIT-2026-08-26-03【中】守卫公屏刷屏

- **现象**：鸣人同一句「公会·岚！镇口鸣人在！」00:00–00:18 刷 80+ 条，峰值 3 秒 4 条（00:07:27–34）。
- **证据**：mc-server/logs/latest.log 公屏段；灯守 00:18:29 曾劝「别重复吆喝啦」无效。
- **根因**：guard ReAct 循环每轮默认动作 = 吆喝招客，无去重无冷却；世界侧公屏无节流。
- **修法**：①世界侧硬保险：同 sender 同文本 120s 内去重（numen say 或消息入口层）；②守卫 prompt 软约束：同一句吆喝 10 分钟不重复、招客改为守在板前等人来。
- **指派**：司灯（修码）。

## AUDIT-2026-08-26-04【中】NPC 空承诺不行动（灯守实证）

- **现象**：灯守（LanternWarden，LLM 村民）被 @ 后永远「收到/我这就去/等雨停/先守灯」，零行动；救援时打太极 18 分钟（「马上来」「正在想办法」「你附近有家猪，抓……」），实际无 goto/give 能力。
- **证据**：latest.log 00:00–00:46 灯守 ~40 条应承类消息无一条行动落地。
- **根因**：mc_npc 的 LLM 村民只有对话能力没有行动器，prompt 却纵容它承诺办事。
- **修法**：①mc_npc prompt 硬约束：没有行动能力就不许承诺「我这就去/我带给你」，只能说「我记下了，托给能跑腿的人」并转任务板；②救援话术降级：指路（哪有食物/找谁）而非「我马上来」；③中期：给关键 NPC 挂委托转办（NPC 收话 → 灶火任务板 → 守卫接单）。
- **指派**：司灯（prompt 修）；灶火（任务板转办设计，下一期）。
