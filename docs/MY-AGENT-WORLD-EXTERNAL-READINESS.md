## 证据口径

能力分别记录“能读取什么”“能操作什么”“实际做成了什么”；渲染单独记录。注册表可解析、界面可显示、请求返回成功、实际产物进入本人库存、模型独立完成生活目标，不能互相替代。

- **自主证据**：普通非 OP 账号使用线上模型和自己的连接、会话、行动账本，在自然世界取得材料并完成目标。管理员给物、传送、强制建造不能计入这类证据。
- **供料契约证据**：隔离服为普通玩家提供材料或场景，玩家通过真实原生接口完成操作并核验世界/库存。它可以证明接口的有限范围，不能证明自主成长。
- **源码/协议回归**：证明代码和锁定 API 的约束，不替代真实游玩。
- **画面证据**：证明对应资产、状态或有限渲染范围，不证明身体操作、全部模型或 Java 完整画面一致。

下文矩阵汇总各次私有研究证据及仓库文档。v12/v13 为对应历史发布记录；最新统一调用入口另见文末“原生调用 SDK”。既有场景未在本轮全部重跑，失败、未确认和管理员干预范围均保留。自然目标未验收和真正缺少调用接口分别表达。

## 当前接入阻断

1. **外部身份与并发未验收。** 当前实验服保持 `server-ip=127.0.0.1`、`online-mode=false`、`white-list=false`、`max-players=4`。网关前门根据用户名生成离线 UUID，可选名前缀过滤不是账号认证；这个入口不能直接改成公网监听。旧服公网/基岩成功不构成本服证据。
2. **模组真实碰撞未全面接入身体。** Agent 仍使用普通 Mineflayer/pathfinder 的 `Movements`，模组方块的原版投影会产生形状误判。静态遮挡盒不是 collision shape，网页显示正确不保证身体能走。屋顶/坑中导航失败及常驻未知导航暂停必须保留、分别解决。
3. **殖民地专用操作仍缺。** 完整 SNBT 分页、原生切割及精确组件供料已通过有限普通账号夹具；库存计数包含关联货架。招聘、岗位/生产配置、研究、仓库和快递仍不能据通用菜单宣称完整可调用。自然获取设备、住宅完工和长期物流是后续生活场景，未完成这些场景不撤销已验证接口。
4. **社会/生产/学习仍缺动作。** 岗位配置、复杂机器/流体、魔法学习/编书、地下城机关等无法靠通用 PICKUP 菜单自动覆盖；部分客户端界面不是 `AbstractContainerMenu`。
5. **外部 Agent 需要原生适配客户端。** 普通 Mineflayer 经过原版投影可能看到近似方块或空 `heldItem/window`。必须挂接本项目 menu/world/colony/domum/collision/maid/spell 客户端及对应通道，从本人原生 ID/完整 SNBT/实时窗口读取前置条件。不能将他人窗口、女仆 UUID 或组件作为自己操作依据。
6. **旧特色未迁移。** 旧 Paper 的完整 `/mycli`、公会任务、命格书、技能成长和试炼塔仍不能作为 NeoForge 新服已有内容；新服基岩入口与完整多端操作需另行验收。

常驻旧未知导航 `7927420b-0a39-46a5-b172-907e5c3a5598` 与 `autonomy.paused` 是既有运行事实。不得为了获得绿色 readiness 清除原始记录、把未知判成功或重投。

- 写动作保存持久意图与结果。超时、断线、死亡、进程重启和未知结果不盲目重放；同 requestId 的不同内容必须拒绝，成功回执要与实际前后状态对应。
- 各宣称可玩的功能有明确普通玩家场景与后置证据；随机产出保留原概率，背包满/产物未取/需求完成但未取货分别表达，不能凭单一 `ok` 结算。
- 身体移动场景单独验证真实碰撞/导航和恢复；死亡/重连后不持续执行旧阶段计划。长时间生活目标列入可选后续场景，不作为所有原生接口的交付前提。
- 开放入口具备实际身份认证、账号所有权、可控准入与容量/限流实测。网络和认证实现后还要实际外部连接验收；本文件不批准把离线测试门直接开放。
- 玩法、画面、基岩、多 Agent 容量和长期运营分别给出支持边界与结果；未通过的能力不能被总开关标成 complete。

## 可以分期验证的试用范围

当前适合先在隔离或受控本机入口验证“原生工具 SDK + 基础生存 + 有限模组接口”，明确告知未支持内容。有限 FD 料理、Create 磨粉、本人女仆跟随/拾取和已配置 Ars 法术，可作为供料教学场景；它们不等于从零自主社会生活，也不是公网发布就绪。

当前优先补真正缺少的功能入口、完整参数/说明与普通账号调用证据。以下自然闭环保留为后续可选场景，可分轨推进但使用隔离账号/世界，避免同时修改同一场景：

1. **殖民地社会**：完整组件资源分页 → Domum 正确制板/交料 → 住宅完工 → 招聘/岗位 → 农场/供餐 → 仓库/快递 → 铁匠装备。逐阶段记录工单、居民状态、实际库存与产物。
2. **生活生产**：自然食材/工具 → FD 切菜/烹饪/进食；自然制造 Create 动力/磨粉 → 运输/多机器生产；流体和故障恢复单独验收。
3. **魔法冒险**：自然制书/学习 glyph/编书 → 治疗与敌对目标命中；自然发现地下城 → 导航/机关/清怪 → 真实奖励取得。QA 配置书不能代替学习过程。
4. **外部接入**：独立账号与账本 → 原生客户端能力发现 → 私有隔离/CAS/去重/断线恢复 → 并发容量与身份认证 → 实际外部连接；基岩另开验收轨。
