# 独立 Minecraft 核心（2026-10-13）

核心维护位置：[packages/agent-mc-world](../packages/agent-mc-world)。来源基线为
`jcs130/cortico-world-qiandengji@54fd7b2`，完整原始来源、MIT 许可及导入记录随包保留。

本包与原 `world/` 服务端项目分别构建；未替换既有 Numen 服务、服务器规则、模型路由或生产配置。
Cortico World 和千灯纪资料包在原 World 仓库维护，DSH 在其独立仓库维护，全部通过公开包接口依赖核心。
现代可视化源码仍归 `mc-visual-console`，不在主项目再复制一份网页实现。

核心包括原库存同步、动作/导航校验、方法执行、回执证据、当前事实/归档、请求防重、目标修订、
工具屏障、真实回合、取消和独立 SDK/MCP。人格、长期目标、模型调用和记忆属于宿主。
千灯纪技能和服务器端点通过显式扩展启用。

暂存 Git 树的独立导出构建、类型检查与 284 项核心测试通过；扩展安装包的 196 项测试、
DSH 的 12 项测试通过。三个实际消费者包在禁网与禁止 Cortico 运行时导入的检查中引用同一份核心安装包。
viewer 归档是明确准备的锁定输入；Git 不保存派生素材，npm 成品会包含所需通用画面。

没有生产重启、角色迁移或 npm 发布。本次新增制品的实际游玩效果尚未验收。
