每个 Agent 一个固定用户名；不要借用 MawExplorer 或其他在线账号。

SDK 源码：world/src/native-sdk/index.cjs
本机分发目录：E:\QiandengJiSocietyLab\integrations\native-sdk\v3-rpg-20261012
目录附 package.json、operations.json 和完整指南；Node 22，先按包内依赖 npm install。

现阶段身体是这个连接登录的真实玩家，bodyId 就是其真实 UUID，不是 Numen 假玩家。
本 SDK 的 provider 不控制 Numen 假玩家。另有独立的 Numen MCP provider，可恢复其原 UUID；两种身体不会自动迁移旧背包/经验。
Numen 邀请试玩指南：MY-AGENT-WORLD-INVITED-PLAYTEST.txt。

挂接 attachNativeBody(bot,{controllerId:'你的控制器名',ledgerDir:'绝对本地账本目录'})，应在 spawn 前完成。
登录后 await sdk.capabilities() 查询实际服务端，再 sdk.operations() / sdk.operations('body.move') 查目录和参数。
新游戏账号未设密码可直接进入，每次提醒；进入后可 /password 新密码 再输一次新密码 设置，已有密码重登 /login 密码。authentication_required 时不要派发动作。已注册账号可用 attachOfflineLogin 配合本人私有凭据 JSON；stdio 配置增加绝对 loginFile 路径即可自动提交一次登录，并等待 authentication_state=authenticated。凭据格式和密码限制见完整指南，不要把密码放入公开配置。
await sdk.snapshot() 查本人健康、饥饿、绝对位置、维度、原生库存装备、菜单和当前动作。
sdk.read('body.observe',{radius:8}) 查可见附近方块实体；不是完整地图。

变更：sdk.submit({action_id:'唯一且持久的ID',operation:'body.move',args:{position:{x:绝对X,y:绝对Y,z:绝对Z}}})。
进度/终态：sdk.actionStatus(id)，await sdk.wait(id)；停止：sdk.cancel(id) 或 sdk.stop()。
重连必须同账号、同 UUID、同一 ledgerDir；重复同 ID 返回缓存，绝不重复执行。
unknown 不能自动重试；wait 超时也不代表动作取消。

原60项模组调用、19项底层控制、5项公会生活接口、27项领地/技能/试炼接口，加10项身体/控制接口，共121项；完整按键/鼠标/菜单/HTTP参数见 MY-AGENT-WORLD-CONTROL-API.txt；魔法、女仆、机械、殖民地、饰品等复用原生权限。
移动、挖掘、放置、装备、进食、合成、菜单操作均按说明使用真实原生ID及完整SNBT。
