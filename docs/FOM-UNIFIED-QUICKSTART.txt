命运齿轮 FOM 2.42 · 千灯纪内容扩展 20261016.1
Minecraft Java 1.21.1 / NeoForge 21.1.248 / Java 21

安装
将 .mrpack 导入支持此格式的启动器，创建新独立实例，按启动器提示下载游戏、加载器和模组。
普通玩家选“玩家版”（127 个启用 JAR）；需要真实客户端控制的 Agent 选“Agent版”（130 个）。
两个版本游戏内容相同，都保留作者禁用的 10 个文件；不要把两个包叠加导入旧实例。
这是完整安装清单，不需要先装原版 FOM 再补六个 JAR；首次导入仍需联网下载清单中的原文件。
建议给客户端 6 GiB 内存；光影按机器性能在游戏设置中选择。
本组合曾出现 Lithium 碰撞方法被 C2 编译时崩溃；本次实际连接沿用单方法规避。
请在启动器“额外 JVM 参数”加入以下一整行（仅排除该方法编译）：
-XX:CompileCommand=exclude,net.caffeinemc.mods.lithium.common.shapes.VoxelShapeMatchesAnywhere::cuboidMatchesAnywhere

连接
公网 micro.kangqiang.site:28976；家庭局域网 192.168.3.163:28976。
线上 FOM 已安装对应内容；无需为导入客户端包再次重启服务器。
正版账号使用启动器正常登录。离线新账号进服后按私有提示设置 /password；已设密账号用 /login。
Paper 千灯纪是另一台独立服，不能拿这个包当作 Paper 的更新包。

内容
保留机械动力、航空学、Sable 物理、铁路、火炮、物流、仓储和原作者画面/界面配置。
新增农夫乐事 1.3.4、车万女仆 1.5.3、Iron 法术 3.16.3 及已配套依赖。
playerAnimator 2.0.4 是作者标为 beta 的兼容版；本组合经过实际连接和部分原生玩法验证。
先看游戏里的配方书、模组手册和实际菜单；更多内容在游戏中学习。
服务器基础入口：/fom help、/fom status、/fom inventory、/fom nearby。

Agent 版
额外安装 MAW Client Bridge 0.5.0、Minescript 4.0、Baritone 1.11.3；这些只装客户端。
控制 SDK 继续使用已发布的 java-client-bridge/v9-native-crafting-release-20261015。
模组启动后在本实例生成新的本机 RPC 配置；只在本机使用，不能把 connection.json、密钥和动作账本互传。
Minescript 需要本机可用的 Python。运行一次 Python 版本命令确认，勿使用 Windows Store 占位解释器；再按模组配置指定本机路径。
本包不预填其他电脑的 Python 路径，不带角色账号、已启动任务或自主模型循环。
等待登录成功、出生和区块加载后再行动；一次只操作一个容器，核对本人库存、容器和光标。
断线或结果未知时先查询对账，不能自动重复投递消耗性操作。
