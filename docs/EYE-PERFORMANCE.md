# 天神之眼编号与渲染性能修复

2026-09-08 Agent视觉后续调研：现代第一视角默认垂直FOV110°，取自Goddess观察者。用户要求轻量服务端方案，桐人拟以Numen信息为主，按需局部图像和共享渲染补充；完整客户端不作为运行前提。角色相机和图像MCP当前尚未接入，路线比较与验收见 [视觉链路设计](SURVIVOR-VISION-DESIGN.md)。

本轮针对“画面慢、页面卡、现代版空白、降级贴图不对”的反馈。2026-09-07 实际管理页测得第一人称、环绕、俯视首个非空区块几何分别为 3,123 / 2,864 / 2,735ms，三视角均完成 25 列网格，稳定后队列为零；环绕拖动可见正确门、楼梯、屋顶与灯笼。详细验收见 `reports/eye-performance-smoke.json`，只代表本机当前区域。

2026-09-08 第一人称画面移除手臂与手持物叠层：渲染器原来沿用玩家画面的 `showHand: true`，现在由 `tools/patch_modern_viewer_runtime.py` 在网页观察相机的初始化配置关闭。场景实体、其他角色及其装备继续渲染，游戏客户端的第一人称行为不变。当前行为验收见本机 `reports/eye-observer-smoke.json`；原性能数据保留原始日期。仅刷新网页静态资源即可生效，不需要重启 world 或 Minecraft。

## 已复现的原因

- 新模组扩展 `note_block` 乐器状态，当前原版方块共有 26,834 个状态，比原版网页数据多 150 个。之后 958 种原版方块范围偏移；不能因 namespace 是 minecraft 就直接把当前数值当作原版 stateId。
- 旧传输桥还把现代渲染器收到的模组方块替换成原版近似块，丢掉了现有模组资源需要的身份。
- 只读 6 秒样本收到 1,634 条 entity、1,336 条 entityMoved 和 60 次完整 avatarState。首块 19ms、25 个不重复区块共约 3.02MB，初始服务器区块传输不是十几秒出画的主要耗时。
- 客户端自适应分辨率覆盖了原有像素比上限；44/55fps 自适应阈值又高于 30fps 上限。网格消息处理预算 30ms，且等待下一帧前没有占用处理标记，可能形成多个并发处理循环。
- 视角切换会重新初始化渲染器。原入口对约 11.4MB bundle 使用 no-store；外层页面每次世界刷新还会重建全部隐藏栏目，并将天眼状态排在容器查询之后。

## 修复边界

原版状态按当前注册表的名称与完整属性映射回网页 canonical 状态，模组身份供现代资源继续消费。新增乐器等原版网页没有的属性组合需要明确回退，不能推算统一偏移量。映射文件必须匹配当前服务端注册表身份。

渲染器保持有界视距、单网格 worker、30fps 和像素比上限；网格主线程每批让出时间，首次收到非空几何后才显示画面已连接。`?diagnostic` 才显示资源、图集、首几何耗时和队列统计，普通页保持简洁。三视角各自的镜头钩子在启动时安装，本轮不伪装成可以无成本热切换。

静态资源使用受原有路径/来源校验保护的缓存：服务端内存最多 32MiB、16项，按文件身份重新验证，支持 gzip、ETag/304 和 HEAD；动态状态不缓存。管理页仅更新当前栏目，天眼和容器查询并行，资源摘要五分钟刷新一次，手动刷新会要求重新查询。

部署后同样 6 秒只读采样中，entity + entityMoved 从 2,970 条降至 869 条（约 71%），完整 avatarState 从 60 次降至 7 次。场景实体活动会影响数量，该采样不是所有负载的性能保证。主脚本传输由约 11.4MB 降至 2.68MB gzip；命中 ETag 的重复请求为 304、零响应体。没有把旧的约十几秒观察当作精确首帧基线。

当前 bundle 固定使用 Three.js/WebGL2；旧错误页的 `/legacy/` 链接原先是 404，没有可通过查询参数开启的独立降级引擎。该入口现在给出明确说明和返回现代画面的链接，不把原版近似方块当成完整模组兼容。

`reports/web-scene-palette-samples.json` 保存观察位置附近的存档样本，`reports/eye-scene-live-blocks.json` 用不带 run 的固定 `execute if block` 对五处原木、楼梯和告示牌进行实时只读核验。截图必须与这些真实名字/属性相符，不能只凭网页“已连接”判断贴图正确。

维护只涉及网页与 world 服务。存档、技能进度、宿主 QwenPaw 和 Minecraft 服务保持原有归属；没有启动额外旧版渲染服务。
