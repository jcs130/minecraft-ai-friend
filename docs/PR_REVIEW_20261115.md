the exact reviewed commit passes CI and is merged. Install matching dependencies;
do not reuse the old Mineflayer dependency directory. Record package SHA256,
source commit, new process and postflight separately. Preserve configuration,
model choices, bodies, hosting/auth databases and request receipts. If readiness

code and dependency tree from the verified F backup; never restore old player
or request data. No game-server restart is required for this core-only release.
