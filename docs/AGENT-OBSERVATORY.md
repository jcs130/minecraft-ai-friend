# Agent 决策回路与直播观察舱

2026-09-21：观察舱采用“3D 世界现场 + 紧凑具身架构”的首屏。下方决策链路已合并为一张大图，System 1、System 2、L2、L3 始终同屏，取消 Jev / LLM / RSI 切换。没有新建 Agent、推理服务或记忆库；仅使用 panel 只读投影。

## 统一决策大图

- `unified-decision.js` 合并四个区域为一个 SVG，使用命名空间隔离节点与边。跨系统升级、行动反馈进入 L2、反思形成 L3 提案、验证后重入在线回路都明确画为机制虚线；不能用共同画布或动画证明它们属于同一次真实执行。
- 默认每 5 秒跟随最新策略选择和最新 LLM 轮次。两个区域分别显示自身记录时间；仅匹配当前 activeLlmTurnId、当前路由和新鲜快照的 LLM 节点标识正在运行。最新轮次尚无动作时显示等待回执，不借用旧工具结果。
- 历史定位只替换所选记录所属的区域，另外三个区域仍然可见；记录过期时在原区域显示缺失，不自动替换。点“跟随最新”恢复自动更新。
- 可拖动空白平移、使用缩放按钮或 Ctrl / Command + 滚轮缩放；聚焦画布后方向键平移、加减键缩放、0 适应全图。刷新和历史定位保留视口，提供“展开大图”专注模式。OBS 侧栏也保留完整图，不再切成单个系统。
- 历史回放依次阅读两个执行区域的已记录路径，不跨区域动画连成因果链；L2 / L3 不进入真实执行回放。当前运行节点脉冲服从暂停和减少动态效果。

本轮生产代码 65 项测试通过，观察舱 HTTP 探针 21 项通过，`probe_panel_smoke.agent_observatory=true`；其他已有全局健康失败独立保留。仅重启 panel，沿用 running / unless-stopped 守护，无模型或游戏控制调用。

## 具身架构与 RSI 研究

`?layer=online|l2|l3` 选择首屏架构，下方始终是一张全图，旧 `view` 参数不再切换系统。默认开启原 19092 第三视角，`?camera=off` 关闭。**该画面属于 JarvisMirror 世界观察者，不是桐人身体镜头**；本次没有移动观察者或新增跟随控制。人物当前目标与身体指标来自桐人快照，不能用于推定镜头中的人物身份。

| 展示层 | 节点与回路 | 证据边界 |
| --- | --- | --- |
| L0 / L1 在线 | 视觉/空间、听觉/交流、本体感知 → 感知整合 → System 1（Jev、已测脚本）或 System 2（LLM、规划调度）→ 控制 → 世界反馈 → 下一轮 | 单轮 DAG，跨轮反馈成环。视觉目前是结构化实体/方块观察；听觉类比文本事件，不宣称像素或音频已进入模型。快慢是职责，不是固定响应时间。 |
| L2 经验进化 | 经历 → 反思 → Dream / 知识 → 技能 → 行为验证 → 复用或修订 | 复盘从原 L1 展示归入 L2；原数据 API 兼容保留。Dream 节点标明回执待接入。索引、启用和行为验证分开。 |
| L3 框架进化 | 提案 → 代码/工作流/节点/模型/工具/MCP 候选 → 编译与固定测试 → 独立对照 → 收益门控 → 发布或退回 | 只有真正改善、关键回归可接受且部署验收后才完成进化。现 API 缺完整收益链，保持未知，不统计成功代数。 |

以上 L0–L3 是本项目按用户需求定义的展示分类，不是论文统一标准；也不会因画出某个节点就宣称自动进化能力已实现。首屏所有边与流光均为机制说明；历史图才区分已记录的实线和未关联的虚线。机制动画可单独关闭，暂停更新、隐藏页面和 reduced-motion 都会停止流光。

研究依据（2026-09-21 查阅一手材料）：

- [RSIAgent，2026-09-14](https://arxiv.org/abs/2609.15364)：以探索、结果验证、可复用环境记忆形成适应过程；对应 L2 的经验循环，不需要将每次记忆更新等同参数训练。
- [Dream-RSI 技术报告](https://www.dream-rsi.com/assets/dream-rsi.pdf)：把已探索的历史树作为有限搜索空间内的重放模拟器，评估和改进探索策略后再部署。它与普通 Dream 记忆整理不同；离线历史上的择优也不保证所有未见环境的收益。
- [Darwin Gödel Machine，2025 首发 / 2026-03-12 修订](https://arxiv.org/abs/2505.22954)：修改自身代码、使用基准经验验证、保留候选档案。对应 L3 候选版本与评测分离的设计。

`embodied-architecture.js` 是独立的纯数据架构模型与 SVG 渲染器；不新增后端读取、外部遥测、模型调用或控制 API。架构节点可鼠标/键盘选取，已有证据按需展开；手机保留世界现场，宽图只在局部滚动。

## 使用入口

- 统一决策画布：`http://127.0.0.1:19091/observatory`，快慢系统与两层进化同屏；当前 Jev 与旧 Decider 历史分别标明来源。
- 带既有世界第三视角：`http://127.0.0.1:19091/observatory?camera=third`。视角来自原 19092 世界查看器，不新增游戏控制通道。
- OBS 侧栏：`http://127.0.0.1:19091/observatory?layout=sidebar`，添加 480×1080 浏览器源，配合游戏捕获；保留完整拓扑、缩放平移、回放与节点证据，不开启世界 WebGL 预览。
- 完整执行轨迹：`http://127.0.0.1:19091/#trace`。支持轮次选择、工具/目标搜索、状态筛选、参数展开、动作前后观察和时间线。

桌面推荐 1920×1080。手机页面自然滚动，横向长图在画布内平移；节点可点击或通过键盘选择，详细参数与回执在证据区展开。侧栏保留核心决策图，不用卡片列表替代链路。全屏是浏览器全屏；没有代用户开播。

## 图形与动画口径

- **策略分支**：观察 → Jev / 历史 Decider → 候选 → 置信度检查 → 派发或回退。已选分支突出显示，未选候选淡化。候选概率和决策置信度分别显示；低置信度回退停在“交回慢系统”，不会动画进入未派发的候选动作。
- **LLM 回路**：按本轮保存的执行顺序展示输入、模型任务、工具、回执与摘要。输入快照未保留时明确未知；模型任务结束不等于游戏目标达成。节点动作耗时来自回执，与动画速度无关。
- **RSI 机制**：大图右侧 L2 与 L3 展示经验和工程演化。节点中可查看已有索引、工单及回执，全部连线为机制，不加入已记录执行的回放序列。工单结案、测试通过或技能启用不计作能力提升。

实线代表保留记录或已记录的执行顺序；虚线代表机制关系及未关联环节。所有回到观察节点的循环线均为虚线，不能据此认定某次循环已发生。Jev 回退没有后续具体 LLM 轮次的绑定，不能用时间接近补出因果关系。重复工具调用也不自动归类为模型循环。

记录动画沿已保存节点播放一遍，到末尾停止；RSI 另用标明为示意的机制演示。可以暂停、单步或切换 0.5× / 1× / 2×。动画用于阅读路径，节奏不代表实际执行时长。系统启用“减少动态效果”时关闭流光和脉冲，仍保留箭头、状态与文本。顶部“暂停更新”冻结页面快照并停止播放，在途读取不会覆盖暂停的快照；恢复后重新读取。这些操作不暂停游戏角色、不提交模型任务、不重放工具调用。

## 数据口径

| 层 | 现有来源 | 展示内容与限制 |
| --- | --- | --- |
| L1 | survivor.json、controller.json、episodes.jsonl、turn-actions、action-receipts、memory.json | 最近保留 20 轮，每轮最多 40 个游戏动作；精确 turnId/actionId 关联，输入身体快照仅在 active 中留存时显示。动作耗时为受理到终态观察，不是纯工具 CPU 时间。轮次时间含等待、推理、执行。 |
| L2 | 桐人 learning/index、drafts、memory 目录，world-skills/index、evolution-board | 知识文件索引、草稿目录、本地启用/停用技能、共享来源与版本、反馈反例；没有新增知识库。文件数/启用数不等于实际能力或游戏效果。 |
| L3 | 原 team.sqlite3、engineering/config、receipts、state | 只读查询 category=improvement 最近 24 条，工程基线/固定测试计划、测试与候选提交回执；不把候选提交当部署，也不证明递归改进收益。 |

Agent 决策摘要来自其主动保存的目标、观察、复盘和下一步计划。没有伪造完整内部思维链。原始 Prompt、逐 Token 思考、所有原生模型工具、单次模型推理耗时及调用计费并未完整记录。Jev 最近选择是独立历史记录，不能仅凭时间接近归入所选轮次。

当前身体目标、历史决策和节点证据分别标记，选择历史记录不把它当作角色此刻正在执行的动作。画布最多展示 6 个候选和最近 6 条动作；候选超出上限时保留已选候选，并注明采样范围。完整执行轨迹仍可查看接口保留的更多数据。机制图展示架构关系，不声称所有边都有逐轮调用证据。世界变化只比较同身体、同维度且两端有效的观察，未知不显示为零。

HTTP 轮询每 5 秒；轨迹后端缓存 5 秒，RSI 缓存 15 秒。已有知识计数/行为统计继续按原生成频率工作，页面单列采样时间。文件读取与列表均有界，目录只用于固定索引；页面不返回密钥、私有原生消息或知识全文。Host/Origin/CSP/只读路由保护保持，未新增公网监听。

## 决策分支与来源

观察舱同图展示 Jev 分支和 LLM 回路。LLM 轮次及其游戏回执标明 LLM；Jev 使用 provider 与 model 身份，旧 Decider 单独标为历史。当前身体状态与分区历史分别显示。

读取 episodes 尾部至多 4 MiB、最近 100 条策略事件，展示最近 12 次选择及最多 16 个候选。候选概率、选择、置信度、服务延迟、控制器接收耗时和回退原因分别展示。低置信选择不记作执行。派发关联要求技能、版本、实践、状态摘要、观察时间、模型及选择精确且唯一匹配，再按 turnId/actionId 读取动作回执；未唯一匹配保留未知。后续 LLM 轮次没有绑定证据时不按时间猜测关联。

现有日志未保存 LLM 未选方案或内部逐步推理；当前页面展示已记录决策与工具路径。输入过期的 `system_one_discarded` 事件尚未投影到前端，不把重新观察回环画成已验证事件。策略完整状态和非白名单工具参数不公开。
