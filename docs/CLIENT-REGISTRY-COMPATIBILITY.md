# 客户端缺少法杖注册表

2026-09-13，另一台局域网电脑连接时提示服务器发送未知的 `qiandeng_chanting:whispering_staff` 与 `qiandeng_chanting:resonance_staff`。这表示已经进入模组注册表同步，客户端没有这两个物品定义；端口可达不等于完整登录成功。常见原因是启动了旧整合包、装错实例目录，或没有完整重启客户端。

两项分别是旅人言灵杖和千灯共鸣杖，属于双端模组 `qiandeng-chanting-0.1.0.jar`。当前 D 项目客户端、服务端及构建锁的实际 SHA256 均为 `b867d1ffe7252ad412bb3ddc9b955eb35f94cabe75aa70ea2ee58233cd03f9e5`。当前服务器注册行为正确，没有为绕过报错删除物品、改动世界或关闭同步校验。

## 已发现的分发差异

| 旧包 | 实际内容 |
|---|---|
| 0.1.0～0.1.3 | 未包含法杖模组 |
| 0.1.4 | 法杖与现服一致，但神谕语音组件已旧，缺少当前人物桥接组件 |

因此不能只根据同为 Minecraft 1.21.1 或 JAR 文件版本名判断兼容。自研 JAR 历史上复用了 0.1.0 版本名，实际应按分发包版本与 SHA 校验。本机 `launch_client.py` 使用 D 项目的 `client` 游戏目录，C 盘 Rapid Optimization 仅提供原游戏和库缓存，不会自动更新另一台电脑的旧实例。

## 本次交付

- `dist/QiandengJi-1.21.1-0.1.5-local.mrpack`：推荐的完整更新，88 个模组、164 个覆盖文件，含当前法杖、神谕语音、人物桥接与两个人物模型。导入启动器的新实例，使用原玩家昵称连接 `192.168.3.133`。完整包 SHA256 为 `7d80d0bff7885153ffd11ac424f9369e5547c0646a12f854c4a8b66e4e5937a0`。
- `dist/QiandengJi-chanting-fix-1.21.1-20260913.zip`：针对本次错误的小补丁，仅含已校验的法杖 JAR 及其强制依赖 Simple Voice Chat `1.21.1-2.6.22`。适用于已有千灯纪客户端，不能替代从原底包安装完整整合包。

安装补丁前完整退出 Minecraft。在启动器里打开实际报错实例的目录，把旧法杖/voicechat JAR 备份到 `mods` 之外，再将补丁的两个 JAR 放入该实例 `mods`。同一模组不能并存多个版本。重新启动后再连接，不需要重启服务器。完整 `.mrpack` 使用启动器的整合包导入功能，不能放进 `mods` 文件夹。

完整包由 `tools/export_pack.py --version 0.1.5-local` 导出，所有 JAR、模型、ZIP CRC、覆盖文件哈希和导出白名单校验通过；小补丁由 `tools/export_chanting_hotfix.py` 对照当前客户端锁和服务端实物生成。没有账号、存档或启动器凭据。另一台电脑的实际安装和重连仍需用户执行，不将打包校验写成客户端已修复进服。

这些安装文件保存在开发机 `dist`，不随 Git 提交；Git 保存构建工具与本说明。尚未启用自动客户端更新，今后更改双端模组后应导出新的整合包并同步给玩家。
