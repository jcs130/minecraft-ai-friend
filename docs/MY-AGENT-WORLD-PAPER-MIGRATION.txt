/mycli profession 选战士、法师或牧师。
/mycli skills menu|list|mine|points，info 技能ID 查看说明，learn/upgrade 技能ID 学习升级。
/mycli tome 领取绑定命格书；/mycli focus give 领取法杖；focus bind 技能ID 绑定，手持交互瞬发。两件道具不可丢弃。

领地：/mycli land menu 可登记营地；claim ID minX minY minZ maxX maxY maxZ 登记绝对边界；trust/untrust ID UUID 授权；list 查看。每人3块、单块最大32×48×32且体积32768、角点在64格内。不覆盖他人、试炼和无权限的殖民地。

/mycli arena status 区分本人参赛和全服进度；resume 断线或死亡后归队；leave 退出。
/mycli arena stash 打开个人真实54格双向存取箱；stash page 2 到第2页，共10页。奖励不在死亡地点。满箱进入待领取队列；队列也满时保留本层，清理或回收后自动继续，不要重复开塔。
/mycli arena recycle list；quote bag|chest 槽位 数量；sell quoteId 回收未装备重复装备为灯币。报价30秒并核对完整组件。
/mycli arena shop list|buy 商品ID|wallet。满包购入个人箱或待领取。相同难度楼层每24000服务器tick限领奖一次。
