## 本次修复

1. Numen 复用已有 Mineflayer 服务端原生处理器，提供同身体私有调用；不使用另一套虚拟库存或 OP 指令。
2. 农夫乐事切菜配方产物查询检查全部可能结果，鸡肉配方的次产物骨粉可被 `outputId=minecraft:bone_meal` 找到，查询不会触发随机掉落。
3. 切菜板射线恰好停在薄模型表面时可能误报不可见。沿同一射线延长 0.0001 格修复，仍要求首个命中为同一个已加载、可达方块，不能穿墙操作。
4. 建筑切割机新增 Numen 原生造型选择，带完整窗口、材料、造型、位置和游标 CAS；服务端注入本人 UUID，调用者不能指定其它玩家。
5. 通用菜单 `slotLayout` 新增 `owner` 和 `inventoryIndex`。所有权来自真实 Slot 容器，区分 `player_inventory` 与 `container`；Agent 不必猜某个模组的背包起始槽。

## Numen 原生模组 API

认证 MCP 仍为 `http://192.168.3.163:28984/numen/mcp`，不新增公网端口，不要求主人客户端常驻。身份与接入见 [Numen 服务端指南](MY-AGENT-WORLD-NUMEN-SERVER.md)。新增三个工具，总 MCP 工具数为 17：

- `mod_operations`：不传参数列目录，传 `operation` 获取完整参数 Schema。
- `mod_query`：传本人 `companion`、操作 ID 与 `arguments`，只允许只读操作。
- `mod_action`：另需本人 `lease_id` 和唯一 `action_id`，只允许变更；`accepted` 后查询同一个 ID 的 `action_status`。

```json
{"name":"mod_operations","arguments":{"operation":"colony.stockResource"}}
{"name":"mod_query","arguments":{"companion":"身体UUID","operation":"menu.snapshot","arguments":{}}}
{"name":"mod_query","arguments":{"companion":"身体UUID","operation":"native.recipes","arguments":{"recipeType":"farmersdelight:cutting","outputId":"minecraft:bone_meal","limit":12}}}
{"name":"mod_query","arguments":{"companion":"身体UUID","operation":"colony.management","arguments":{"buildingPosition":{"x":603,"y":64,"z":600}}}}
```

坐标全部为绝对坐标；示例建筑位置来自隔离夹具，必须换成本人世界实际位置。`aimOffset` 仅为目标方块内部的 0–1 瞄准偏移。

不要沿用本地 SDK 自动补参数的假设。`menu.pickup` 需要最新窗口/stateId、槽位 ID/数量/完整 SNBT 与游标 SNBT；`menu.close` 要求游标为空。`domum.select` 从 `domum.state` 原样带回窗口、状态、位置、当前组、造型、全部输入、游标与输出组件前置值。初次 `currentGroup=null` 合法。切割机查询共用原生 10 tick 限流，通常间隔至少 0.6 秒；`rate_limited` 应等待后重读，不能当作没有菜单。

变更需要本身体 `bypass` 模式，但不授予 OP，也不跳过殖民地成员、`MANAGE_HUTS`、研究与材料规则。`ask/observe` 明确拒绝这些变更。Lua 和原生模组操作共用单控制器互锁。

动作先持久记录，再由服务器线程执行。相同 ID/意图返回原结果，换参数拒绝；重启后不再次开菜单或消耗物品。无法确认结果时为 `unknown`，阻断后续写入。私有回执只返回所属账号，不进公屏。

34 项范围：殖民地 15、配方/视线/碰撞/交互 4、Create 4、Curios 3、YSM 2、Domum 3、菜单 3。移动、挖掘、放置、进食、合成仍使用官方 Numen Lua 的真实能力；不能把 SDK 本地计划当服务端同步调用。Ars 专用编书等尚未接入新目录。

## 正常建城顺序与验收边界

用真实物品建镇、放建筑工小屋，**先给建筑工小屋本身下建造工单**，安排居民并满足材料请求。新放下的 0 级建筑工小屋不能直接建普通住宅；原生拒绝时返回 `native_build_request_not_accepted`，不能改等级或直接造完来绕过。

之后继续住宅、农场、仓库等，分别核对工单、居民工作、库存和实际建筑完成。岗位、大学研究及带完整材质组件的供料有此前隔离记录；完整自主采集 → 供料 → 住宅完工 → 长期经营仍未通过验收。

本轮实际流程使用提供材料/设备的普通生存身体，不是自主采集。磨石供能使用明确记录的创造马达夹具，不能当作风车自主生产证明；生产存档不执行这些夹具。

当前网页小屋审计 28 类可解析、20 类拒绝：17 个原生模型加载器未支持、2 个素材缺失、1 个随机变体种子未验证。不能用原版近似模型掩盖。基岩已有 732 静态图标、279 女仆/YSM 模型变体和两套模型包；不代表自定义世界方块、专用界面或手机显示全部可用。

常驻网页当前绑定 MawExplorer。新增 Numen MCP 不会自动把另一具身体接到这个网页；Numen 的视角/界面绑定仍需单独接入，不能把原网页健康当成这项验收。
