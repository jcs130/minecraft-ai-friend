# 开源与独立部署检查（2026-10-23）

## 结果

仓库公开、根目录 MIT，自研 Paper 玩法、Eye、登录桥、网站和构建源码可获取。当前维护源在 `qiandengji-personal-stash`，网站现役 0.8.4 在公开固定提交 `9f03e4f1`；默认 `main` 仍是旧 NeoForge。**目前不能称为全套现役世界的一键、逐字可复现发行版。**

部署入口与准确限制见 [SELF_HOSTING.md](SELF_HOSTING.md)。本次完成：

- 从 GitHub 匿名浅克隆维护分支，未使用维护者 GitHub 私人 token。
- 在独立新目录从上游下载并校验 9 个固定依赖，Paperclip 仅准备编译输入；构建不读取家服 JAR、配置、数据库或世界。
- 编译 AgentFriend 0.4.48 候选（136 个源文件含共享类）和 CortiEyeMirror 0.1.17（5 个源文件含共享类）。两次构建的产物摘要一致；这是本次 Windows/JDK21 的结果，不代表跨编译器逐字相同。
- 新世界在独立回环端口启动，普通 Mineflayer 实际出生、加载库存、收到 `/mycli status --json` 和帮助；无连接错误，随后正常保存停止。当前家服未连接、未重启、未替换。
- EssentialsX 沙盒依赖由首次验证不支持该核心的 2.22.0 调整为公开 2.21.2；新沙盒不再报 unsupported server version。它是独立沙盒锁，不擅自变更家服。
- 正式网站从公开提交导出，在全新依赖安装后通过 196 项 API/DOM 测试；自部署与安全边界 9 项 Python 测试通过。
- 新增 Linux CI：无维护者私有 secrets 的源码路径检查、密钥扫描、JDK21 构建和固定官网测试。远程 CI 的实际运行结果另看 GitHub Actions，不把本机 Windows 结果冒称 Linux 已验。

## 凭据检查

对本次预发布源码树及官网固定源码分别使用经官方 checksum 校验的 Gitleaks 8.30.1，扫描嵌套 ZIP 两层；修订后当前树均为 0 项未处置命中。原扫描的文件校验摘要和确定性 HMAC 夹具经逐项核对，只添加精确例外；测试目录没有整体放行。

旧直播固定写入令牌已改为私有环境变量；语音测试中疑似实际 Key 已换为合成 UUID。本次未调用它们验证有效性，未修改现役凭据。历史已公开的值仍需原服务所有者按需撤销/轮换；本次不改写 Git 历史，不能把当前树通过当成历史无泄露。详见 [SECURITY.md](../SECURITY.md)。

源码包不包含维护者的模型/邮箱/阿里云凭据、网站账号库、游戏认证库、Floodgate 私钥、现役背包、世界或诊断转储。所有运维原始报告留在本机私有目录，仓库只保存上述不含凭据的结论。
