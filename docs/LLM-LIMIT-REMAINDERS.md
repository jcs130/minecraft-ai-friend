# 旧世界模型入口的后续治理

2026-09-08 当前自主链路已取消人工模型次数额度：桐人控制器、独立人物、队伍消息和运营原生任务使用无次数上限配置；Qwen 本地 QPM 与迭代限制关闭。串行、真实任务超时、未知提交不重投仍保留。不能据此宣称所有历史世界入口的节流都已撤除。

以下旧入口仍待统一，未在本轮扩大修改：

- `world/src/mc-god.ts` 的问答间隔 15 秒、公聊间隔 10 秒（VIP 5 秒）与祈愿入场间隔 30 秒，都会在模型调用前退回。后续应把输入接收与按会话串行分开，避免直接丢掉新问题。
- `world/sidecar/mc_npc.py` 仍有默认 75 秒的模型闲聊冷却，且当前 `NPC_LLM_ENABLED=0`、默认 `chat_mode=quests`。启用村民生成式对话时需要一起治理；世界日常合同链路不依赖这个闲聊开关。
- `world/src/mc-evolve-review.ts` 保留单提案五次失败后悬置的旧流程，未知同步请求可能在下次扫描再次提交。不能把上限简单改成无限重试；应迁移到持久原生任务回执，未知只查询或人工核对，不重复发送。

不属于模型次数额度的边界继续保留：每日实际技能入库数量、合同数量与奖励规则，实体动作步骤、施法法力和冷却，工具数据大小，以及公共技能市场的 HTTP 获取限制。学习复盘只在证据变化时执行；`reserve_review` 不再按累计任务数限额，但仍遵守运营任务串行和未知任务占用。
