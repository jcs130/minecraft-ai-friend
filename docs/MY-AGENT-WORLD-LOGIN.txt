My Agent World 登录方式（NeoForge 1.21.1 新服）

正版 Java：使用正版账号启动对应的 NeoForge 模组包，连接 192.168.3.163:28976。官方会话验证通过后直接进入，无需注册和密码。

离线 Java / Mineflayer Agent：未设密码时直接进入，每次登录会提醒。进入后可用 /password 新密码 再输一次新密码 设置；至少 8 个字符。设过密码的账号重登用 /login 密码。已有密码不会被取消。不要把密码当普通聊天发出。

正版基岩版：192.168.3.163，端口 28988。通过 Xbox 验证后自动进入，无需密码；原背包和角色保持。若该名字以前设置过离线密码，首次绑定先输入一次原密码，以后免密。改 Xbox 名字需服主核对迁移。

Mineflayer：host=192.168.3.163，port=28977，version=1.21.1，auth=offline。新账号可直接使用 SDK，进入后设置自己的密码；已有密码先登录。authentication_required 表示尚未完成认证，应停止游戏动作。每个 Agent 使用自己的账号和密码。

Numen：仍连接 http://192.168.3.163:28984/numen/mcp，使用本人 Agent Bearer 令牌。服务端的 Numen 身体继续按原 UUID、主人和租约管理，不需要主人游戏客户端在线或另设身体密码。

Numen 网页观战：http://192.168.3.163:28984/numen/view/ 。输入本人 Agent 接入令牌，选择自己的身体；支持第一人称、第三人称和已适配的原生模组菜单。网页只读，不争夺控制权。

同名正版和离线账号拥有不同 UUID、背包和权限，不能当成同一个角色。当前仍是局域网测试服，旧千灯纪的公网地址不是本服入口。

菜单：使用冒险指南针可随时打开指南，再选“我的 Agent 同伴”→“配置模型 / API Key”；也可 /mawagent menu。魂符点实心方块上表面召唤女仆，对空气使用打开女仆面板。女仆指南、魔法笔记可用交互键打开原书中文文字目录，并从中进入模型配置。车万女仆的全服 LLM Key 仍由服主管理，自己的 Agent Key 可以自己配置。

已验证离线密码流程、绑定保护及真实基岩 UDP 道具/菜单/召唤。实际手机 Xbox 免密和真实正版 Java 会话仍需客户端验收；书中配方图和 3D 页面没有完整转换。
