My Agent World 登录方式（NeoForge 1.21.1 新服）

正版 Java：使用正版账号启动对应的 NeoForge 模组包，连接 192.168.3.163:28976。官方会话验证通过后直接进入，无需注册和密码。

离线 Java：连接同一地址。首次输入 /register 密码 再输一次密码，以后输入 /login 密码。密码至少 8 个字符。不要把密码当普通聊天发出。

基岩版：192.168.3.163，端口 28988。目前也使用 /register 和 /login；基岩桥没有被当作正版 Java 自动认证。手柄专用登录表单还没有实现。

Mineflayer：host=192.168.3.163，port=28977，version=1.21.1，auth=offline。先注册/登录再使用 SDK；authentication_required 表示尚未登录，应停止游戏动作。每个 Agent 使用自己的账号和密码，不共用别人的身份。

Numen：仍连接 http://192.168.3.163:28984/numen/mcp，使用本人 Agent Bearer 令牌。服务端的 Numen 身体继续按原 UUID、主人和租约管理，不需要主人游戏客户端在线或另设身体密码。

Numen 网页观战：http://192.168.3.163:28984/numen/view/ 。输入本人 Agent 接入令牌，选择自己的身体；支持第一人称、第三人称和已适配的原生模组菜单。网页只读，不争夺控制权。

同名正版和离线账号拥有不同 UUID、背包和权限，不能当成同一个角色。当前仍是局域网测试服，旧千灯纪的公网地址不是本服入口。

已验证离线注册/重登、错误密码拒绝、伪造正版会话拒绝及 Agent 接口隔离；真实正版免密和基岩手机操作还需实际客户端验收。
