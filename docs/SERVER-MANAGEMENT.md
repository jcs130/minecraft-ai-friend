# 世界管理入口

19091 是本机日常首页：总览 → 天神之眼 → 服务器管理 → 众生/村务/世界 → 运营组。

总览把常用入口与当前容器状态放在前面。运营组仅展示千灯纪 D 项目的角色与运行环境，内置 default/QA 辅助配置不列入角色和统计；未来新增的项目角色会自动显示，禁用状态如实保留。宿主团队和旧游戏配置保留在 CLI 审计清单，页面不提供跨环境筛选。依赖档案限当前项目所需服务，和终端命令一起默认折叠。启用配置不等于正在执行任务，历史健康结果始终显示记录时间。

## 三个边界

| 服务 | 职责 | 入口 |
| --- | --- | --- |
| panel | 公开读模型、管理登录、固定 API 代理 | 127.0.0.1:19091 |
| control | 固定 D 项目服务的维护、保存确认、脱敏日志与操作回执 | 仅 Compose 内部 3090 |
| world | 现有玩法、只移动 Goddess 的观察控制、区块画面 | 内部观察 API 3080；网页画面 127.0.0.1:19092 |

panel 不持有 Docker socket；control 只识别项目登记的固定服务，执行前重新核对 Compose 标签和不可变容器 ID。控制令牌仅在私有文件与容器内部使用。浏览器获得的是一小时管理会话和 CSRF 令牌。

## 登录与维护

首次执行 `python tools/prepare_management.py` 会幂等准备私有凭据；不会覆盖已有密码。管理密码位于 `server/admin-state/secrets/admin-password.txt`。该目录不进入源码或分发包。页面点击“解锁管理”使用该密码；不用解锁即可浏览世界。

启动、停止和重启都先生成一分钟有效的计划。重启世界会纳入正在运行的依赖消费者；维护 Minecraft 会先停消费者，再取得保存完成应答，才停止 Minecraft。启动按依赖顺序等待就绪。一次只允许一个维护任务，计划不能重复执行。

失败回执保留步骤、实际观察到的服务状态和恢复提示；不会把部分执行显示成成功。执行器异常退出后的未完成任务不自动重放；遗留维护锁需要查清原任务后再处理。执行器自身不能在网页停止，维护它使用项目 CLI。重启 panel 会中断当前页面会话，恢复后重新解锁查看回执。

日志只读最近 120 行，带凭据脱敏；操作回执在 `server/admin-state/operations/`。普通游戏数据与旧环境数据不因停止而删除。

## 天神之眼

支持第一人称、环绕观察、俯视场景和周边地图。管理页仅在查看天眼时建立渲染连接；离开页面或进入后台会断开。跟随移动 Goddess，保留开始位置，使用 120 秒租约和有上限的续期；停止或正常关闭时归位。浏览器强杀依赖租约到期；world 被强杀时不能承诺内存中的原观察位置仍可恢复。

当前资源由实际客户端/服务端 JAR 和当前方块注册表生成。添加或更新内容模组后，应重新导出注册表并运行资源构建工具，再验证真实三维场景；参见 [模组渲染兼容](WEB-RENDER-COMPATIBILITY.md)。资源摘要直接显示兼容范围，不能把缺失渲染当作游戏实体不存在。

周边地图只覆盖观察者已加载区块，缓存按维度隔离；忙时返回重试响应，不保留悬挂请求。远程玩家背包和 YSM 网页动画尚未接入。

方块编号偏移和渲染性能修复见 [天神之眼性能](EYE-PERFORMANCE.md)。当前实测三视角首块约 2.7–3.1 秒；只有收到非空区块几何才显示画面已连接。

## 旧环境退役

本轮用户明确要求停止旧游戏环境，宿主 QwenPaw 保留。旧游戏容器设置 restart=no 并正常停止；旧脚本、角色 MCP 和专用宿主进程按已核实归属精确退役。有些管理员拥有的任务无法修改任务定义，已停止其运行实例并让专用入口提前退出。任务定义“启用”不能再当作游戏仍运行的依据。

宿主 QwenPaw、其通用模型和非游戏任务保留。TTS 权重、配音和 API 已复制并校验到 D，8100 由 D 的 tts 容器提供，不再依赖旧游戏 TTS。原始数据与逐文件回退备份保留，详见 `reports/legacy-game-retirement.json`、`reports/tts-ownership-transfer.json` 和 [TTS 归属](TTS-OWNERSHIP.md)。

## 验证与运维

常驻服务统一由 Compose restart 策略守护；现有单次 Windows 任务每两分钟采集公开清单。健康检查 `python world/ops/health/health_mon.py` 验证当前 11 服务、管理会话边界、观察者、画面协议和注册表身份，并要求实际浏览器与操作回执冒烟报告。健康 HTTP 不替代真实 WebGL 画面验收。

本轮真实管理接口 12 项通过（实际重启一次 NPC，Minecraft 重启仅预览）；跟随 6 项、TTS 接管 10 项通过。源码回归包含 87 项 Node 与 202 项 Python 检查。最终报告为 `reports/management-platform.json`；原始技能状态与本轮开始时逐字节一致，临时验收角色已退出并清理。
