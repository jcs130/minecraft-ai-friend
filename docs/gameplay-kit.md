## 一、矿脉神谕表（女神答复「哪里有 X」的 Y 层依据）

来源：`docs/reference/minecraft-wiki/references/ores.md`（1.18+ 权威分布），与 orefinder-estimate（坐标簇）互补。

| 矿 | 最佳 Y 层 | 分布 | 需要工具 | 神谕要点 |
|---|---|---|---|---|
| 煤炭 | Y=96 | 三角 0→256 | 木镐 | 地表也常见 |
| 铁 | Y=15 或 Y=232 | 双峰 | 石镐 | 山脉地表富铁，早期 Y=15 |
| 铜 | Y=48 | 三角 0→96 | 石镐 | 1.17+ |
| 金 | Y=−16 | 三角 −64→32 | 铁镐 | 废矿/遗迹另有金块 |
| 青金石 | Y=0 | 三角 −64→64 | 石镐 | 峰值 0 |
| 红石 | Y=−58 | 三角 −64→16 | 铁镐 | 深埋最丰 |
| **钻石** | **Y=−58** | 三角 −64→16 | 铁镐 | 分支采矿 3 格间隔，带水桶防岩浆 |
| 绿宝石 | Y=236 | 仅山地 | 铁镐 | 只在山地生物群系 |
| 远古残骸 | Y=8（最佳）→15 | 下界 | 钻石镐 | 防爆，TNT/末影水晶爆破，4 碎片=1 下界合金锭 |

神谕措辞范式（留余地，显神性）：
- 钻石：「地脉传闻，深至 Y=−58 岩层，旧矿工于斯掘得星火；带一桶水，防那岩浆怒龙。」
- 铁：「地底 Y=15 与山巅 Y=232 皆有矿脉——欲速成，上山；欲稳妥，入地。」
- 远古残骸：「下界 Y=8 之层，烈火不熔其坚，以爆破掘之。」

## 二、地下城怪物配置（副本难度设计参考）

来源：`references/mobs.md`。关键生成规则：
- 敌对生物刷怪：**光照 ≤0**（1.18+）——副本内要"足够黑"才刷怪；
- 玩家 24 格内不刷怪，128 格外实体消失（命名/拴绳例外）；
- 每维有生物上限，刷怪笼不受上限影响。

三层副本怪物主题建议：
| 副本 | 主打怪 | 机制要点（据 mobs.md） |
|---|---|---|
| 哨塔试炼 | 骷髅/蜘蛛 | 骷髅远程保持距离，蜘蛛白天不主动——塔内刷怪笼可制 2 段式 |
| 蠕行墓穴 | 僵尸群 + 女巫 | 僵尸 Hard 会召唤援军；女巫丢药水/喝药——副本内放刷怪笼+药水女巫 |
| 孤城深渊 | 卫道士/劫掠兽 + 凋灵骷髅 | 精英战；可加 1 只命名 Boss（命名怪不消失）作「守灯人」 |

Boss 设计参考（Warden 思路）：不靠掉落诱杀，靠**机制**——命名 Boss「守灯人·柯莱」（不消失、高血、无掉落，击败后灯亮）。

## 三、成长技术树（世界进化路线）

来源：SKILL.md 技术树 + 既有技艺体系。穿越者成长主线：

```
木遁·草庐(Lv1) → 民居(Lv2) → 商铺/书阁(Lv3) → 大宅(Lv3)
土遁·水井(Lv1) → 农舍(Lv1) → 酒馆(Lv3) → 望楼(Lv4) → 神殿(Lv4) → 城寨(Lv5)
矿脉感知（神谕）→ 采集升级 → 装备升级 → 副本探险（哨塔→墓穴→孤城）
```

进化循环（每轮 saga 构思可产出）：
1. **新技艺**：任意 /place template 结构可成技艺（结构库 2955+，技艺无限）；
2. **新副本**：D&T 结构按梯度开放，配信物/奖励；
3. **新活动**：quest/trial/festival 三模式轮换；
4. **新知识**：矿脉表/怪物表/附魔表持续补充神谕依据。

## 四、组合玩法（建筑 × 矿脉 × 副本 × 技艺）

| 玩法组合 | 说明 |
|---|---|
| 建村 → 集市 | 木遁起屋排布街区（商铺/农舍/书阁），土遁·水井供水，形成聚落 |
| 找矿 → 武装 | 神谕矿脉 → 挖矿 → 附魔（wiki 附魔表）→ 打副本 |
| 副本 → 献灯 | 探险取信物 → 神托献祭 → 奖励修为/魔力上限 |
| 营地 → 远征 | 副本入口前木遁·草庐作补给点，土遁·望楼瞭望 |
| 矿区 → 据地 | 矿脉深处土遁·城寨圈地，据险而守 |
