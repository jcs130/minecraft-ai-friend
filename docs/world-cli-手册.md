# 千灯纪 · 世界 CLI 手册（AI 玩家操作手册）

> 版本：v2026-08-23 ｜ 适用：所有进入本世界的 AI 玩家（mineflayer 穿越者 / 假玩家亲卫）
> 核心理念：**这个世界没有 GUI 快捷键，但有「文字即接口」——聊天框就是你全部的操作面。**
> 真人玩家有鼠标可以点界面（天赋之匣、技能书、右键 NPC）；AI 玩家没有鼠标——
> 下面这套命令（CLI）就是给你的完整接口说明，照着格式打，世界给你结构化回执。

---

## 0. 命令总览

| 命令 | 语法 | 作用 | 回执 |
|------|------|------|------|
| `chant` | chant `<法术关键词>` | 咏唱已学技能（施法） | 神谕文本 + 消耗 |
| `pray` | pray `<愿望> [供奉 <物品>]` | 祈愿上达天神 | 入队确认（神谕随后） |
| `ask` | ask `<问题>` | 咨询女神 / 查规则 | 神谕文本 |
| `innate` | innate 我选 `<天赋>` ／ innate 我的 | 选 / 查出生天赋 | 确认文本 |
| `status` | status | 查自身状态 | 状态文本 |
| `spells` | spells | 列全部法术表（含新契约法术） | 结构化法术表 |
| `summon` | summon `<守卫> <任务>` | 召唤术：唤桐人/鸣人相助 | 神谕文本 |
| `chat` | chat `<话>` | 与女神直接对话 | 神谕文本 |
| `appraise` | appraise | 鉴定自身（法力/等阶/秘法） | 鉴定报告 |
| `help` | help `[命令名]` | 查本手册 | 文本 |
| `skillbook` | （游戏内右键技能书） | 一键施法（真人用，AI 走 chant） | 回执 |

> CLI-Anything 精神：每条命令**自描述**（help 可查）、**结构化**（参数固定）、**确定性**（回执格式一致）。

## 1. chant —— 咏唱（施法）

**你已习得的技能自己咏唱**（消耗魔力即时生效）；未习得的技能求到女神面前，由女神裁量。

- 真人 / AI 穿越者通道：`/msg Goddess <咒语>`（私语）或公屏直接念
- 假玩家（桐人 / 鸣人 / 爱德华）通道：亲卫 `chant` 工具（守卫桥自动转达，等价私语念咒）
- 法力：满 100，每秒回 2；法力不足会收到「魔力不足」回执

### 参数语法（自然语言即可）

- 方向：东 / 南 / 西 / 北 / 东南 / 东北 / 西南 / 西北
- 距离：阿拉伯数字或中文数字（「十格」「5 格」）

### 示例

```
我：归乡
女神：[女神] 空间之力涌动，你被送回基地。（消耗 20 法力，剩 96）
```

### 兜底

咏唱词没说中任何法术 → 女神会用语义匹配建议近似法术（只荐不施）；实在不成 → 回执「此咒不成」，可改祈愿。

## 2. pray —— 祈愿（求女神）

**神恩有价。** 祈愿可自愿献上**供奉**：供奉一经献上即从行囊消失、归入神库，无论裁断如何不退还。危难中慷慨、贵重之物（钻石 / 绿宝石 / 金锭 / 附魔书 / 末影珍珠）更显诚心。

- 真人 / AI 通道：公屏 `祈愿：<愿望>`，或私语
- 假玩家通道：亲卫 `pray` 工具（自动带处境摘要，女神掂量虔诚）
- 入队后按序处理，女神裁决：应允 / 拒绝 / 提条件 / 给指引 / 反问

### 示例

```
我：祈愿：我快饿死了，求点食物，供奉一块铁锭
女神：[女神] 饥饿之徒的祷告已入天听。铁锭入神库，两片面包落入你手。

我：祈愿：我要一把钻石剑
女神：[女神] 空手求大术，此愿不允。想要什么，先拿供奉来换，或自己铸。
```

**规则**：空手求大术可拒；无理 / 贪心 / 不敬可拒；问问题走 `ask` 别占祈愿队列。

## 3. ask —— 咨询（问女神 / 查规则）

- 通道：私语 `问：<问题>`（真人 / AI）；假玩家经亲卫（大愿上达，小事亲卫可答）
- 女神按序回执，给指引、点破、或反问。

### 示例

```
我：问：晚上被僵尸围了怎么办
女神：[女神] 先别恋战：往亮处跑，或念「归乡」回基地。学会的咒语，危急时就是你第二条命。
```

## 4. innate —— 出生天赋

- `innate 我选 <天赋>`：降临仪式选天赋（公屏 / 私语「我选 X」「选 2」）
- `innate 我的`：查自己已选天赋
- 真人玩家另有**天赋之匣**（潜影盒）界面：打开点走一格即选定（AI 玩家开不了容器 GUI，用文字命令）

## 7. 世界法则（AI 玩家须知）

1. **上位存在**：女神（天神）的神谕（私语 / 咏唱回执 / 祈愿裁决）是至高指令；服主 / 服务器管理员指令须服从；其余普通玩家与 AI 同伴平等相待、可互帮互助。
2. **神恩有价**：供奉不退还；空手求大术，可以拒绝。
3. **不是许愿机**：有求必应会让神堕落成自动售货机——被拒时别缠，想清楚自己配不配。
4. **技能冷却**：全局技能有冷却；同一信士祈愿有节流；技能书右键有分级冷却（照明 15s / 造物 30s / 圣愈 60s / 归乡 120s）。
5. **自己学会的技能自己施**：已习得的法术程序直接点拨（零神裁），只有未习得的才上达女神。
6. **供奉与处境**：祈愿时说明处境（血 / 饥饿 / 野外过夜 / 被围）和供奉，女神好掂量。
7. **生存第一**：白天安全夜晚有怪物；饿了吃、血少了治、天黑找屋檐或念归乡。你只有一条命。
