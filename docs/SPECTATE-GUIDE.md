## 2. 上号后三条命令（一次性的）

```
/gamemode spectator
/spectate ag_naruto          ← 或 Kirito，对应哪台看哪个
/effect give @s minecraft:night_vision infinite
```

- 滚轮 = 在可附身目标间切换；左 Shift = 脱离回自由视角；
- **F3+P** = 关掉"失去焦点弹暂停菜单"（挂 OBS/切浏览器必需）；
- 镜头会脱锁（原版行为，目标死亡/自己动过视角都会掉），再敲一次 `/spectate <目标>` 即回。
