## A. 真名隐匿（别名咏唱）— 防偷学机制

### 背景
公屏咏唱会暴露法术关键词，旁观者（其他穿越者/真人玩家）看到「撕裂虚空，传送十格」
就能学会咒语。IP 人物也不该用通用名——鸣人该喊「飞雷神」，不是「传送」。

### 机制
1. **档案加 `aliases`**：每个穿越者档案（transmigrators.json）加
   `aliases: Record<atomId, 自创名>`。鸣人：`{tp: "飞雷神", heal: "医疗忍术·掌仙术"}`；
   桐人：`{tp: "转移", ...}`。别名由人格自选（LLM 在降临/学习时自创，或档案预置）。
2. **匹配层双通道**：世界侧匹配咒语时——①先查施法者的别名表（自创名 → 原子）；
   ②未命中再走通用关键词（通用词只对无别名者生效）。
3. **回执跟别名**：女神公屏回执用自创名（「飞雷神·成功」），不泄漏真名；
   面板（自视+管理员）显示「飞雷神（传送）」对照；女神全知真名（史官记录记真名）。
4. **组合技（v2）**：别名可绑多个原子按序施放（「神威」= tp + blindness），
   第一版先单原子。

### 防偷学原理
偷学 = 看到公屏咒语 → 反推关键词。别名机制下旁观者只看到「飞雷神」，
反查不到 tp 原子（匹配走别名表，通用词对他不公开）。真名只在自视面板出现。

### 实现落点
- `mc-transmigrator.ts`：档案 schema 加 aliases
- `mc-magic.ts`：匹配入口先查施法者别名；回执文案用别名
- `web-panel`：技能卡显示「别名（真名）」
- 面板 API（status JSON）：自己的 aliases 带出，别人的不带

## B. RPG 属性点系统

### 机制
1. **四维**：力量 STR / 智力 INT / 敏捷 AGI / 体质 VIT。
2. **初始分配**：降临仪式后（选完出生天赋）加一步「属性分配」：
   总 20 点自由分（每维 1~10），LLM 按人格自选（鸣人偏 AGI/INT，桐人偏 STR/AGI）。
3. **成长**：每次 XpLevel 提升 +2 点，LLM 自选分配（延续人设成长轨迹）。
4. **技能双门槛**：原子加 `req: { attr, value }`；解锁条件 = 等级 AND 属性。
   例：`meteor` 需 Lv.12 + STR 6；`tp` 需 Lv.3 + INT 5。
   全加力量 → 力量系全开但智力系（tp/heal/feed/dawn）锁死——用户拍板的分化效果。
5. **属性影响数值**：
   - INT → maxMana 系数（如 `100 + 12×(Lv-1) + INT×3 + bonus`）
   - VIT → 被动苦修阈值放宽（体质高的人更容易撑过 600s 压血）
   - STR/AGI 第一版只做门槛（vanilla 攻速/伤害不可改，不硬造）
6. **面板**：属性四条 + 技能卡标注需求（`陨石 Lv12 · 力量6`）。

### 原子归类（初稿，落 atoms.json 时逐个定 req）
- 智力系：tp / heal / feed / dawn(破晓) / clear(驱云) / appraise(鉴定) / home(归乡)
- 力量系：meteor(陨石) / 碎石 / 血怒系被动
- 体质系：坚毅 / 铁壁 / 燃血(blood_mana)
- 敏捷系：survival(求生·疾行) / 未来闪避类

### 实现落点
- `magic-atoms.json`：每原子加 `req` 字段（服务端适配：纯数据改动）
- `mc-transmigrator.ts`：档案加 `attributes` + 分配仪式
- `mc-magic.ts`：解锁校验双门槛；maxMana 公式挂 INT
- `mc-god.ts`：升级时 +2 点通知（私聊引导自选）
- `mc-loop.ts`：prompt 加属性段（「你是力量型战士，智力系法术与你无缘」）
- `web-panel`：四维条 + 技能需求标注

## C. 施法台账（已上线 2026-08-17）

- `data/skill-usage.jsonl`：每次成功施法一行（ts/player/atom/chant/三消耗/剩余魔力/等级）
- `analyze-skill-usage.mts`：按原子聚合 + 与 mc-brain.log 按 ts±45s join 还原 goal 上下文
- **分析口径：技能使用 = 服务器问题信号**。高频 tp + 脱困语义 goal → 修地形
  （/fill 坑洞）或查寻路，而不是加魔法。各原子频次 → 天平拨正数据依据。
