## 玩家与手柄入口

从冒险指南针进入“命格书·技能·领地·试炼”，或 `/mycli rpg`。`/mycli tome` 领取绑定命格书；`/mycli focus give` 领取灵纹法杖。菜单图标是按钮，个人试炼箱中的物品才是真实存储。

先选职业，再在技能详情学习、升级或绑定。通用技能可直接花 1 点学；职业技能须选对应职业并满足真实成长条件。升级需成功使用 8 / 24 次及点数。失败、没有合法目标、冷却中或魔力不足时不收取成功施法费用。法术效果和实际参数以当前 `rpg.skills` 为准，并非把 Paper 的 AuraSkills 属性原封不动复制进 Ars。

试炼菜单先“前往入口”，在入口选难度。`/mycli arena status` 明确区分本人是否参赛与全服试炼进度；`/mycli arena resume` 续关，`leave` 退出，`stash [page 2]` 开自己的箱子。掉线或死亡后的已领取奖励保留，不要去死亡地点找试炼奖励。每次只有一场试炼。

`/mycli land menu` 可登记身边营地。命令也支持：

```text
/mycli land claim my_camp minX minY minZ maxX maxY maxZ
/mycli land trust my_camp 对方UUID
/mycli land untrust my_camp 对方UUID
/mycli land list
/mycli protect break 100 64 200
```

每人最多 3 块地，单块最大 32×48×32 且体积最多 32768，角点须在本人 64 格内。不能覆盖别人的地、试炼或没有权限的殖民地。成员授权要求对方已认证在线；不会因 OP 身份自动绕过私人领地。访客可使用没有方块实体的普通门等设施，不能随意打开私有箱子或机器。

## Agent 接口

Native SDK 0.4.0 总目录 **121**，Mineflayer 服务端绑定 **111**；Numen 原生目录 **99**，统一适配器 0.3.0 的 Numen 目录 **104**，其中 `body.observe` 仍明确不可用。先查询当前 provider 的 `operations(id)`，不能猜测跨 provider 的菜单参数。

新增 27 项：

```text
rpg.state  rpg.skills  protection.query  land.list
arena.status  stash.state  arena.recycle.list  arena.recycle.quote  arena.shop.list
skill.learn  skill.upgrade  skill.cast  skill.bind  skill.imprint  profession.choose
land.claim  land.release  land.trust  land.untrust
arena.lobby  arena.start  arena.resume  arena.leave
stash.open  arena.recycle.sell  arena.shop.buy  rpg.open
```

先读本人技能、资格、魔力、剩余冷却，再发动作。示例：

```js
const own = await world.read('rpg.state', {})
const rules = await world.read('protection.query', {
  action: 'break', position: {x: 100, y: 64, z: 200}
})
// deny 停止；unknown 等待区块加载或改路线；allow_likely 仍可能被其他模组拒绝。
const action = await world.submit({action_id: 'cast-0001',
  operation: 'skill.cast', args: {skillId: 'starbolt'}})
const done = await world.wait('cast-0001')
```

上述 `world` 为统一身体适配器。Native SDK 的 `submit` 接受相同动作封装；Numen 须先按原流程取得本人的租约与行动许可。所有状态按本账号 UUID 读取，不按 CortiLan 等名字特判。不授 OP，不替换身体，不自动恢复 MawExplorer 自主循环。

探矿开始的成功回执表示已排入有界扫描，读取 `rpg.state.lastResults.prospect` 等待实际终态；不应重复施法。普通地形观察仍遵守可见性。未知动作结果先按原 `action_id` 对账，不换 ID 重试消耗。

奖励箱按普通双箱操作：`stash.open {page:1}` 后再读取当前窗口，用当前 provider 的普通/Shift 菜单接口。回收先 `arena.recycle.list`，按来源和槽位 `quote`，检查名称、完整组件、耐久、数量与价格后 `sell {quoteId}`。报价 30 秒有效，成交二次核验。已装备、手持、绑定、任务和唯一物品不在默认可卖集合。收益进 EconomyCraft 账户，购买满包进个人箱或待领取。

成交在服务端同一 tick 内完成物品核对和扣除，但两个模组持久化文件并无跨文件数据库事务。服务端崩溃时遇到未知经济动作须对账，不能声称跨崩溃绝对原子或自动重放。

## 私有状态与视觉

`mcagent:state`、`mcviewer:state`、`mcagent:event`、`mcagent:protection` 是每条玩家连接自己的 UTF-8 JSON，没有 writeUTF 长度前缀。状态与能力各最多 24 项、单包 16 KiB。魔力或冷却变化最多每秒更新，viewer 每 5 秒刷新。成功事件包含技能 ID 与绝对作用位置；失败无成功事件。

保护查询回执只走 `mcagent:protection`，没有 MC_PROTECT 聊天副本。GUI/CLI 的主动查询、错误提示、清层与奖励指引为本人私有提示，不作全服广播。声音和世界粒子属于现场表现，附近玩家可感知。

Java 和基岩使用原版容器/标题/声音/粒子，Mineflayer/Numen 使用相同服务端处理器。基岩 UDP 自动资源包下载与菜单协议验收不等于真实手机像素、每个复杂模组 GUI 或 Java 完全一致，`allGameplayVerified=false` 保持。

## 部署与维护

本轮由既有主服务守护运行，没有新增守护进程或公网端口。运行时安装记录 `server/maw-rpg-installation.json`，玩法数据原生保存在 `world-life/data/maw_rpg.dat`；目录与数据包定义均随源码提交。完整物品组件使用 NBT UTF-8 字节数组保存，兼容早期短字符串记录，避免 64 KiB 字符串限制。待领取队列最多 2048 组；满时保留已清楼层，状态返回 `anomaly=reward_storage_full` / `phase=awaiting_reward_space`，清理或回收后自动结算，不能重复启动。

`tools/maw_rpg_migration.py health` 或 health_mon 的 `--society-rpg-migration` 检查编译产物、目录、私有频道、原生维度和守护，不代替游玩验收。网关新增四个可选私有频道；已有守护保留原环境，因此冷部署同时补充其后端通道知识缓存，正式连接已实际收到状态，不能只改配置后就认为运行连接已声明新频道。

修改规则先重建桥，在独立 34 模组副本验普通玩家/Mineflayer、Numen 同身体权限、真实基岩菜单、死亡/重连和保存恢复；确认无人游玩及动作空闲后，经既有控制器正常停新服和基岩桥、冷备校验，再安装。旧 Paper 不停服、不写入。

本次候选在专用维度分批建房，每 tick 最多 512 次方块位置处理；探矿每 tick 最多 4096 次已加载方块读取，不用主线程同步遍历全世界。新服 `world-life` 不重生成，不覆盖已有主世界结构。

新分发目录使用 `v5-paper-rpg-20261012`，保留所有旧包；依赖从原锁文件 `npm ci`。原账号、身体、Numen owner、模型 Key、原动作账本及旧 unknown 保持。旧 `auto-start.paused` 或以前维护标记不作为本次部署脚本重放的理由。

回滚应先正常停本轮拥有的服务、备份更新后的玩家与 RPG 数据，按本轮备份清单恢复两个自有产物和受管配置，再启动原守护。**不能在已有玩家进入试炼维度后直接删数据包或替换整份旧世界**；先把参赛者安全送出并保留新数据，按具体故障制定回滚。旧服历史导入、公共结构迁址和运营团队接线另做有预览的迁移，不在此步骤自动执行。
