# Game Design Core（游戏设计核心）

综合方法论：用于设计、调优、审计游戏机制——特别适用于千灯纪/九灯深渊的技艺、副本、成长与供奉经济。

## 总流程

```
定义核心幻想 → 设计核心循环 → 成长与难度 → 内容/关卡设计 → 调手感 → 测试迭代
```

## Step 0 核心幻想（Core Fantasy）

动手前先答三问：

- 玩家幻想自己**是什么/在做什么**？（不是"玩家会做什么"，而是"玩家想成为谁"）
- 最该让玩家体验到的情绪是什么？（力量/机敏/紧张/惊奇/掌控）
- 十秒电梯游说——一句话说不清，就简化。

> 千灯纪落点：世界无魔王，病是荒芜；穿越者不是英雄，世界需要住民。核心幻想不是"打败魔王"，而是"点灯、养灯、让荒芜之地亮起来"——这是设计一切玩法的北极星。

## Step 1 核心循环（Core Loop）

每个游戏都有一个反复循环：**行动 → 反馈 → 奖励 → 决策**

Sid Meier 法则：游戏是一系列有趣决策的集合。每个决策必须**知情、有力、有取舍**。若存在唯一最优解（dominant strategy），这个设计就死了——重做它。

> 千灯纪循环草稿：采集/咏唱（行动）→ 点灯/建屋/除荒（反馈）→ 灯辉/供奉/新技艺（奖励）→ 下一盏灯点哪、技艺怎么配（决策）。

## Step 2 成长与难度（Progression & Difficulty）

- 默认用**锯齿难度曲线**（sawtooth）：稳定爬升 + 周期性小高峰（Boss/事件），高峰后回落再爬。
- 成长 = 玩家变强 + 世界变难的双向匹配；不能只有数字膨胀（玩家血 100→1000，怪伤 10→100，等于没成长）。
- 区分三种成长：**数值成长**（伤害/血量）、**选择成长**（新技艺/新策略）、**理解成长**（玩家变聪明）。只有第一种最廉价也最无趣。
- 难度设计看 references/skill-tree-design.md 的梯度原则与 references/rpg-numbers.md 的数值曲线。

## Step 3 内容设计（Level / Content Design）

- 用玩法教，不用文字教（teach through play）——第一关就是安全的教学场。
- 每个岔路都有回报：物品、捷径、剧情、风景——空探索是原罪。
- 反模式：换皮加数值的"伪难度"（更多 HP、同样 AI）。真难度 = 新行为、新组合、环境挑战。

## Step 4 手感（Game Feel）

- 响应性、重量感、打击感——反馈必须即时可见。
- 帧级技巧（coyote time 土狼时间、squash & stretch、hit pause）只在需要时引入；MC 语境下对应：方块放置音效/粒子、攻击冷却条、进食动画。

## Step 5 测试迭代（Playtest）

- **先找乐子**：占位美术的原型不乐，再打磨也救不回。
- **看玩家，别问玩家**：卡住的地方比嘴上说的更真实。
- **杀掉你的宝贝**：不为核心幻想服务的机制，砍。

## 好游戏的三大支柱（自我决定论）

| 支柱 | 游戏实现 |
|---|---|
| 胜任感 Competence | 清晰反馈、可见进步、够得着但需要挑战的目标 |
| 自主感 Autonomy | 多条有效策略、有意义的选择、玩家表达 |
| 归属感 Relatedness | 合作、竞争、共享故事、社区 |

- **变比率强化**最抓人：不可预测的奖励（掉落、暴击）。
- **道德线**：玩家永远有清晰退路。不做暗黑模式（dark patterns）。

## 反模式速查

| 反模式 | 改为 |
|---|---|
| 开篇文字教程轰炸 | 玩中学——安全的第一遭遇 |
| 唯一最优解 | 每个选择都有取舍 |
| 空探索 | 每条路都有回报 |
| 伪难度（加血不加AI） | 新行为/组合/环境挑战 |
| 氪金变强 | 外观付费、技术成长 |
| 功能臃肿 | 一切服务核心幻想，其余砍掉 |

## 玩家动机审计（简版）

完整九原型审计见 `game-design-granular-player-motivation-audit` 技能。设计任何系统前先问：**它在服务谁？在排斥谁？这排斥是有意的吗？**

常用对照（千灯纪语境）：
- **Steady Advancer（17%）**：要简单可见的进步——灯辉计数、等级清晰、短会话有成就感。
- **Imaginative Creator（11%）**：要建造与耕耘——木遁/土遁 11 咒正好喂养他们。
- **Immersed Storywriter（10%）**：要世界与叙事沉浸——村民故事、灯窝家书、正典剧情。
- **Passionate Belonger（7%）**：要归属与陪伴——共创、节日、共生仪式。
