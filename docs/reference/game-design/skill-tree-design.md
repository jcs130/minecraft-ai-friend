# 技能树/技艺设计（skill-tree-design）

为千灯纪技艺表与九灯深渊「点灯换恩惠」设计。

## 一、技能的本质：动词法则

> **好技能含一个动词，伟大的技能含一个独特的动词。**
> 例：回退（Revert）、耗尽（Exhaust）、连锁（Chain）、无视（Ignore）、阻止（Prevent）、转化（Convert）、倍增（Multiply）、创造（Create）、扩张（Expand）、堆叠（Stack）、改变（Change）、施放（Cast）、增益（Buff）、占有（Possess）……

- 纯数值提升（+10% 伤害）不是技能，是补丁。
- 设计新技艺时：先挑有趣动词，再围绕它构建。
- 千灯纪对照：木遁「造屋」= 创造 + 扩张；土遁「筑墙」= 阻止；圣愈 = 恢复；归乡 = 传送。已有的 11 咒里，给它们各配一个"动词身份证"。

## 二、节点类型（一个技能树至少三种）

| 类型 | 作用 | 例 |
|---|---|---|
| 叶节点（叶） | 具体新能力——玩家记忆点 | 木遁·大宅（新结构） |
| 枝节点（枝） | 增强既有能力——数值/范围 | 木遁·熟练（消耗 -20%） |
| 根节点（根） | 改变玩法规则——系统级 | 灯芯共鸣（技艺可叠加咏唱） |

- **意义与成本正相关**：定义新机制的成本（动画/系统/测试）远高于数值调整。所以技能树里"叶"要精贵，"枝"可繁茂。
- 数量法则：**填几百个纯数值节点只要 UI 功夫；一个新定义能力要整套系统**。宁可 20 个有意义的技能，不要 200 个补丁。

## 三、技能树的目标

技能树存在的意义（三选一，都要）：
1. **让玩家构建独特角色**——自我表达（RPG 起源）。
2. **每次升级都改变一个决策**——不是数字滚动。
3. **制造取舍**——点了 A 就暂时不能点 B；可洗点但付出代价（供奉/灯油）。

## 四、梯度与解锁（千灯纪/九灯深渊落点）

- **三层技能体系**（天定法则）：
  1. 已习得 → 咏唱瞬发（零神谕成本）；
  2. 未习得 → 求神代施（慢路径裁决）；
  3. 造物 → 白名单克制发放。
- 神恩分层 = 天然技能树：**点灯（基础）→ 点技艺（选择）→ 点灯换恩惠（九灯深渊：每层一点灯，解锁一恩惠）**。
- 恩惠设计建议：每层给"三选一"而非单点——自动创造取舍；低层恩惠偏枝（消耗/范围），高层恩惠偏叶（新动词），顶层给根（改规则）。

## 五、玩家适配（结合 motivation-audit）

- **Steady Advancer**：技能树要"可见的下一步"——解锁路径清晰，短会话有进展。
- **Curious Solver**：要有可发现性——隐藏节点、条件解锁（"连点 7 盏灯后解锁"）。
- **Competitive Achiever**：要有可比性——技艺等级/深渊层数/点灯数排行榜。
- **Imaginative Creator**：建造系技能（木遁/土遁）就是为他们——多给建造自由度。
- **Passionate Belonger**：共生恩惠（帮村民点灯得回礼）喂养归属感。

## 六、技能树设计清单

- [ ] 叶/枝/根三类节点都有？

- [ ] 升级改变决策，而非只滚数字？
- [ ] 有取舍（资源有限，点 A 难点 B）？
- [ ] 低层枝、高层叶、顶层根？
- [ ] 九种玩家原型里至少服务 3 种？
