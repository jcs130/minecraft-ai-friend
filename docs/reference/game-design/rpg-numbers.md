# RPG 数值设计（rpg-numbers）

千灯纪/九灯深渊数值体系的图纸。原则优先，公式示例次之。

## 一、硬数值 vs 百分比成长

- **硬数值成长**（level 1 打 500，level 2 打 750，level 3 打 1000）：直观但**全周期必然失衡**——后期要么小数值无感、要么大数值崩坏，且极难回调。
- **百分比/倍率成长**（技能造成 `225% 攻击力` 伤害）：与角色属性挂钩，长期平衡性强，改一处全链路联动。
- **结论**：核心成长一律走倍率（`基础值 × 属性倍率`），硬数值只用于短期小增幅（附魔/临时药水）。

## 二、技能平衡三要素

每个技艺/技能由三者定价：

1. **威力**（伤害/效果强度）
2. **消耗**（魔力/饱食/血祭/供奉）
3. **实用度**（泛用性、冷却、条件）

> 三者互偿：高威力必须高消耗或低实用。解锁制游戏里**后解锁的技能必须整体更好**（玩家花了时间与选择成本）——但更好 ≠ 同维度碾压，可以是"换一种玩法"。

## 三、成长曲线

- **指数成长 → 百分比感观**：等级-数值映射用 `value = base × growth^level` 或分段线性；不要纯线性（线性让后期无感）。
- **难度曲线**：锯齿形（sawtooth）——主线稳定爬升，周期性事件高峰（Boss/神恩日/深渊层主），高峰后回落再爬。
- **边际收益递减**：同一属性堆叠应有上限或递减（`实际收益 = 名义 × (1 - 衰减×已堆量)`），防止单一数值流。
- **时间价值**：玩家第 N 小时获得的提升应仍可见——每次升级至少改变一个"决策"，不只是数字。

## 四、DPS / 战斗平衡公式基线

```
每秒输出 DPS = 单次伤害 × (1 / 攻击间隔) × 命中率 × 暴击期望
暴击期望 = 1 + 暴击率 × (暴击倍率 - 1)
```

平衡步骤：
1. 定基准 DPS（玩家预期通关副本的耗时）。
2. 所有技艺/武器按 DPS 拉齐（±10%），再用消耗/冷却/范围拉开手感差异。
3. BOSS 血量 = 基准 DPS × 期望战斗秒数 × 容错系数（1.2~1.5）。
4. 玩家受伤 = BOSS 单次伤害 × 攻击频率；让"可承受失误次数"= 3~5 次（视难度）。

## 五、经济与供奉（千灯纪特化）

- **供奉 = 风险投资**：供品是消耗品（献出即消失），神明回赠恩惠。设计上：**期望回赠价值 > 供品价值**（否则没人供奉），但**不保证具体回赠**（变比率强化，最抓人）。
- **货币分层**：口粮级（面包/火把——小心愿）、贵重级（钻石/绿宝石/附魔书——大恩典）、传说级（末影珍珠/下界之星——神迹）。供奉稀缺度与神恩强度挂钩。
- **防通胀**：神恩产出循环消耗（灯油/修复/技艺升级都要花资源），否则世界富到无趣。
- **掉落经济**：掉落率按"玩家净收益曲线"设计——前期资源稀缺驱动探索，后期资源过剩驱动建造，过度即转为装饰/升级消耗。

## 六、BOSS / 副本数值（深渊回响）

- **三层梯度**（浅层·哨塔试炼 / 中层·墓穴回声 / 深层·孤城深渊）：每层 DPS 门槛提升 ~1.8~2.2 倍，但**机制复杂度提升优先于数值提升**（Warden 思路：靠机制不靠掉落）。
- **敌对刷怪规则**（MC 硬约束）：光照 ≤0、距玩家 24 格内不刷、128 格外消失；**命名怪不消失**——守关 BOSS 必须命名（`/summon ... {CustomName:"..."}`）。
- **Boss 设计三问**：玩家要学习什么？（机制）玩家失败为什么？（信息不足还是数值不够——前者是设计失败）玩家胜利靠什么？（决策而非堆血）。

## 七、数值测试清单

- [ ] 每项技艺的 DPS 与基准线差 ≤10%？
- [ ] 所有成长都是倍率而非裸加？
- [ ] 同一属性堆叠有边际递减？
- [ ] 供奉的期望回报 > 供品价值？
- [ ] 后期仍有"决策"级成长（非纯数字）？
- [ ] 副本每层 BOSS 机制 > 数值压力？
