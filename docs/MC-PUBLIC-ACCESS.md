## 二、客户端怎么连（可直接发给访客 ✓）

### A · 基岩版（手机 / 平板 / Switch / Win10&11 版）

- **服务器地址**：`191.223.220.150`
- **端口**：`19140`
- 不需要正版/Microsoft 账号 ✓ 离线登录 ✓
- 客户端版本保持较新即可（桥是 Geyser 2.11.2 ✓ 会做版本翻译 ✓）

**基岩版能玩到什么** ✓：地形/建筑/昼夜/玩家与生物/智能村民/交易/红石/探索 ✓
**看不到** ✗：模组方块与物品贴图（可能黑紫格 ✓）、技能树界面、语音、书页点选施法/神谕 UI ✓
（**基岩装不了服务器模组** ✗ 提示"要装 NeoForge"是 Java 侧话术经桥透传 ✓ 忽略即可 ✓）

### B · PC Java 版

**方式 1 · 原版客户端（最简单 ✓ 功能受限）** ✓

- 能进 ✓ 但模组的方块/物品会以原版形态显示（贴图与自定义行为看不到 ✗）

**方式 2 · NeoForge 客户端（完整体验 ✓）** ✓

## 三、开放前后必须做的收口 ✓（30 秒 ✓ 我随时能办 ✓）

服务端是**离线模式** ✓ 名字**可以被冒用** ✗ 所以：

1. 访客先给**独占名字**（例：`guest_aoqi` ✓ 别用可能撞车的名 ✓）
2. 我把名字加进白名单：`whitelist add <名字>` ✓
3. 全部备齐后一句"开"：`whitelist on` ✓（RCON 即时生效 ✓ 不用重启 ✓）
4. 撤客：`whitelist remove <名字>` ✓

## 四、转完后自证连通（30 秒 ✓）

1. **手机关 WiFi 用 4G** ✓（关键：不能用家里 WiFi 测 ✓ 局域网走不到公网 IP ✓）
2. 基岩版 → 添加服务器 → `191.223.220.150 : 19140` ✓
3. 连上 = 转发成功 ✓ 连不上按顺序查：① WAN IP 是否等于 191.223.220.150 ② 规则是不是 **UDP**（不是 TCP ✓）③ 内部 IP 是否 192.168.3.133 ④ 桥是否还在跑（我一条命令可验 ✓）

想稳定一点就换 **DDNS 域名**（路由器自带或阿里云/DNSPod ✓）→ 访客填域名 + 端口即可 ✓ 公网 IP 变了不用重发 ✓
