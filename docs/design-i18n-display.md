# 设计：多语言部署 — 显示名本地化（i18n Display Names）— 2026-08-19 拍板

> 状态：**已拍板，待实现**。触发：管家汇报混用「桐人/Kirito」「佐助/Sasuke」被用户点名，
> 拍板「中文译名统一 + 作为多语言部署的特性」。

## 背景

- **username 是协议层技术标识**（Kirito / Naruto / Sasuke / Asuna），游戏协议、
  白名单、usercache、世界数据都以它为唯一身份键——不可改（改名=换身份）。
- **世界语言是中文**：NPC 显示名（甲匠·石磊）、编年史、女神公告、公会看板全中文，
  但 bot 在编年史/面板/台账里却裸露英文 username，叙述层割裂。
- 世界定位是可对外部署的开源项目（B 仓 Public），不该硬编码绑死中文——
  显示名应为**按部署语言可配置**的本地化层。

## 机制

1. **身份与显示分离**：`username` = 唯一身份键（协议层，永不本地化）；
   `displayName` = 展示层本地化名（编年史/面板/公会/女神公告/回执全走它）。
2. **档案为一等来源**：穿越者档案（A 仓 transmigrators）加
   `displayNames: { zh: "桐人", en: "Kirito" }`；未配置者回落 username。
3. **世界侧映射表兜底**（B 仓先行，不等 A 仓）：`data/display-names.json`
   `{ "Kirito": {"zh":"桐人"}, "Naruto": {"zh":"鸣人"}, "Sasuke": {"zh":"佐助"},
   "Asuna": {"zh":"亚丝娜"}, ... }`——外部接入的 bot（如 225 侧 Asuna/Sasuke）
   没有本地档案，映射表是唯一来源。档案与映射表并存时**档案优先**。
4. **部署语言配置**：世界配置加 `locale: "zh"`（默认），决定渲染取哪一档
   displayNames；换语言部署只改配置+映射表，不动代码。
5. **史官保真**：编年史底层事件记录（world.db）存 username 原文，
   渲染层（chronicle.md / 面板 / 公告）才做本地化——数据可回放，展示可翻译。

## 实现落点

- **B 仓（世界侧，归我）**：
  - `data/display-names.json` 映射表 + 读取工具（status 渲染处统一过一道）
  - 编年史（world-chronicle.md 话语/陨落行）、观察面板（:9090 玩家卡/tab）、
    公会台账（quest-ledger 的 player 字段渲染）、女神公告/回执
- **A 仓（穿越者侧，归小 P）**：
  - `mc-transmigrator.ts` 档案 schema 加 `displayNames`
  - bot 自我介绍/对话中可引用本地名（人格层已有中文名的档案天然满足）
- **管家汇报规范（133 侧即刻生效，不等实现）**：对用户汇报一律中文译名
  （桐人/鸣人/佐助/亚丝娜/女神），引用协议原文时标注 username。
