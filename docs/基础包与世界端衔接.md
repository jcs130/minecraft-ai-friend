# 基础包与世界端衔接

## 文档理解

桌面文档合并了项目概览和部署运维手册，两部分的版本背景不同：前半部分说明纯原版玩法架构并提到实测 1.21.11；后半部分记录当前世界为 **MC 1.21.1 + NeoForge 21.1.248**。用户指定的基础包、世界端本地 `ops/docker/modpack.json` 与后者一致，后续整合按此版本推进。

世界端承担女神、聊天施法、祈祷、成长、供奉、NPC 委托、编年史和观察面板；穿越者由独立 Agent 进程接入。概览中“世界独占 RCON、穿越者只走聊天”描述的是外部 Mineflayer 穿越者路线。进一步检查发现，现役系统还包含受信任的 Numen 守卫路线：MCP 桥通过 RCON 驱动假玩家，并通过共享文件向世界端提交咏唱与祈祷；两种接入方式需分别保留。

当前 NeoForge 世界还包含车万女仆及好感度、自言自语、女仆法术，铁魔法及其依赖，技能树、建筑结构、载具、收纳和视听模组。客户端基础包主要提供优化与渲染能力，后续需要与世界端内容逐项对齐。

单纯制作客户端整合包不会同时获得世界端的 AI 服务、账本、NPC 常驻进程和观察面板；这些依赖现有世界端运行环境。

## 基础包核对结果

- `modrinth.index.json` 和启动 JSON 均确认 Minecraft 1.21.1、NeoForge 21.1.248；启动 JSON 要求 Java 21。
- 实际 `mods` 下 24 个 JAR，另有 1 个资源包。
- 上游索引登记 22 个 JAR 和 1 个资源包，23 项的 SHA1、SHA512 全部匹配。
- 额外加入的模组是 RuOK `1.7.4` 与 Accelerated Rendering `1.0.14-1.21.1-alpha`；不能只凭原索引重建用户当前的基础包。
- 锁定文件记录全部 25 个模组/资源包文件的文件名、大小、SHA256，以及是否属于上游索引。
- GPUTape 文件名写作 `1.0.3`，内部版本声明为 `1.0.2`；后续识别需结合内部元数据与哈希。

## 后续整合约束

1. 优先核对女仆本体、teallib、女仆扩展、女仆法术、铁魔法、irons_lib、GeckoLib、玩家动画库和 Curios 的实际依赖，再纳入其余内容模组。
2. 按 mod ID 去重。基础包的 Lithium、ModernFix、Cloth Config 已与世界端存在重叠，中文文件名前缀不会使其成为不同模组。
3. 世界端专用管理、协议代理和权限配置不应整目录复制进客户端。`botgate` 是必须保留的服务器组件；现役版本除了六个网络兼容 Mixin，还包含技能书、技能箱/轮盘、飞行、武器技能和光环等共 15 个 Mixin。不能因旧 `settlementsfix` 退役而丢弃这些已迁入 `botgate` 的能力。
4. 不恢复文档已退役的 settlements 系、settlementsfix、roadweaver 或错误的 Forge 版女仆好感度。
5. 客户端素材可从现有实例和世界端取得；女仆 AI 端点凭据、RCON 密码等敏感配置不进入整合包。
6. 复制开发实例时排除 `.hmcl/`、`PCL/`、`config/sodium-fingerprint.json`；`options.txt` 需要作为默认设置单独审阅。存档、截图、日志、服务器列表和缓存不作为发布素材。

## 尚需实际验证

以下结论来自本地 JAR 元数据，不代表游戏启动或联机测试已通过。

- Iris `1.8.14-beta.1+mc1.21.1` 和 More Culling `1.0.9` 的 Minecraft 依赖范围写为 `[1.21,1.21.1)`，与目标 1.21.1 存在声明疑点；当前 `config/fml.toml` 为 `dependencyOverrides = {}`。两份 JAR 均匹配原始索引哈希，需要用实际启动日志核实。
- 基础包含 C2ME、ScalableLux、Accelerated Rendering 的 alpha 版本，以及 Sodium、Iris 的 beta 版本；加入女仆、动画、远景和世界生成内容后需要启动、进服和画面验证。
- Sodium/Iris 元数据禁止同时加载 Embeddium；zfastnoise 禁止 Moonrise、AntiXray；C2ME 不建议同时加载 Dynview、BetterChunkLoading。基础包当前未安装这些冲突对象。
- 两份 Better Combat 的重复问题，以及目录额外的 Patchouli/YSM，需要在后续内容清单中作出明确选择。

当前验证范围：静态文档、清单、JAR 元数据和文件哈希。尚未验证游戏主菜单、现有世界联机、女仆显示/施法、光影或实际性能。
