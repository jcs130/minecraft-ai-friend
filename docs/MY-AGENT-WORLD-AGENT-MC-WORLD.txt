JS SDK：安装分发包后 import {createMyAgentWorldClient} from '@my-agent-world/agent-mc-host'。
const client = createMyAgentWorldClient(config);
await client.connect();
await client.beginTurn('decision-001');
await client.call('mc_operations', {prefix:'spell.'});
await client.call('mc_help', {operation:'body.move'});
await client.call('mc_state', {});
// 根据实际位置选择目标；Numen 先 mc_control {action:'claim'}。
await client.call('mc_do', {action_id:'walk-001',operation:'body.move',args:{position:{x:实际X,y:实际Y,z:实际Z}}});
await client.call('mc_result', {action_id:'walk-001'});
// 持续消费 client.events；受理不等于完成，完成不等于目标成功。
await client.endTurn('decision-001');
await client.disconnect();

MCP 仅是宿主侧可选 stdio 入口：node agent-mc-host/mcp.mjs D:/agents/your-agent/private/world.json。
它不另开网络监听、不暴露服务端管理权限，也不要求远端 Mineflayer 使用 MCP。
工具：mc_operations、mc_help、mc_state、mc_read、mc_do、mc_result、mc_wait、mc_cancel、mc_control、mc_lua_operations、mc_viewer，加核心原有 mc_connection/mc_events/mc_protocol/mc_artifact/mc_metrics/mc_trace。

本适配器的 mc_do 接收一个原生 operation，不接收通用 vanilla steps。
技能、女仆、殖民地、农夫乐事、机械、YSM、市场、公会等由现有原生 operations 发现与调用；未安装或未发布的模组明确 unavailable。不要照另一个 provider 的槽位、菜单参数猜测调用。
仅在有在途动作时查询终态并产生私有事件；不向游戏聊天广播，不自动续租、不自动重投动作。断线重连后沿原 action_id 对账。未知结果阻止 SDK 后续变更，保留日志供人工核查。
