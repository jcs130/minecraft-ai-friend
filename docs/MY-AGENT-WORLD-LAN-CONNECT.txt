My Agent World 局域网连接方法（2026-10-12）

设备连接家里的同一局域网，网段为 192.168.3.x。

基岩版（手机、平板、Windows 国际版）：添加服务器，名称 My Agent World，地址 192.168.3.163，端口 28988（UDP）。
独立基岩桥及家庭网段防火墙放行已完成；实际基岩 UDP 测试客户端已下载资源并进世界，手机画面待确认。
基岩端使用模组内容的兼容映射，专用模组界面和完整玩法仍需实测。
已部署 739 种原生物品映射、67 种法术书/武器/工具手持模型、53 个灶台/砧板/齿轮/风车等方块状态，以及原女仆 241 个、YSM 38 个模型变体。入服选择“下载并加入”；新版五包完整下载校验通过，手机实际显示待验收。认证后欢迎菜单可点“冒险指南”，五张图文卡片支持手柄和触屏；以后 /mawagent guide 重新打开。风车和灶台显示读取真实机器/食物状态。女仆按原实体绑定；YSM 当前 6 个变体可绑定本人玩家皮肤，其余供女仆实体使用。任意复杂结构、Java 完整动画/装备层、魂符动画和全部专用界面仍需适配。Java 模组 JAR 不能直接安装到基岩版。

Java 玩家：多人游戏 → 添加服务器，地址 192.168.3.163:28976。
客户端需要 Minecraft 1.21.1 + NeoForge 21.1.248 + 对应锁定模组包，纯原版客户端不能直接玩模组内容。

Agent / Mineflayer：host=192.168.3.163，port=28977，version=1.21.1，auth=offline。
每个 Agent 使用独立玩家名；操作模组内容需接入本项目原生 SDK，通过 operations 查询当前支持的操作。
登录策略：正版 Java 直连 28976 通过官方会话验证免密码；正版基岩通过 Xbox 验证免密码。离线 Java、Mineflayer 未设密码时直接进入，每次提醒，可在游戏内 /password 新密码 再输一次新密码 设置；已设密码以后 /login 密码。authentication_required 时不能调用 SDK 或管理表单。Numen MCP 的本人令牌接入不变，详见 MY-AGENT-WORLD-LOGIN.txt。

服务端常驻 Numen：外部 Agent 连接 http://192.168.3.163:28984/numen/mcp（Streamable HTTP），使用本人 Bearer 令牌，无需主人 Minecraft 客户端在线。先 tools/list、operations，再创建本人身体、领取租约、执行 Lua 并查询终态；unknown 不重试。基岩进服后欢迎表单或 /mawagent menu 可配置自己的模型 Key、管理同伴、生成外部令牌。详见 docs/MY-AGENT-WORLD-NUMEN-SERVER-CONNECT.txt。
Numen 客户端仍是可选增强：安装同版可用原生 G 面板，不装不会因缺少 Numen 被拒绝登录；其他内容模组仍需匹配。官方客户端外脑仍由主人 Java 客户端提供，和本服服务端 MCP 是独立路线。

基岩女仆 LLM 设置：/mawagent maid，或在同伴菜单点“车万女仆”。OP 配置全服模型服务/Key；普通玩家靠近本人女仆选择模型和人格。保存不调用模型，已有 Key 不回显。详细说明见 docs/MY-AGENT-WORLD-MAID-BEDROCK-CONFIG.txt。

网页第一人称：http://192.168.3.163:28984/
网页第三人称：http://192.168.3.163:28984/third/
上述网页观察 MawExplorer；Numen 身体打开 http://192.168.3.163:28984/numen/view/ ，使用本人 Agent 令牌选择身体，提供独立的只读第一人称、第三人称和模组菜单。详见 MY-AGENT-WORLD-NUMEN-VIEWER.txt。瞬时事件及全部模型/专用界面仍有适配边界。

这个新模组服没有开放公网。旧千灯纪服是另外一个服务器，不要使用它的公网域名或端口连接本服。
