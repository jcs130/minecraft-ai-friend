# 桐人的自主冒险与长期规划

## 原因与改动

2026-09-14 检查发现，之前修复农耕程序时提交的临时反馈仍留在 `control.mission`，每轮都作为当前使命发送。原生 `memory/goals.md` 混有旧矿坑、等待作物等记录，工作记忆也持续围绕农耕。原长期方向只要求选择小目标和写技能，缺少阶段完成后重新选择方向的明确入口。

本次保留 QwenPaw 原会话、人格、身体与程序实践体系，将任务规划交给桐人自己：

- `config/survival-agent.json` 保存长期使命：结合人格与实际经历，选择探索、装备与法术成长、公会承诺、结衣协作、营地等方向，说明理由、依赖、有限完成条件、下一步和调整时机。
- 生存控制器提供固定、有限的规划入口，目标文件仍是原生 `memory/goals.md`。新使命、阶段完成或持续受阻时重新评估；不增加一个额外规划模型或新调度器。
- `qd-survivor-practice` 继续渐进披露：主技能介绍自主规划；`references/long-term-planning.md` 解释阶段与补给维护的区别；`references/exploration.md` 对照当前真实游戏工具说明能力和边界。
- 原生记忆检索的主题优先使用本使命下桐人自己保存的下一步，最多160字符；完整当前使命与长期使命仍保留。来自旧使命回合的迟到记忆不能抢在新使命前面。

主题归属使用真实 `SkillTools.remember` 的 `history[-1].turnId`，不是不存在的顶层字段。最后历史条目的时间、目标、下一步和状态必须与当前记忆一致，再用原决策的 `startedAt` 确认该回合晚于使命变更。没有充分证据时回退当前使命，不补造关联或改记忆格式。

## 自主选择与事实边界

农耕仍可以维持补给，由桐人判断何时够用；反复收割补种没有自然终点，不应成为装备准备、资源侦察等独立活动的统一前置。模型可根据真实危险或身体需要休息。这里没有任务轮换表、强制路线、探索坐标或固定装备优先级。

原生公会支持收购、讨伐、到访任务；当前游戏工具支持近距观察、导航、采矿、制作、装备、交易与法术查询/学习/施放。但还没有开放主动攻击、远距离结构/群系定位、跨维度旅行或通用附魔接口。天然遗迹宝箱也尚不在当前容器授权范围。指南据实说明这些限制；文字规划不使这些能力自动可用。

任务完成依据实际观察、装备变化、本人动作回执与原生公会验收。写下一份计划、程序返回 done 或一段总结，都不能代替游戏成果。程序经验仍走原测试、晋升和实践账本。
