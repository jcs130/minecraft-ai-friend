My Agent World：基岩版同伴可视面板

登录欢迎面板里，直接点击“我的车万女仆”或“我的 Agent 同伴”。
平时选空的快捷栏，靠近自己的女仆或 Numen 同伴，按交互键就能打开面板。
手机点交互，手柄用交互键；不用输入命令。手持魂符等物品时仍使用物品原来的功能。
备用入口：/mawagent maid 或 /mawagent menu。

女仆面板显示实际生命、饱食、工作、跟随、拾取和当前模型。
点“模型 / 人格 / 聊天语言”：选择服务、模型并填写中文人格。
点“工作 / 跟随 / 拾取”：选择种植、护卫等原生工作，开关跟随和拾取。工具、材料仍需要准备；睡觉时请等她醒来。
女仆列表范围是 32 格，空手点击需要靠近到 5 格以内，只能管理自己的女仆。
服主（OP）：菜单里可管理全服女仆 LLM 服务，填写完整聊天接口地址、模型名称和 API Key。

聊天地址示例：https://coding.dashscope.aliyuncs.com/v1/chat/completions
模型示例：qwen3.7-plus
多个模型用英文逗号分隔，最多 24 个。新服务默认关闭，配置完再启用。

已有 Key 不回显，留空保留；新输入会显示在本人输入框，填写时请避开直播录屏，不要发到聊天。
保存不会调用模型。之后女仆原生聊天会使用此服务的 Key。
设置直接接入女仆模组原生配置，Java 客户端可读取同一配置；女仆的记忆、工作和语音设置保留。

这些是游戏内原生按钮、下拉列表、开关和输入框，Java 仍使用模组自带界面。
基岩语音播放、聊天气泡、聊天窗口、女仆背包和饰品格子界面另行适配。
真实手机和云模型还需实机验证，本轮没有付费模型调用。
