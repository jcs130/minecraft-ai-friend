# 桐人与结衣的双角色直播运行计划

目标：保持桐人快慢异步运动链路，恢复结衣独立生活回合，让两人在游戏内自然交流；结衣可依据原生任务目录自主选择跟随、工作或战斗。

## 现状与验证点

1. 核对当前模型路由和节流设置，只提高真实受限的调用频率；保留桐人现有工具和会话。
2. 修复结衣生活 Cron 部署校验的版本漂移，启用已存在的三分钟信号；核对下一次原生任务、信号和模型回合。忙碌时合并信号，不叠加模型任务。
3. 核对结衣的真实身体、装备和原生任务目录；用 `work(taskId)` 切换已启用的任务。战斗模式先确认装备和环境，不能把模式切换当成击杀成果。
4. 恢复结衣的原生聊天设定，验证双方消息的游戏内听见回执及语音队列。结衣生活提示以有意义的观察、危险和协作为发言契机，避免定时念固定台词。
5. 跑相关单元/健康探针和现场回执；保留现有用户工作树改动，记录未能现场验证的能力。
