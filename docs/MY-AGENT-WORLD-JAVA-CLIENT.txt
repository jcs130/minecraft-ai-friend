My Agent World 真实客户端桥 0.3.1

环境：Minecraft Java 1.21.1 + NeoForge 21.1.248 + Java 21。
把 maw-client-bridge-0.3.1-neoforge-1.21.1.jar 放进客户端的 mods，通过正常启动器登录服务器。
可选安装原作者 baritone-api-neoforge-1.11.3.jar，可由同一身体执行导航、采矿、跟随和有限种田；不装时原生操作照常可用。
服务端不需要安装对应桥接模组。目标服务器原有的版本、整合包、账号和权限要求仍然适用。

启动后，游戏目录会生成 maw-client-bridge/connection.json，里面是本机回环接口和令牌，只交给本机 Agent。
SDK 选择 provider=java-client，并明确 username、expectedUuid、expectedServer、controllerId、credentialsFile、ledgerDir。
expectedServer 必须与客户端实际连接地址一致。正常使用沿用原账本，不更换 UUID 或目录绕过未知动作。

流程：连接统一 SDK → snapshot 查询本人 → operations/help 查看参数 → claimControl 申请控制 → submit 带稳定 action_id → wait/result 查询终态 → 核对实际位置或库存。
相同 action_id 和相同参数只返回旧结果；未知动作只对账，不自动重做。客户端观察成功不等于上层任务完成。

崩溃后须分别核对客户端和 SDK 两端账本。0.3.1 的 tools/audit_java_client.py 只供操作者离线使用，要求真实证据及显式 --release-new-actions-keep-unknown；通过同一 instance.lock 确认客户端已经关闭，追加原文件及证据 SHA 证明后才允许新动作。原动作仍为未知，旧 ID 不重放。此入口不向 Agent 或 HTTP 开放，参数见完整 Markdown 指南。

现有接口覆盖真实状态、完整背包组件、菜单槽位、聊天回执、移动视角、挖掘攻击、物品使用、模组界面点击和原始游戏截图，加上 5 项可选 Baritone 和 2 项可选 Minescript，共 30 项。Minescript 用法见 MY-AGENT-WORLD-MINESCRIPT.txt。
魔力等未接入字段返回 null，不能假造满值。世界方块读取来自客户端已加载区块，尚未做严格视线过滤。
菜单操作核对完整物品及光标，界面操作核对 screenToken，避免旧界面误点。

F8 暂停/恢复 Agent 控制。暂停会释放按键，恢复后需要重新申请控制。
控制租约 90 秒，需要显式续租；SDK 没有隐藏的模型循环或控制心跳。
关闭 SDK 保留真实客户端和身体；桥随游戏退出，无新增公网端口。

Mineflayer 兼容层可复用部分 bot API，以及 mineflayer-pathfinder 的 A* 和目标类。
实际碰撞、物品使用、合成和模组界面由原客户端执行。未验证的插件不能当作已完整兼容。
首版局部寻路不挖路搭桥，不支持复杂游泳跑酷或移动机械结构导航。

screen.capture 采集真实客户端 PNG，frame(actionId) 读取字节，支持原始模组模型、动画当前帧和 GUI。
连续视频流与网页观看页尚未接入；原始截图保留最近 64 张，动作记录独立保留。

已在没有服务端桥的农夫乐事隔离服验证真实移动、A* 绕障碍、烹饪锅界面、12 个番茄存取、2×2 合成工作台、切铁镐、挖掘、放置、取消和去重；客户端同世界重启后保留 UUID、位置及动作终态。
完整安装、API 示例和维护细节见 MY-AGENT-WORLD-JAVA-CLIENT.md。
