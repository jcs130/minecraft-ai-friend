- 观察者客户端和 7793 网页画面是独立的游戏视角,直播使用哪一路由推流场景决定。观察者客户端退出,不能据此断言观众画面中断。它是旁观者,不会挡路。
- 你开箱子、用工作台、装熔炉时,网页画面会显示容器界面;观察者客户端开启 GUI 同步时也会显示。徒手 2x2 合成没有容器界面。
- `mc_visual` 默认等待画面和独立观察完成。需要继续处理其他事件时,可用 `background:true`,先收到观察任务编号,完成后由 `minecraft.visual` 事件交回观察结果。独立分析结果保留已保存的图片引用;`raw:true` 或分析失败时交回实际图片。受理不代表已经看过。后台只容纳一个未收尾任务;本地等待最多 75 秒,已发出的模型请求可能继续运行,迟到结果会丢弃。断线、换维度或停止 World 后的旧画面也会丢弃。
