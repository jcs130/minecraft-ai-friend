# MinecraftWorld.reportViewerDecision / 可视化决策来源

任务与战术选择入口将可信的调用角色映射到共享可视化：`main` 为系统二，`host-decision` 为系统一，其他角色保持来源未提供。参数中的自报来源不会覆盖调用角色。

`mc_do` 与 `mc_scout` 上报真实任务编号、技能类别、受理状态和已解析的绝对目标坐标；不会复制聊天正文、命令、模型提示或内部推理。战术选择上报选择回执编号及当次目标实体位置。受理与选择采用不代表执行完成，实际身体操作和效果沿原终态、观察及服务端回执核验。

共享渲染器通过本体 `viewer:decision` 事件显示来源配色，并执行有界保留、过期与连接清理。可视化失败不能改变任务受理或战术选择。没有关联来源的脚本子调用保持未知；不要从攻击、移动、战斗胜负或临近玩家推断决策来源。
