# 新版原生协议依赖兼容

0.5.7-rc.131.native-protocol.1 修复显式服务端扩展选用新版 Mineflayer 时，核心在加载 `game.js` 阶段因旧补丁锚点不匹配而退出的问题。

核心保留两种经过审查的原文：旧版数字／payload 复活指令，以及新版协议 mapper 的 `actionId: 'perform_respawn'`。两者均处理首次片尾与再次离开末地。一个文件只能命中一种且一次；缺失、重复或混合匹配仍拒绝加载，不按任意关键词猜补丁。

通用执行队列、请求去重、取消、身体租约和事件协议保持不变。核心没有导入任何服务器适配器，也没有通过跳过依赖校验来接纳未知版本。Minecraft 1.21.1 仍是默认维护目标；26.3 等新协议由显式注入的、独立验收的连接组件承担。构建和打包本核心并不自动升级任何运行中的服务器或 Agent。
