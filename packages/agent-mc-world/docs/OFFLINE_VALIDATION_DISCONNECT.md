# 离线方法校验与断线（rc.71）

Linux 的真实子进程检查暴露：引擎的连接尝试失败时，World 无条件取消当前方法，连 `mc_script validate:true` 的纯语法／依赖图校验也收到 `cancelled`。Windows 的时序常让校验先完成，所以此前完整本机测试没有暴露这个竞争。

`MethodRunner.cancelForDisconnect()` 现在区分校验和执行：

- `validate:true` 不取得游戏能力，连接中断不撤销纯校验；它仍受原工作线程、大小与时间预算约束。
- 正在调用游戏的方法继续收到原断线取消回执，不重放未知动作。
- 显式 `mc_stop`、World 停止等仍走原 `stop()`，可以取消校验。

没有放宽认证、权限、脚本能力或超时，不新增模型循环。新增三项边界回归，并保留真实子进程的原回执断言；失败信息附完整离线夹具回执以便诊断。

源码版本升至 **0.5.7-rc.71**。这次仓库发布不自动更新已安装的 Agent 客户端或官网下载 Skill；宿主更新需独立校验自己的固定依赖。引擎／SDK 构建、声明校验、完整测试及隔离打包消费者是发布门禁。
