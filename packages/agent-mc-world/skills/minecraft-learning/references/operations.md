# 不同操作共用的评价方法

系统2选择任务与有依据的操作版本，系统1在已确认的选项中及时选择，执行器持续控制实际身体。先用真实帮助读取参数，运行时核验能力。

| 操作 | 前提与结束条件 | 应核对的效果 | 常见误判 |
| --- | --- | --- | --- |
| 飞行 | 已授权、已加载净空、可达落点、许可剩余时间与落地余量 | 起终点、按键持续时间、落地回执、生命和资源变化 | 获得许可不等于已起飞；施法后等待模型会消耗时长 |
| 闪现/传送 | 真实技能说明、已学会、魔力/冷却、目标与落点条件 | 施法回执、服务端位置更新、维度、到目标剩余距离 | 客户端动画不等于服务端接受；未知冷却不是零 |
| 法术/治疗 | 目标资格、距离、视线、资源与现有控制器 | 施法前后生命、资源、目标状态及效果回执 | 指令受理不等于命中；同时变化不能证明单一因果 |
| 寻路/游泳 | 支撑、净空、氧气、已知安全出口 | 实际位移、终态、受伤、卡住位置 | 寻路失败不证明目的地不可达 |
| 采集/制作/建造 | 材料、工具、配方、权限、清理责任 | 净库存/方块变化、消耗、终态、遗留物 | API 返回不代表物品到账；库存未同步为未知 |
| 交互/菜单 | 当前窗口和按钮语义、窗口代号 | 服务端反馈和目标状态 | 点击成功不等于任务领取/结算成功 |
| 战斗/跟随 | 任务目的、敌我关系、生命、距离、地形、可执行候选 | 延迟、受伤、距离控制、拒绝和最后任务证据 | 短时位移不是获胜；目标不可见不是击杀 |

方法分成有限的观察—行动—验收段，必要时组合已有方法。新危险、未知机制、条件变化或连续失败交还系统2；继续有用的控制器也是合法选项。快模型选择权不能凭历史“成功过”扩展到未授权动作。
