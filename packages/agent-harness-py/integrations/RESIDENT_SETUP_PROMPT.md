# 千灯纪居民插件接入提示词

把下面整段发给负责接入这台电脑的 Agent。

> 请帮我把这台电脑的 N.E.K.O. 或 Cortico 接入千灯纪正式服，使用服务器里的居民身体。去 https://mc.kangqiang.site/downloads.html#resident 下载千灯纪居民插件。N.E.K.O. 在插件中心导入 `.neko-plugin`。Cortico 先核对本机 World API 版本，解压对应安装包，再在扩展管理中从本机目录安装含 `package.json` 的 `package` 目录，为我要使用的 bot 启用「千灯纪居民」。
>
> 先让我选本机人设。N.E.K.O. 里点「登录千灯纪」，由我在官网选择原游戏角色并确认这台设备。官网有登录会话时直接显示授权页。跨设备时才使用插件给出的地址和六位码。原角色有旧居民插件绑定时，由我决定是否迁移。Cortico 沿用「网页登录并授权」，在官网核对 Cortico 显示的六位码，并返回插件选择原角色。
>
> 新建使用车万女仆。可以在插件里填写游戏角色名和托管人设，也可以在 https://mc.kangqiang.site/resident-connect.html?flow=create&bodyKind=maid 创建，完成后回插件刷新列表。托管人设用于桌面断线后的服务器决策，本机的人设和记忆继续由本机宿主管理。已有女仆或 Numen 可以沿用原角色连接。身体准备中时查看状态，发现名额不足就告诉我当前页面反馈。
>
> N.E.K.O. 授权后先核对角色 UUID 和身体状态，由我点击「开始游玩」。重开 N.E.K.O. 后，确认面板恢复原角色的身体和模式，再手动开始一次并查到游戏原动作回执。然后由我在游戏里靠近并打字点名。再用 Java 的 Simple Voice Chat 在附近说一句话，核对插件能收到来源为语音的转写，最后让角色在游戏里回复。分别告诉我观察结果、文本回执、语音发出回执和实际听到的情况。游戏账号密码、官网密码和连接密钥都由各自登录界面或宿主私有存储管理。
