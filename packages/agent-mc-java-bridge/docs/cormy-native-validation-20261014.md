# Cormy 真实客户端阶段验收

日期：2026-10-14。此报告区分源码、候选包、部署与实际操作，不将基础接入等同于完整游戏能力迁移。

## 源码与候选包

- 通用核心使用独立 `agent-mc-world` 源码、默认入口、公开类型和构建；宿主通过可选 `provider=java-client` 使用自己的 Fabric 1.20.6 客户端桥。
- 已接入显式启用的 Minescript 4.0 Python。没有移植 Numen Lua VM；[Lua API 核查](numen-lua-api-review.md) 是能力对照与后续方案。
- 核心独立构建、类型检查通过，95 个测试文件、733 项测试全部通过，包含真实 loopback/子进程及公开声明消费测试。
- 宿主适配器独立构建、类型检查和 API 5 包校验通过，29 个测试文件、185 项测试通过。
- 通过候选 tarball 安装到隔离运行目录，未安装 Cortico 框架的消费者通过 SDK/MCP 行为一致性、显式回合、等待取消、停止后不复活、禁止额外网络/子进程检查，NodeNext 公开类型消费通过。
- 本轮为本地候选验收，没有发布 npm。

## 部署保持

Cormy 使用原宿主主会话、原游戏账号和 UUID，原目标、模型设置及游戏记忆作用域保持。旧 Mineflayer 身体先通过自己的停止工具收尾，再切换真实客户端；没有两个控制器同时占用同一账号。宿主在显式配置后续租身体控制权，无额外模型循环或自动重连。

两次修复重载均保留原账本。未知动作不重投；失败尝试原记录保留。主会话曾因超大回执达到约 22 万 token，已使用宿主原生 handoff 保留目标和记忆并整理到约 3.6 万 token，不通过手工清空历史解决。

运行原文、图像及私有账本保存在部署目录，不随公开源码提交。

## 修复的问题

1. **未知移动参数静默忽略**：`backward` 被模型误用。桥现在拒绝未登记字段；真实后退字段为 `back`。
2. **回执污染上下文**：书本全文/完整组件导致一次状态超过 50 万字符。现在正常状态约 7800 字符，动作受理约 400 字符；原文压缩归档，`mc_evidence` 与组件分页可完整取回。原文没有丢弃。
3. **Minescript 工作目录不一致**：4.0 从进程 cwd 读取脚本和 Python 配置，单独 `--gameDir` 不够。启动目录已改为实际游戏目录；桥在目录不一致时不广告此能力，防止只装了模组就误认为可用。

## 仍未验收

- 高级寻路、采矿、战斗、复杂合成和精确容器搬运没有完成真实客户端迁移，不能承诺旧 Mineflayer 脚本直接可用。
- 原 YSM 角色模型、全部整合包模组和原 Web 第三人称/2.5D 信息面板尚未在这次最小 Fabric 实例中验收。
- 本次实机证据覆盖短程移动、脚本和背包。长期自主生存、任务完成率、整体验证速度、最小化/锁屏后的持续渲染及真人同时使用鼠标的完整体验尚不能据此宣布通过。
- TTS/演出仍为独立扩展，QQ/B 站登录等既有事项不属于这次客户端验收。
