# Changelog

## 0.2.94

- End the current model chain after a typed successful action completion with
  no execution identity and no remaining steps. Preserve its exact receipt and
  use the existing bounded no-action backoff instead of treating an already
  satisfied arrival as new work. Queries, pending tasks, unknown-dispatch
  fences, arrival conditions and submitted arguments remain unchanged.

## 0.2.93

- Pin upstream core rc.80 with shared bounded observation contracts, structured
  partial/blocked/unknown receipts, original-request reconciliation and strict
  booleans/integers. Preserve sparse visible defaults, anchored optional paging
  and unknown-effect barriers; unsupported targets are not guessed or rewritten.
- Recognize the new MCP `data.status=unknown` receipt even without an execution
  object or transport error. Preserve the original in-flight journal and restart
  fence. The disconnected consumer reconciles the original request read-only
  instead of interpreting the new transport envelope as successful capture.
- Include native proactive combat/checkpoint restoration, bounded journey cues
  and explicit method-cost evaluation support. Optional practice workers and
  model-based decision services are not activated by installing this update.

## 0.2.88

- When a real full-context overflow retires an immutable native terminal's
  history group, retire its identical recent replay copy too. Otherwise the
  next scene re-inlines the retired receipt and can keep requests saturated
  even after all history has gone. Keep the newest terminal, report omitted
  execution identities and original event locations, and preserve journals,
  pending work, barriers and fitting history. Cache-margin probes use the same
  retirement operation as the actual request; no deadline or capacity changes.

## 0.2.80

- Preserve the complete bounded standing instruction in strategic review, rather
  than silently clipping later method-learning and evidence requirements. Larger
  instructions have an explicit immutable original query.
- Compare dated public native goal/method summaries across the existing review
  publication path. Inventory activity no longer hides that sampled milestones
  and method summaries are unchanged. Keep at most eight samples over an hour,
  with three in the compact view, isolated by owner/world/run/lifecycle and user
  intent. This is evidence for the host's choice, not a forced project switch,
  world-progress certification, extra timer/model call or second body queue.
