# Short strategic checkpoint contract

The final transaction already asks for short text fields. That does not address
hidden deliberation before the transaction. A bounded strategic checkpoint now
also supplies `completion_contract.reasoning_guidance`: reason briefly from
inspected evidence, state uncertainty, and finish within the original deadline.
Full and compact inspection expose the same host-neutral guidance. Host adapters
may project it into their system instruction ahead of selected personal context.

This is advisory model guidance, not a provider thinking parameter, enforced
token budget, different decision policy or evidence of reduced latency. It does
not pick continue/insert/revise, force a particular project, omit required death
reflection, waive original evidence/intent/stop checks, extend an opportunity or
dispatch a game action. Persona projection and selected memory remain available.
Actual finish reason, usage and canonical acknowledgement must be measured
separately by the consuming transport before claiming a live improvement.

The change is review-only. An adapter can consume it while its independent body
continues using the earlier coordinator package; body, core and viewer need no
restart or replacement. No optional worker or additional model loop is enabled.
